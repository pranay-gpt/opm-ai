# Well Controls in Eclipse/OPM Flow: Rate vs BHP Control

Well controls define how wells are operated during simulation. Understanding the difference between rate control and bottom-hole pressure (BHP) control is essential for realistic simulation.

## Control Types

### 1. Rate Control (Surface Rate)
**Keywords**: `WCONPROD` / `WCONINJE` with rate targets

```
WCONPROD
'PROD1' OPEN ORAT 5000 1* 1* 2000 /
```
- **ORAT**: Target oil rate (STB/day)
- **WRAT**: Target water rate (STB/day)
- **GRAT**: Target gas rate (MSCF/day)
- **LRAT**: Target liquid rate (STB/day)
- **RESV**: Target reservoir volume rate (RB/day)

**Behavior**: Simulator adjusts BHP to meet rate target. If BHP hits limit, well switches to BHP control (constraint).

### 2. BHP Control (Bottom-Hole Pressure)
**Keywords**: `WCONPROD` / `WCONINJE` with BHP target

```
WCONPROD
'PROD1' OPEN LBHP 2000 1* 1* 1* /
```
- **LBHP**: Target flowing bottom-hole pressure (psia)
- **THP**: Target tubing head pressure (optional)

**Behavior**: Simulator calculates rates based on BHP and inflow performance. Rate is the result, not the input.

## Control Switching (Constraints)

Wells can have **multiple constraints** - the simulator honors the most restrictive.

```
WCONPROD
'PROD1' OPEN ORAT 5000 1* 2000 1500 /
```
- Target: 5000 STB/day oil
- Max water: 2000 STB/day (if exceeded, switch to WRAT control)
- Min BHP: 1500 psia (if hit, switch to LBHP control)

**Priority order** (most restrictive wins):
1. BHP limits (LBHP, THP)
2. Rate limits (ORAT, WRAT, GRAT, LRAT)
3. Group constraints (`GCONPROD` / `GCONINJE`)

## VFP Tables (Vertical Flow Performance)

For THP control or when tubing hydraulics matter:

```
VFPPROD
'VFP1' 2000 1000 0.5 0.8 ... /
```
- Relates BHP to THP at given rates and GOR/WC
- Required for `THP` control on `WCONPROD`
- Generated by wellbore simulators (e.g., Prosper, WellFlo) or correlations

## Well Groups (`WELSPECS` + `GCONPROD`)

Wells grouped for collective constraints:

```
WELSPECS
'PROD1' 'GROUP1' 1 1 /
'PROD2' 'GROUP1' 1 1 /

GCONPROD
'GROUP1' GRAT 20000 1* 1* 5000 /
```
- Group rate target (GRAT) distributed to wells based on PI
- Group BHP limit applies to all wells
- Priority via `WELSPECS` well ordering or `WELPRI`

## OPM Flow Specifics

| Feature | Eclipse | OPM Flow |
|---------|---------|----------|
| Rate control | ✓ | ✓ |
| BHP control | ✓ | ✓ |
| THP control | ✓ | ✓ (via VFP) |
| Group control | ✓ | ✓ |
| Multi-segment wells | ✓ | ✓ |
| Automatic constraint switching | ✓ | ✓ |

## Common Issues

| Problem | Cause | Fix |
|---------|-------|-----|
| Well shuts in | BHP limit too high / rate target unreachable | Check PI, relperm, skin; lower BHP limit |
| Oscillating control | Rate target near constraint boundary | Add small tolerance, check timestep |
| Water breakthrough not seen | Injector BHP limit too low | Increase injector BHP limit |
| Gas coning | Producer rate too high | Reduce rate, add BHP limit |

## Key Keywords Summary

| Keyword | Section | Purpose |
|---------|---------|---------|
| `WCONPROD` | SCHEDULE | Producer control (rate/BHP) |
| `WCONINJE` | SCHEDULE | Injector control (rate/BHP) |
| `WELSPECS` | SCHEDULE | Well location, group, VFP table |
| `GCONPROD` | SCHEDULE | Group production constraints |
| `GCONINJE` | SCHEDULE | Group injection constraints |
| `VFPPROD` | SCHEDULE | Producer VFP table (BHP-THP) |
| `VFPINJ` | SCHEDULE | Injector VFP table |
| `WELPRI` | SCHEDULE | Well priority in group |
| `WTEST` | SCHEDULE | Well test criteria (shut-in conditions) |

**Key takeaway**: Rate control with BHP constraints is most common for producers. Injectors typically use rate control with BHP limit. Always set both target and constraint to avoid unrealistic behavior.
