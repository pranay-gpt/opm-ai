In a run with Ncomps components, using an equation of state, this keyword defines the acentric factor for each component. The keyword should be followed by Ncomps values. The use of the acentric factor in the equation of state is discussed in "Equations of State" in the ECLIPSE Technical Description.

If multiple equations of state are being used, a set of data should be entered for each reservoir EoS. The number of reservoir equation of state regions is entered as NMEOSR in keyword TABDIMS. The use of multiple EoS regions is discussed in "Equations of State Regions" in the ECLIPSE Technical Description.

DEFAULT: There are no component-wise default values. You are recommended not to default these to the internal default values.
