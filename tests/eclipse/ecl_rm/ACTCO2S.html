This keyword is used to specify the activity coefficient model for CO2 which is used by the CO2STORE option (salting out effect).

This keyword has one item that specifies the activity coefficient model to be used.

  1. An integer selecting the model:
    0 No correction of the CO2 activity due to salts.
    1 This is the Rumpf et al. (1994) activity coefficient model with the modifications as detailed by Spycher and Pruess (2005). It is applicable up to 160°C.
    2 This is the activity coefficient model of Duan and Sun, as modified by Spycher and Pruess (2009). It is applicable up to 250°C.

    DEFAULT: 1

Example

Selecting activity coefficient model 2 for CO2:
