The keyword should be followed by one integer for every grid block in the current box to identify an active/inactive grid block:

0 Indicates that the corresponding grid block is inactive
1 Indicates that the corresponding grid block is active
2 Indicates that the corresponding grid block has rock volume only(ECLIPSE 300 Thermal only)
3 Indicates that the corresponding grid block has pore volume only (ECLIPSE 300 Thermal only).

The data must be terminated by a slash (/).

Grid blocks are ordered with the X axis index cycling fastest, followed by the Y and Z axis indices. Repeat counts may be used for repeated values (for example 12*0). Note that spaces must not be inserted on either side of the asterisk.

It should be noted that ACTNUM is one of a number of ways of identifying inactive grid blocks – any method that results in zero pore volume will cause a grid block to be treated as inactive. Other possibilities include:

  • Setting the porosity ( PORO), or net to gross thickness ratio ( NTG), to zero in the GRID section.
  • Setting a minimum threshold pore volume, using either the MINPV or MINPVV keywords; any grid blocks having a pore volume smaller than the minimum pore volume will be treated as inactive.

The active cell indicator information is output to both the EGRID and GRID files. Please refer to the description provided in the ECLIPSE File Formats Reference Manual.

ECLIPSE 300

The values set using this keyword can be output by setting item 5 of the DEBUG3 keyword to a non-zero positive value.

This array of information is further updated internally to provide a natural cell to active cell mapping (refer to additional output given by this DEBUG3 switch as well as the IOCN argument for use with the RPTGRID and RPTGRIDL keywords).

ECLIPSE 300 Thermal option with dual- or multi-porosity

For runs with the Thermal option and dual- or multi-porosity, the combination of available ACTNUM values can cause inconsistencies in how the data is used.

  • A wholly inactive (ACTNUM=0) matrix or fracture cell will deactivate the corresponding fracture or matrix, but other values will affect only the selected porosity and leave the other porosities unaltered. However, the meaning of a rock-only fracture cell or a fluid-only matrix cell, for example, is ill-defined, and care should be taken care in using these options. For more information, see "Dual porosity" in the ECLIPSE Technical Description.
  • Also note that pore volume only (ACTNUM=3) means that the porosity will be set to 1.0, regardless of the input porosity values. Some control over the fraction of cell volume that is pore volume is available with this option by using net to gross values (NTG).
