The data comprises NTSFUN (set in the TABDIMS keyword) tables of alkaline adsorption functions, each terminated by a slash (/), describing the adsorption of alkaline by the rock formation. Each table consists of the following columns of data:

  1. The local alkaline concentration in the solution surrounding the rock.

    The values should increase monotonically down the column.

    UNITS: kg/sm3 (METRIC), lb/stb (FIELD), gm/scc (LAB)

  2. The corresponding saturated concentration of alkaline adsorbed by the rock formation.

    These values should increase monotonically down the column.

    UNITS: kg/kg (METRIC), lb/lb (FIELD), gm/gm (LAB)

Each table must contain at least two, and no more than NSSFUN (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table. If any table after the first is defaulted, then that table is copied from the previous table.

CAUTION: The first row in the adsorption tables should consist of a pair of zeroes.

See "Alkaline model" in the ECLIPSE Technical Description for further information.
