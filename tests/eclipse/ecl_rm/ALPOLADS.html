The data comprises NTSFUN (set in the TABDIMS keyword) tables of polymer adsorption multipliers as a function of the alkaline concentration, each terminated by a slash (/). Each table consists of 2 columns of data:

  1. The local alkaline concentration.

    The values should increase monotonically down the column.

    UNITS: kg/sm3 (METRIC), lb/stb (FIELD), gm/scc (LAB)

  2. The corresponding polymer adsorption multiplier.

    UNITS: dimensionless

Each column in the table must contain at least two, and no more than NSSFUN (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table. If any table after the first is defaulted, then that table is copied from the previous table.

CAUTION: The first row in each table should consist of a multiplier of one associated to a concentration of zero.

See "Alkaline Model" in the ECLIPSE Technical Description for further information.

Example

With NTSFUN = 2 and NSSFUN = 5

 3   0.90005
 5   0.90007
 8   0.90008
