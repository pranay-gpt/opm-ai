This keyword can be used to change the datum depth and the datum pressures in all the aquifers defined using the AQUCHWAT keyword.

The data consists of some or all of the following items terminated with a slash (/).

  1. Change to add to datum depths

    UNITS: m (METRIC), ft (FIELD), cm (LAB)

    DEFAULT: 0.0

  2. Factor to multiply datum pressures by

    DEFAULT: 1.0

Example

Increase the datum depth by 10 metres; leave the pressure unchanged:

AQUCWFAC
 10.0 1.0 /
