This keyword can be used to define a wettability factor F as a function of the asphaltene deposition. The wettability factor is used to interpolate relative permeability between the water wet relative permeabilities at F= 0, provided by standard keywords such as SWFN, SOF3 or SWOF and the oil wet relative permeabilities at F= 1, provided by the ASPKROW keyword.

The data consists of NTSFUN (set in the TABDIMS keyword) tables, each containing the following columns of data:

  1. The volume fraction of asphaltene deposit, either S s or ε.

    If the solid model is used for asphaltene deposition, the volume fraction is measured as a proportion of the pore volume, and the solid saturation Ss is required here. However, if the pre-2011.1 asphaltene deposition model is used, the volume fraction of asphaltene deposit is measured as a proportion of the cell volume and ε =ϕ⋅Ss is required here.

  2. The wettability factor F which must be between 0 and 1.

The maximum number of rows in each table is specified by MXRATF in the TABDIMS keyword.

For more details please refer to the "Asphaltene option" in the ECLIPSE Technical Description.

Note: This keyword is active only where the system is water wet, defined here by the oil-water capillary pressure P cow >0

Example

ASPWETF
-- deposit F factor
    0.00    0.0
    0.01    0.01
