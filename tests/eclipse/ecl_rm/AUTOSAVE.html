This keyword specifies that SAVE files are to be written every N steps during the simulation. It may be entered more than once in the SCHEDULE section.

The effect depends on the MULTSAVE option specified in the RUNSPEC section:

  • If MULTSAVE set to -1: No effect, as SAVE files suppressed
  • If MULTSAVE set to 0 (default): Continuously overwrites SAVE files
  • If MULTSAVE set to 1: Produce a new SAVE file each time.
