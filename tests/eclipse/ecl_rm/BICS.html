In a run with Ncomps components, using an equation of state, this keyword defines the binary interaction coefficients between the components. These are the coefficients to be used for the production system (that is on the surface). If the BICS keyword is not used, the values supplied with keyword BIC is used.

The format of the keyword is exactly the same as that of BIC.

If multiple equations of state are being used, a set of data should be entered for each surface EoS. The number of surface equation of state regions is entered as NMEOSS in keyword TABDIMS. The use of multiple EoS regions is discussed in "Equations of state regions" in the ECLIPSE Technical Description.
