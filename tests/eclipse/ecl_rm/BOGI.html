The data comprises NTPVT (set in the TABDIMS keyword) tables of saturated oil FVF multiplier functions, describing the variation of saturated FVF of oil with pressure and Gi values. Each table is terminated by a slash (/). Each table is terminated by a slash (/). Each table contains a maximum of NPPVT (set in the TABDIMS keyword) records terminated by a slash (/) and each record contains a maximum of NPPVT rows of data. The rows of data specify a two-dimensional (P, Gi) function which multiplies the saturated oil FVF value at (P, Gi=0) to give the true saturated oil FVF at (P, Gi). The saturated oil FVF value at (P, Gi=0) is obtained from the corresponding PVTO table.

The first row of data in a record contains:

  1. The oil pressure value.

    The values should increase monotonically down the column.

    UNITS: barsa (METRIC), psia (FIELD), atma (LAB)

  2. The factor by which the saturated oil FVF calculated from the PVTO keyword at a pressure corresponding to item 1 has to be multiplied to give the true saturated oil FVF at a pressure corresponding to item 1 and a Gi value given by item 1 in the corresponding GINODE table.

The other rows in the record each contain only the second item of data which defines the corresponding factor by which the saturated oil FVF at (P, Gi=0) (computed from the PVTO data) has to be multiplied to give the true saturated FVF for oil at a pressure value given the first row and whose Gi value is specified in the corresponding record in the GINODE keyword.

See "Gi pseudo-compositional model" in the ECLIPSE Technical Description for further information.

Example

In this example, NTPVT = 1 and there is one table of data, terminated by the final slash (/). Also NPPVT =2 and the table contains two records, each terminated by a slash and each record contains two rows of data. The first row of each record contains the oil pressure and a multiplication factor, while the second row contains a multiplication factor.
