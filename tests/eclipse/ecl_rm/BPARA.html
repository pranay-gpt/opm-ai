This keyword enables the Block Parallel license option.

This is an alternative license option for parallel simulations with up to 32 parallel domains. In such cases, a single Block Parallel license can be used instead of the (up to) 32 parallel licenses that would normally be required.

To use this option the parallel keyword ( PARALLEL) must also be present, with item 1 (the number of domains) set to a value in the range 2 to 32.

The keyword BPARA contains no items of associated data.

Notes

  • The Block Parallel license feature is not compatible with multiple realization ( MULTREAL) runs.
  • Only one Block Parallel license can be used in an ECLIPSE run. If more than 32 domains are requested the simulation will stop with an error message and the simulation should then be run using the normal parallel licensing options.

See "Block parallel license" in the ECLIPSE Technical Description for more information.

Example

BPARA 
PARALLEL 
--NPROCS MACHINE TYPE
    32     DISTRIBUTED /
