The data consists of items which specify the number of SUMMARY keywords for interpolated quantities. Such SUMMARY keywords include BPR_X, BHD_X, BHDF_X, BSCN_X and BCTRA_X for the global grid, and LBPR_X, LBHD_X, LBHDF_X, LBSCN_X and LBCTRA_X for local grids. The data must be terminated by a slash (/).

  1. MXNBIP

    The maximum number of lines of block interpolated data entered in the SUMMARY section for the global grid, using keywords BPR_X, BHD_X, BHDF_X, BSCN_X and BCTRA_X.

    DEFAULT:  10

  2. MXNLBI

    The maximum number of lines of block interpolated data entered in the SUMMARY section for all local grids, using keywords LBPR_X, LBHD_X, LBHDF_X, LBSCN_X and LBCTRA_X.

    DEFAULT:  1

Example

A maximum of twenty listings for the global grid, and ten listings for local grids.

BPIDIMS
 20 10 /
