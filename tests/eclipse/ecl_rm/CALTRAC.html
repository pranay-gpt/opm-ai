This keyword is used to specify the tracer whose concentration represents the calorific value of the gas, when the Gas Calorific Value Control option is being used (see "Gas calorific value control" in the ECLIPSE Technical Description).

The tracer must be already defined as a gas phase passive tracer (keyword TRACER in the PROPS section), and initialized to equal the calorific value in units of kJ/sm3 (METRIC), Btu/Mscf (FIELD), J/scc (LAB). (See "Tracer tracking" in the ECLIPSE Technical Description for an account of how to define tracers.)

The keyword is followed by a single record, terminated with a slash (/).

  1. Name of the tracer

    (Up to 3 characters)

End data record with a slash (/).

Example

CALTRAC
 CAL /
