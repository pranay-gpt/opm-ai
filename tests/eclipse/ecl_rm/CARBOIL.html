The data comprises one carbon content value for each pressure table region representing how many atoms of carbons are present per surface volume of oil. The number of pressure table regions is specified using keyword TABDIMS in the RUNSPEC section and defaults to 1. Each record consists of the following item of data, and is terminated by a slash (/).

CARBOIL or CARBGAS keywords trigger additional reporting to help better understand the environmental impact of hydrocarbon produced. If either or both is present, a message will be present at the end of the PRT file showing the overall moles of carbon produced as well as the corresponding mass in terms of pure carbon or equivalent CO2. Net carbon rates and cumulatives can also be reported as summary vectors.

See "Net carbon production/injection tracking" in the ECLIPSE Technical Description for more information.

  1. The amount of carbon in oil at surface conditions

    UNITS: kg-M/sm3 (METRIC), lb-M/stb (FIELD), gm-M/scc (LAB)

    DEFAULT: 0 in all units

Note: Setting this value to zero does not imply that the oil contains no carbon; only that oil produced or injected via wells which use that PVT region will not contribute to the amount of carbon reported.
Note: If this keyword is used with the API facility, you will need to define one value per API degree table, but only the value in the first table will be used.
