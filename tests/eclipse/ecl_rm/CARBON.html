The CARBON keyword specifies the number of carbon atoms per molecule for each component. It should be followed by one value for each hydrocarbon component and terminated by a slash (/).

The CARBON keyword triggers additional reporting to help better understand the environmental impact of hydrocarbon produced. If it is present, a message will be present at the end of the PRT file showing the overall moles of carbon produced as well as the corresponding mass in terms of pure carbon or equivalent CO2. Net carbon rates and cumulatives can also be reported as summary vectors.

See "Net carbon production/injection tracking" in the ECLIPSE Technical Description for more information.

UNITS: dimensionless

Note: While logically the number of carbon atoms per molecule is an integer, real values are permitted to allow for components which represent a mixture.

Example

CNAMES
CO2   N2   C1    C2      C3  /

CARBON
  1   0   1  2.005  3.0069  /
