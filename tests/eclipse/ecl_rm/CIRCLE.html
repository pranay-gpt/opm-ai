This keyword requests that non-neighbor connections be generated to complete the circle in radial geometry. These connections act between the last cell in the azimuthal, θ, direction, and the first cell, for each layer and ring of cells in the R-direction.

Such connections are only generated if the grid subtends 360 degrees, so that the first and last cells are in contact.

This keyword has no items, and only has an effect if the RADIAL keyword is specified in the RUNSPEC section.
