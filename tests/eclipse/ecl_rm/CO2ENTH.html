This keyword selects the calculation method for CO2 enthalpy. It is available only for CO2STORE Thermal runs for models with no additional hydrocarbon components.

The data consists of a character string terminated with a slash (/).

The options are:

SPECH Calculate CO2 enthalpy using the SPECHx, HEATVAPx, and ZFACT1 keywords.
IMPNOMFD Calculate CO2 enthalpy using the internal Symmetry* process software platform tables without mole fraction dependence.
IMPMFD Calculate CO2 enthalpy using the internal Symmetry* process software platform tables, including phase mole fraction dependence.

DEFAULT: SPECH

See "Thermal CO2STORE" in the ECLIPSE Technical Description for further details.
