This keyword can be used with multi-component water ( COMPW) to identify special water components.

The keyword should be followed by one value for each component:

Table 247.2 CWTYPE component values
Type Component
SURFF Surfactant component for foam model ( FOAMFSC)
SURFS Surfactant component for surface tension effects ( SURFST)
SURF Surfactant component for both foam and surface tension effects
POLY Polymer component for water phase viscosity effects
ALK Alkaline component for water phase viscosity effects

All other water components should use the default type (for example 1*).

If multiple equations of state are being used, a set of data should be entered for each reservoir equation of state (EoS). The number of reservoir EoS regions is entered as the NMEOSR in keyword TABDIMS. The use of multiple EoS regions is discussed in "Equations of state regions" in the ECLIPSE Technical Description.

Note that the multi-component water model is not currently compatible with THERMAL options, GASWAT option, GASSOL option, CO2SOL option, Satellite groups (see GSATPROD) and IMPSAT. See “Water components option limitations” in the ECLIPSE Technical Description.
