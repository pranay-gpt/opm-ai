This keyword is relevant only in dual porosity runs (keyword DUALPORO in RUNSPEC) that use the molecular diffusion option (keyword DIFFUSE in RUNSPEC).

If this keyword is present, the molecular diffusion calculation is only performed for the matrix-fracture flows.

This can be useful to minimize the computer cost in dual porosity cases where the diffusive flows have been shown to be negligible except in the matrix-fracture flow, where diffusion may be the dominant recovery mechanism.

The keyword has no associated data.
