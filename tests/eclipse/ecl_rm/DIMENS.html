This keyword defines the basic size of the simulation grid. It is followed by three integers, specifying the number of cells in the x, y and z directions respectively. (In the radial case, these values specify the number of cells in the r, θ and z directions). In the documentation, the items in the DIMENS keyword are referred to as Nx, N y and Nz, or NDIVIX, NDIVIY and NDIVIZ.

There is no default. It is an error not to supply the grid dimensions.

In ECLIPSE 100, when using any discretized matrix option (keyword NMATRIX) including the discretized gravity drainage model activated by keywords GRAVDRB and NMATOPTS (option VERTICAL), the minimum value of the number of cells in the X direction is 2.

Example

For a reservoir represented by a 10 x 3 x 4 grid the keyword would be:

DIMENS
10 3 4 /
