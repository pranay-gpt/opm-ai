The DIMPES keyword switches from the default implicit solution technique to the IMplicit Pressure Explicit Saturation solution procedure.

The data comprises the following data items terminated by a slash (/). If a slash is encountered before the end of the data, the remaining items are left at their default values.

Data items

DSTARG Target maximum saturation change in any timestep

DEFAULT: 0.05
DSMAX Maximum tolerable saturation change in any timestep

DEFAULT: 0.1
DPMAX Maximum tolerable pressure change in any timestep

UNITS: bars (METRIC), psi (FIELD), atm (LAB)

DEFAULT: 200 psi
