This keyword requires no data and can be used to switch from the IMPES method back to the Fully Implicit method (see keywords IMPES, DIMPES and FULLIMP). The TUNING parameters are reset to their default values.

This was formerly the IMPLICIT keyword in ECLIPSE 100.

Note: The DIMPLICT keyword cannot be used if the IMPES keyword has been specified in the RUNSPEC section. If the base case of a restart run was run with IMPES, however defined, the restart run cannot use the DIMPLICT keyword.

Example

DIMPLICT
