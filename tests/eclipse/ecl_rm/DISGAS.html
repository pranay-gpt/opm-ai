This indicates that the run contains dissolved gas in live oil.

The keyword may be used only if OIL and GAS are both present.

If oil has a constant and uniform dissolved gas concentration, and if the pressure never drops below the bubble point, then the model can be run more efficiently by omitting the GAS and DISGAS keywords from the RUNSPEC section, treating the oil as dead oil, and declaring a constant Rs value with keyword RSCONST or RSCONSTT in the PROPS section. The simulation is run as a dead oil problem with no gas, but the calculations take into account the constant dissolved gas concentration.

The keyword has no associated data.

When the BLACKOIL keyword is used in ECLIPSE 300 this option is automatically selected if the PVTO or PVCO keywords are present.
