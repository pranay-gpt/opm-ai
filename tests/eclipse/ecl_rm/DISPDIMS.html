The data consists of the following items, describing the dimensions of the dispersion tables to be used in the run (see TRDIS). The data must be terminated by a slash (/).

The items are:

  1. The number of dispersion tables

    DEFAULT: 1

  2. The maximum number velocity nodes in any dispersion table (there must be a minimum of 2)

    DEFAULT: 2

  3. The maximum number of concentration nodes per velocity node in any dispersion table.

    DEFAULT: 1

See also TRDIS, DISPERSE and DSPDEINT.
