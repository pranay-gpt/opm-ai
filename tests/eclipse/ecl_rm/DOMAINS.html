You can use this optional keyword to modify the number of planes allocated to each domain.

The keyword should be followed by one positive real number for each domain in the model. The number of domains is specified using keyword PARALLEL in the RUNSPEC section. The data must be terminated by a slash. The total number of planes must sum to the number of cells in the outer solver direction.

It is advisable to set the outer solver direction manually using the SOLVDIRS keyword when using this keyword. The solver direction sequence, whether it is determined by ECLIPSE or set by you, can be output using the DOMAINS mnemonic in the RPTGRID keyword. If so, the SOLVDIRS and DOMAINS keywords are also output in the PRT file so you can paste them into the grid section and modify them if you want to use other settings.

Example

Outer direction X, NX=40 and Nprocs=8 

SOLVDIRS
 '-X' /
DOMAINS
 7 6 4 3 3 4 6 7 /
