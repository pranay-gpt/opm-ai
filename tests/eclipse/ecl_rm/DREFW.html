DREFW specifies the water density at a reference pressure for each of the Nw water components.

The water component densities, at pressure P, are calculated from:

ρw =ρ refw ⋅(1+ X+X 2/2 )

X=c Pw ⋅(P-P ref w )

where

ρ refw is the reference density, specified with this keyword
c Pw is the water component compressibility, specified with keyword CREFW
P ref w is the reference pressure, specified with keyword PREFW

There should be one value for each component:

UNITS: kg/m3 (METRIC), lb/ft3 (FIELD), gm/cc (LAB), kg/m3 (PVT-M)

DEFAULT: 999.014 kg/m3

If multiple equations of state are being used, a set of data should be entered for each reservoir EoS. The number of reservoir equation of state regions is entered as NMEOSR in keyword TABDIMS. The use of multiple EoS regions is discussed in "Equations of state regions" in the ECLIPSE Technical Description.

See "Water components" in the ECLIPSE Technical Description for further details of the water component option.
