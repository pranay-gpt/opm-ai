This keyword controls the rate at which the solution gas-oil ratio is allowed to rise, with a separate value for each PVT region. The data comprises NTPVT (set in the TABDIMS) entries, each terminated by a slash (/). Each line of data corresponds to a single PVT region and has the same structure as the DRSDT keyword:

  1. The maximum rate at which the solution gas-oil ratio (Rs) in any grid block in the corresponding PVT region is allowed to increase.

    UNITS: sm3/sm3/day (METRIC), Mscf/stb/day (FIELD), scc/scc/hr (LAB)

    DEFAULT: 1020

  2. Option flag
    ALL Apply the limit to all cells in the corresponding PVT region
    FREE Apply the limit only to the region's cells which contain free gas

    DEFAULT: 'ALL'

In the same way as the DRSDT keyword operates, this keyword controls the way in which free gas and undersaturated oil coexist within a grid block. For example, if the first entry is set to 0, Rs cannot rise and free gas does not dissolve in undersaturated oil (no re-solution) in this PVT region. At the other extreme, if the first number of a particular region entry is very large, Rs rises very quickly until either the oil is saturated or no free gas remains (total re-solution).

If the keyword is not used, the resolution rate is unrestricted (equivalent to a resolution rate limit of infinity).

Note: Similar to DRSDT, this keyword has no effect on reductions in Rs (for example during pressure decline). Moreover increases in Rs are constrained by the availability of free gas and the oil saturation limit (Rssat).

If this keyword is used in a system containing both dissolved gas and vaporized oil, the application of the DRSDTR limit will be disabled by the subsequent use of the VAPPARS keyword. Similarly, the constraints imposed by the VAPPARS keyword will be disabled by the subsequent specification of the DRSDTR keyword.

If the first number of a PVT region entry is zero and the model contains undersaturated oil with a variation of Rs values in this region, then non-physical behavior can occur when high Rs oil moves in to a cell containing a lower Rs. The DRSDTR limit prevents the Rs increasing, and free gas develops, even though the oil is undersaturated. This behavior can be prevented by setting the option flag in item 2 to 'FREE' for this region. The limit then only applies to the two-phase regions. (Note that in this case gas flowing from a two-phase cell into an undersaturated cell will dissolve in the destination cell, as the Rs is allowed to rise.)
