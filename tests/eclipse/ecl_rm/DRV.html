SCHEDULE

This keyword specifies the size of the cells in the radial direction.

The keyword should be followed by up to NDIVIX positive real numbers, where NDIVIX is the grid radial dimension entered using the DIMENS keyword in the RUNSPEC section.

The Ith number specifies the size in the radial direction of all the grid blocks with the R axis index equal to I. In other words, blocks (I, 1- NDIVIY, 1- NDIVIZ).

DRV causes the DR value for every grid block in the reservoir to be set. Repeat counts may be used for repeated values (for example 11*208.4). Note that spaces must not be inserted on either side of the asterisk.

UNITS: m (METRIC), ft (FIELD), cm (LAB), m (PVT-M)

The data must be terminated by a slash (/).

Notes

  • The inner radius of the innermost column (I = 1) of grid blocks must be set. To do this, refer to the INRAD keyword, for ECLIPSE 100, and the RADFIN keyword, for ECLIPSE 300. These blocks has an outer radius equal to the sum of the inner radius and their DRV value.
  • If the outer radius is not entered (using the OUTRAD keyword in ECLIPSE 100), a complete set (NDIVIX) of DRV values must be entered. The outer radius of these blocks is equal to the sum of the inner radius and the accumulated DRV values.
  • If keyword OUTRAD is entered, it is not necessary to specify all (or any) DRV values. For ECLIPSE 100, any DRV values not specified are completed using a geometric series (see keyword OUTRAD).

    ECLIPSE 300

  • This keyword cannot be used to specify the grid data for a Local Grid Refinement (between the RADFIN and ENDFIN pair).

Example

With NDIVIX=11 as specified in RUNSPEC keyword DIMENS:
