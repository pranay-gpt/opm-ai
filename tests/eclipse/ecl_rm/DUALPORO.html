This requests that the dual porosity option is used in the run.

If either DUALPORO or dual permeability ( DUALPERM) are used, the number of layers entered in item 3 of the DIMENS keyword must be even. ECLIPSE interprets the first half of the grid layers as matrix cells, and the remainder as fracture cells. The non-neighbor connections representing matrix-fracture flow transmissibilities are automatically constructed.

See "Dual porosity" in the ECLIPSE Technical Description for further information.

The keyword has no associated data.
