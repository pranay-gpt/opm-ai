The DUMPFLUX keyword is used in the full-field run to tell ECLIPSE to write a Flux file containing the flows across the flux region boundaries.

The extent of the flux regions are defined by the FLUXNUM keyword.

The keyword has no associated data.

See "Flux boundary conditions" in the ECLIPSE Technical Description for further information about this option.

Notes for ECLIPSE 300

  • If the base run is either a Black oil or a Compositional model, and the reduced run is a Thermal model, then item 1 of the FLUXOPTS keyword must be used to tell ECLIPSE to output the necessary information for the reduced case. For a full field thermal to reduced thermal case, item 1 of the FLUXOPTS keyword is not required.
  • If the base run has a water phase present with water properties input with the PVTW keyword, it is possible to use the FLUX file on reduced runs with the Water Components option active. See the "Water components option" in the ECLIPSE Technical Description.
  • Thermal reduced runs and reduced runs with the Water Components option active can only be carried out from an ECLIPSE 300 base run.
