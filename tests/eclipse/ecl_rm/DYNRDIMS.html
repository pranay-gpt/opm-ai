This keyword determines the size of storage set aside for dynamic regions specified with the DYNAMICR keyword, and must be present if dynamic regions are to be specified.

The data consists of some or all of the following items.

The data must be terminated by a slash (/).

  1. The maximum number of dynamic regions (MNUMDR).

    If item 1 of REGDIMS or item 5 of TABDIMS are also set, the greatest value of the three settings is used.

    Note: Since the fluid-in-place balance sheet reports region-to-region flows, the storage required is proportional to the square of MNUMDR. Very large values of MNUMDR should therefore be avoided, as excessive storage may be required and in addition the restart files will be very large.

    DEFAULT: 0

  2. The maximum number of dynamic region families (MXDYNF).

    DEFAULT: 0

  3. The maximum number of dynamic region records which can be defined under the DYNAMICR keyword (MXDYNR).

    DEFAULT: 0

Example

DYNRDIMS
 5  2  10  /
