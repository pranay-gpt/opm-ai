This keyword specifies the size of the cells in the Z-direction.

The keyword should be followed by NDIVIZ positive real numbers, where NDIVIZ is the grid Z dimension entered using the DIMENS keyword in the RUNSPEC section.

The Kth number specifies the size in the Z-direction of all the grid blocks with a Z axis index equal to K. In other words, blocks (1- NDIVIX,1- NDIVIY, K). See the DIMENS keyword for the specification of NDIVIX and NDIVIY.

DZV causes the DZ value for every grid block in the reservoir to be set. Repeat counts may be used for repeated values (for example 11*208.4). Note that spaces must not be inserted on either side of the asterisk.

UNITS: m (METRIC), ft (FIELD), cm (LAB), m (PVT-M)

The data must be terminated by a slash (/).

Notes

This keyword must not be used to specify the grid data for a Local Grid Refinement (between the CARFIN / RADFIN and ENDFIN pair).

ECLIPSE 300

If DZ <= 10-6 for any cell, the cell will be either be made inactive or in thermal cases it may become rock-filled.
