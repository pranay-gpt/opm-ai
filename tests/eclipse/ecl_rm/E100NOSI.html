This keyword causes a switch to NOSIM mode if any ECLIPSE 100 keywords are encountered that are not recognized or are substantially different from their ECLIPSE 300 counterparts.

The simulator will also switch to NOSIM mode if it reads a non-default entry in an item that is not supported by ECLIPSE 300 in a keyword that is recognized by both simulators.
