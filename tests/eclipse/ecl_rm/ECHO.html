The keyword turns on the echoing of the input file to the Print file at the start of the run. This echoing may be disabled using NOECHO, for example when large machine generated input files are entered.

The default status for echoing is on, which may be set to off using NOECHO. ECHO is normally only required, therefore, to turn echoing back on after a NOECHO keyword.

ECHO and NOECHO may be specified in any section, and any number of times in an input file.
