The keyword activates the multi-component option in ECLIPSE 100. The keyword is required in runs using the multi-component brine model.

Note that the multi-component brine model is distinct from the standard brine option (latter specified using keyword BRINE without keyword ECLMC). Thus, functionality that is specific to the standard brine model, such as PLYVISCS, is not compatible with ECLMC.

The keyword has no associated data.

See "Brine tracking" in the ECLIPSE Technical Description.
