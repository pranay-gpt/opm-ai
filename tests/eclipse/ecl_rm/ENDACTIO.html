x SCHEDULE

The ENDACTIO keyword may only be used after an ACTION, ACTIONG, ACTIONR, ACTIONS , ACTIONW, ACTIONX or DELAYACT keyword has been entered. It indicates the end of the set of SCHEDULE section keywords associated with the preceding ACTION family keyword.

The set of keywords between the ACTION family keyword and ENDACTIO keyword are processed when the condition defined in the ACTION family keyword has been satisfied.

The ENDACTIO keyword has no associated data.
