The ENDBOX keyword has no associated data.

It causes the input box to be reset so that it encompasses the entire grid.

Note that at the end of each input section, the program effectively supplies an ENDBOX and resets the input box.

See also keywords BOX, ADD, COPY, EQUALS, MULTIPLY, MINVALUE and MAXVALUE.

Example

Thus, for an 11 by 19 by 4 grid, it has the same effect as:

BOX
1 11  1 19  1 4  /
