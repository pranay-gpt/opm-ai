SCHEDULE

Specify the equation of state to be used for the production system. This defaults to the equation of state used for the field, entered using keyword EOS.

The possible options are:

PR Peng-Robinson
RK Redlich-Kwong
SRK Soave-Redlich-Kwong
ZJ Zudkevitch-Joffe-Redlich-Kwong

Details of the equations of state are discussed in "Equations of state" in the ECLIPSE Technical Description.

If multiple equations of state are being used, an equation of state may be chosen for each surface EoS. The use of multiple EoS regions is discussed in "Equations of state regions" in the ECLIPSE Technical Description.

DEFAULT: Will follow the EOS keyword
