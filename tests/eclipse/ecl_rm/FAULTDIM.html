This keyword specifies the maximum number of segments of fault data entered with the FAULTS keyword in the GRID section.

The keyword should be followed by a single item of data, terminated by a slash (/).

  1. MFSEGS The maximum number of fault segments

    DEFAULT: 0

Example

FAULTDIM
3 /
