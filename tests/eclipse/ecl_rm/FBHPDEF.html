x SCHEDULE

The keyword is optional and is used to provide a default BHP (bottom hole pressure) target or limit values to be used where none is specified for a well.

The keyword should be followed by up to two positive real numbers:

  1. The target BHP for production wells.

    UNITS: barsa (METRIC), psia (FIELD), atma (LAB), atma (PVT-M)

    ECLIPSE 100

    DEFAULT: (production) 1 atma = 14.70 psia = 1.01 barsa

    ECLIPSE 300

    DEFAULT: (production, history matching) 1 atma = 14.70 psia = 1.01 barsa

    ECLIPSE 300

    DEFAULT: (production, other) 100 atma = 1469.59 psia = 101.32 barsa
  2. The limit BHP for injection wells.

    UNITS: barsa (METRIC), psia (FIELD), atma (LAB), atma (PVT-M)

    ECLIPSE 100

    DEFAULT: (injection) 6802.72 atma, or 1.0E5 psia, or 6891.16 barsa

    ECLIPSE 300

    DEFAULT: (injection, thermal) 200 atma = 2939.1 psia = 202.65 barsa

    ECLIPSE 300

    DEFAULT: (injection, CO2STORE) 592.15 atma=8702.18 psia = 600 bars

    ECLIPSE 300

    DEFAULT: (injection, all other cases) 1000 atma = 14695.9 psia = 1013.25 barsa

Either or both of these can be defaulted. Defaulting both is equivalent to not specifying the keyword.

All defaults stated are accurate to 2 decimal places.

The data must be terminated by a slash (/).

Notes

  • The values in this keyword are used purely when default values would otherwise be used to set up a well's control data, that is when no BHP target or limit value is set in one of the related keywords. Setting new default values with this keyword does not change existing control data for any well. It must be defined before the keyword to which it is to apply. To change an existing BHP limit, use WELTARG.
  • This keyword can be specified more than once: the new values will then be used with subsequent related keywords if a default BHP value is required.
  • The keywords for which the FBHPDEF production value will be used as the BHP limit if it is defaulted in the keyword are WCONPROD and WCONHIST.
  • The keywords for which the FBHPDEF injection value will be used as the BHP target if it is defaulted in the keyword are WCONINJE, WCONINJH and WCONINJP.

    ECLIPSE 100

  • The FBHPDEF injection value will also be used as the BHP target if it is defaulted in the obsolete WCONINJ keyword.
  • For the WCONINJH keyword, it is possible that a well may change to BHP control before its productivity index has been properly matched. If this happens, the default BHP limit value should be set to atmospheric pressure and the WELTARG keyword used subsequently to set the required BHP limit.
  • If the WCONINJH or WCONHIST keyword is respecified for an existing history matching well, the default BHP value is only reapplied if the limit was previously defaulted (in practice this means that BHP limit values set by WELTARG are preserved). For all other keywords, the default is always reapplied if no new BHP limit value is specified. This is true in general, not only when FBHPDEF has been used to specify a default value.

Example

This will set the default production well BHP limit to 250 and the default injection well BHP limit to 1500. These values will be used to set up the well control data if the BHP limit is defaulted in subsequent uses of one of the related keywords.

FBHPDEF
250 1500 /
