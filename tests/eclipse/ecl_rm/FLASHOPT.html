This keyword is used to set certain options in the flash. It contains the following data:

  1. Stability criteria ϵ .

    The flash code will look for a two–phase solution if the single phase solution is unstable. Instability is determined by calculating a term called the tangent plane distance (τ ), which is a measure of the change in energy when a small amount of a new phase is split off. The single phase is deemed unstable if the energy of the system is reduced, τ <0. Calculation of the tangent plane distance can be affected by rounding errors, so the calculated value of τ can sometimes be small and negative when the true value is small and positive. In these cases, one–phase cells will be misidentified as two–phase. The stability check can be made more robust by testing for τ <ϵ≤0 .

    There is a drawback of using ϵ <0. Some two-phase cells with genuinely small negative values of τ will now be misidentified as being one-phase. However the fluids in these cells should be very close to the phase boundary, so the error in this case will be small. Nevertheless it is important that only small negative values of ϵ should be used, −1×10 −8< ϵ≤0, otherwise the flash results will be unreliable.

    DEFAULT: 0.0
