This keyword sets optional parameters for the ECLIPSE 300 "Flux boundary conditions" option.

  1. Output to run a thermal reduced run.

    This item should be used in the full-field run to tell ECLIPSE whether the reduced run will be a thermal run or not.

    This item should be followed by one of the following values:

    YES

    The simulator will output the necessary information to run a thermal reduced run

    NO

    The simulator will not output the necessary information to run a thermal reduced run

    DEFAULT: NO

    Note: There is no need to use this item if the base run is thermal or there is no intention of running a thermal sector model from the base run.
  2. Factor to improve convergence.

    Convergence degradation might be observed as the molar density of a given component crossing the flux boundary approaches zero. In order to improve performance in such cases, this item should be used in the reduced run.

    If the simulation is experiencing convergence issues during a reduced run, you can set DEBUG3 item 8 to 1 to identify the cell with worst convergence. Use the summary vector BMLSC to assess if the convergence issues occur as a given component approaches zero. In such cases, this item can be used in the reduced run to improve its performance.

    By default, the boundary conditions are applied as a step function with a discontinuity when the molar density is zero. By using this item, the discontinuity will be replaced with a slope controlled by the input to the item. The actual value to be used is problem dependent. If the value is too high, the slope of the function around zero molar density might be too steep to avoid the convergence problems. If the value is too low, it might affect the solution.

    Note: The correction factor on the boundary condition triggered by this item is not applied on thermal sector models.

The data should by terminated by a slash (/).
