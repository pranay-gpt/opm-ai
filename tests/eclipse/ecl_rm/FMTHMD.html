SCHEDULE

Declares that the HMD output file, used by the ECLIPSE Gradient option, containing the derivatives is to be formatted.

The default is unformatted.

See "Gradient option" in the ECLIPSE Technical Description for further information.

The keyword has no associated data

For ECLIPSE 100, if an RFT gradients file .GRFT is produced, this is also formatted.
