This indicates that output files which may be either formatted or unformatted are to be formatted. This includes the SMSPEC, SUMMARY, GRID, INIT and RESTART files (see "File handling in ECLIPSE" in the ECLIPSE Technical Description).

The default is unformatted, as this reduces file size and processing time.

FMTOUT contains no items.

The format of ECLIPSE 300 SAVE files is controlled by a separate keyword, FMTSAVE.
