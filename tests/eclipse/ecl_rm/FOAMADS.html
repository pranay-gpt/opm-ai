The data comprises NTSFUN (set in the TABDIMS keyword) tables of foam adsorption functions, each terminated by a slash (/), describing the adsorption of foam by the rock formation. See "Foam model" in the ECLIPSE Technical Description for further information.

Each table consists of the following columns of data:

  1. The local foam concentration in the solution surrounding the rock. The values should increase monotonically down the column.

    If item 1 of FOAMOPTS is set to ‘GAS’:

    UNITS: kg/sm3 (METRIC), lb/Mscf (FIELD), gm/scc (LAB)

    If item 1 of FOAMOPTS is set to ‘WATER’:

    UNITS: kg/sm3 (METRIC), lb/stb (FIELD), gm/scc (LAB)

  2. The corresponding saturated concentration of foam adsorbed by the rock formation. These values should be level, or increase down the column.

    UNITS: kg/kg (METRIC), lb/lb (FIELD), gm/gm (LAB)

Each table must contain at least two, and no more than NSSFUN (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table.

CAUTION: The first row in the adsorption tables should consist of a pair of zeroes.

See also FOAMROCK, SURFADS, PLYADS, PLYADSS and ADSORP.
