The FOAMDCYO keyword inputs data describing the decay of foam as a function of oil saturation. See "Foam model" in the ECLIPSE Technical Description for further information.

The data comprises NTSFUN (set in the TABDIMS keyword) tables of foam decay data, each terminated by a slash (/). Each table consists of the following columns of data:

  1. The local oil saturation.

    The values should increase monotonically down the column.

  2. The corresponding decay half-life.

    UNITS: day (METRIC), day (FIELD), hr (LAB)

Each table must contain at least two, and no more than NSSFUN (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table.

Note that if the FOAMDCYW keyword is also present, the decay half-life is taken to be the minimum of the two values for each cell.

See also keywords FOAMDCYW and FOAMADS.

Example

With NTSFUN = 2 and NSSFUN = 3:

FOAMDCYO
--
-- Constant half-life
--
 0.0  12.0 
 1.0  12.0   /
--
-- Reduced half-life if oil is present.
--
 0.0  15.0
 0.1   5.0 
 1.0   5.0   /
