The FOAMDCYW keyword inputs data describing the decay of foam as a function of water saturation. See "Foam model" in the ECLIPSE Technical Description for further information.

The data comprises NTSFUN (set in the TABDIMS keyword) tables of foam decay data, each terminated by a slash (/). Each table consists of the following columns of data:

  1. The local water saturation.

    The values should increase monotonically down the column.

  2. The corresponding decay half-life.

    UNITS: day (METRIC), day (FIELD), hr (LAB)

Each table must contain at least two, and no more than NSSFUN (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table.

Note that if the FOAMDCYO keyword is also present, the decay half-life is taken to be the minimum of the two values for each cell.

See also keywords FOAMDCYO and FOAMADS.

Example

With NTSFUN = 2 and NSSFUN ≥ 2:

FOAMDCYW
--
-- Constant half-life
--
 0.0  15.0 
 1.0  15.0   /
--
-- Reduced half-life if water is present.
--
 0.0  15.0 
 1.0   5.0   /
