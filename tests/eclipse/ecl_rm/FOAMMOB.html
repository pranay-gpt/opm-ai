This keyword supplies tables of the gas phase mobility reduction factor as a function of foam concentration. The keyword is obligatory in runs using the foam model as described in "Foam model" in the ECLIPSE Technical Description.

The data comprises NTPVT (set in the TABDIMS keyword) tables of mobility reduction factors. Each table consists of two columns of data, terminated with a slash (/).

  1. The foam concentration.

    The values should increase monotonically down the column.

    If item 1 of FOAMOPTS is set to ‘GAS’:

    UNITS: kg/sm3 (METRIC), lb/Mscf (FIELD), gm/scc (LAB)

    If item 1 of FOAMOPTS is set to ‘WATER’:

    UNITS: kg/sm3 (METRIC), lb/stb (FIELD), gm/scc (LAB)

  2. The corresponding gas mobility reduction factor

Each table must contain at least two, and no more than NPPVT (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table.

Example

With NTPVT = 1 and NPPVT ≥ 5:

FOAMMOB
-- 
-- Concentration    Mobility factor
--
      0.00              1.0
      0.01              0.2
      0.015             0.1
      0.02              0.09
      0.025             0.09  /
