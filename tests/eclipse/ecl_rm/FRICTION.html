This keyword must be entered to enable the wellbore friction option (see "Wellbore friction option" in the ECLIPSE Technical Description). It specifies the maximum number of wells requiring the wellbore friction calculation, and (for multilateral wells) the maximum number of branches that can join within any single grid block connection.

The keyword should be followed by two items of data, terminated by a slash (/):

  1. NWFRIC The maximum number of wells requiring the wellbore friction calculation

    DEFAULT: 0

  2. NWFRIB The maximum number of branches, or flow streams, that may join together at a single connection (including the main stem). For example, if no more than one side branch joins the main stem within any grid block connection, the number should be set to 2.

    DEFAULT: 1 (describing a standard well, which has only a main stem)

FRICTION
 3  2 /
