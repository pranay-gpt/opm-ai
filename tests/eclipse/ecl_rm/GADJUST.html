This keyword specifies that the permeability tensor is assumed to be input as a diagonal tensor on the basis defined by the cell tangent vectors. It is supplied only for FrontSim compatibility.

This is equivalent to using item 2 in the TBASIS keyword as long as the off-diagonal coefficients, for example PERMXY, are zero.

See "Tensor permeability" in the ECLIPSE Technical Description for further information.
