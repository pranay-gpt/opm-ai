This keyword can only be used with the THERMAL option.

The data comprises NTPVT (set in the TABDIMS keyword) of gas phase component viscosities versus temperature for each pressure table. Each table consists of Ncomps +1 columns of data (described below), and is terminated by a slash (/).

  1. Temperature values.

    The values should increase monotonically down the column.

    UNITS: °C (METRIC), °F (FIELD), °C (LAB), °C (PVT-M)

  2. The corresponding values of gas component viscosity.

    The values should increase or stay level down the column.

    UNITS: cP (METRIC), cP (FIELD), cP (LAB), cP (PVT-M)

For temperature values outside the interval specified, constant value extrapolation is performed.

The gas phase viscosity is calculated as

μg =Σi=1 Ncomps +1 μgi Yi

where μ gi are the gaseous component viscosities and Yi are the component mole fractions in the gas phase.

Note: In a thermal CO2STORE run, values for the CO2STORE special components can be defaulted. They use gas viscosity values from the simulator's internal CO2 storage modeling. If additional oil and/or gas components are present, their values should be set.
