This keyword can be used to instruct ECLIPSE to read in just the global grid data from a restart file of a previous run that had local grids present. Any data for local grids on the restart file are ignored. This may be useful, for example, if the local grids are no longer needed in the restart run.

The keyword has no associated data.

ECLIPSE 100. If the restart run has any local grids present, then these are treated as being added at the restart time. The run is initialized by inheriting the solutions from the global host cells at the restart time.

Additional information can be found in “Switching refinements on and off” in the ECLIPSE Technical Description.
