The data comprises NTPVT (set in the TABDIMS keyword) tables of Gi values, each terminated by a slash (/), describing the nodal values for Gi to be used in the calculation of the oil and gas properties. Each table consists of up to NPPVT (set in the TABDIMS keyword) real entries.

The Gi nodal values within each table should be positive and strictly increasing.

UNITS: sm3/rm3 (METRIC), Mscf/rb (FIELD), scc/rcc (LAB)

The number of entries in each table must correspond to the number of multiplier values entered under each of the RSGI, RVGI, BGGI and BOGI keywords.

See "Gi Pseudo-compositional model" in the ECLIPSE Technical Description for further information.
