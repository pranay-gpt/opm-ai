The default gravity constant values are defined in the "Units" in the ECLIPSE Technical Description.

If this value needs to be overwritten, it can be done using the GRAVCONS keyword.

The data comprises one value terminated with a slash (/).

UNITS: m2bars/kg (METRIC), ft2psi/lb (FIELD), cm2atm/gm (LAB), m2atm/kg (PVT-M)

Example

GRAVCONS
 0.05/
