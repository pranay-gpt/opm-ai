This requests that gravity drainage and imbibition are modeled between the matrix and fracture cells in a dual porosity run.

If this option is used, then the vertical dimensions for blocks of matrix material should be entered with keywords DZMTRX or DZMTRXV in the GRID section.

See "Dual porosity" in the ECLIPSE Technical Description for further information. See also keyword GRAVDRM.

The keyword has no associated data.
