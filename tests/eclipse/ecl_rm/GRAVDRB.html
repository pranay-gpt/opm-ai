This keyword requests that the vertical discretized gravity drainage and imbibition model should be used. If this option is used, then the geometry of the matrix sub-cell specified by keyword NMATOPTS must be vertical.

See "Dual porosity" in the ECLIPSE Technical Description for further information.

The keyword has no associated data.

In ECLIPSE 100, with this model, the minimum value for the number of global cells in the X direction (keyword DIMENS) is 2.
