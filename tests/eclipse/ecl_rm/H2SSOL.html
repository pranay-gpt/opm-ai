This keyword turns on the H2S solution option. The H2S component is then allowed to exist in all three phases. This keyword cannot be used if directional saturation table end-point scaling is used (switched on by setting the first item of keyword ENDSCALE to DIRECT).

This keyword cannot be used with the THERMAL option.

For further information see "CO2/H2S solution in the aqueous phase" in the ECLIPSE Technical Description.
