This keyword can only be used with the THERMAL option.

HEATCR specifies the rock volumetric heat capacity value for each cell. Each keyword should be followed by NxNy Nz values in normal order, with the X index changing fastest.

UNITS: kJ/m3/K (METRIC), Btu/ft3/°R (FIELD), J/cc/K (LAB), kJ/m3/K (PVT-M)

See "Thermal option" in the ECLIPSE Technical Description for further information on this option.

Example

Set heat capacities for a 10*10 cross section, with two different rock types.

HEATCR
