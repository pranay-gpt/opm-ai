This keyword can only be used with the THERMAL option.

HEATCRT specifies the temperature dependence of the rock volumetric heat capacity value for each cell.

The enthalpy per unit volume of rock in each cell is calculated as

H rock=CR0(T-T ref)+CR1( T-Tref)2 2

where C R0 is given by the HEATCR keyword and C R1 is given by the HEATCRT keyword.

Each keyword should be followed by NxN yNz values in normal order, with the X index changing fastest.

UNITS: kJ/m3/K2 (METRIC), Btu/ft3/°R2 (FIELD), J/cc/K2 (LAB), kJ/m3/K2 (PVT-M)

See "Thermal option" in the ECLIPSE Technical Description for further information on this option.
