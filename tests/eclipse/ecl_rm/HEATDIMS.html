This keyword can only be used with the THERMAL option (see "Thermal option" in the ECLIPSE Technical Description).

The data consists of the item, describing the dimensions of the heater data to be used in the run. The heater data for each connection should be defined using keyword HEATER or keyword HEATERL.

  1. The maximum number of heater connections

    DEFAULT: 1
