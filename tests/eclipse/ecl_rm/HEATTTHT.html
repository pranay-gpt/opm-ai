This keyword can only be used with the THERMAL option.

HEATTTHT specifies the thermal transmissibility values in the azimuthal direction, for runs using radial geometry.

Each keyword should be followed by NrN θNz values in natural order.

UNITS: kJ/day/K (METRIC), Btu/day/°R (FIELD), J/hr/K (LAB), kJ/day/K (PVT-M)
