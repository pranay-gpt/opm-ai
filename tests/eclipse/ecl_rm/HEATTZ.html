This keyword can only be used with the THERMAL option.

HEATTZ specifies the thermal transmissibility values in the Z direction, replacing those calculated by the program.

The thermal transmissibilities are entered as a number for each grid cell - that is   NxNy Nz in all, in normal grid order with the X-index changing fastest. The thermal transmissibility is that between a cell and its neighbor in the positive direction.

UNITS: kJ/day/K (METRIC), Btu/day/°R (FIELD), J/hr/K (LAB), kJ/day/K (PVT-M)
