This keyword applies multipliers to properties determining the performance of the Carter-Tracy aquifer defined in keyword AQUCT. It is intended to be used as a modifier on the base data specified in the AQUCT keyword during history matching.

The keyword should be followed by a number of records defining the aquifers and multipliers for each aquifer.

The set of records must end with a single line containing only a slash (/). The set of records must be terminated with a blank record containing just a slash.

Each record refers to a separate Carter-Tracy aquifer, and contains the following items of data:

  1. Aquifer identification number

    The identification number is specified in AQUCT item 1.

  2. Multiplier on aquifer permeability.

    DEFAULT: 1.0

  3. Multiplier on aquifer angle of influence.

    DEFAULT: 1.0

  4. Multiplier on aquifer depth

    DEFAULT: 1.0

See also the HMAQUCT keyword.
