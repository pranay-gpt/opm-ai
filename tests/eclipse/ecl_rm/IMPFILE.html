This keyword enables values such as porosities and permeabilities to be imported from an INIT file. The keyword contains two records, each terminated by a slash (/).

The first record contains the filename, where the extension of the file specifies the type and format of the file.

There are currently two choices of file name extensions:

  • INIT binary input
  • FINIT formatted input (ASCII)

The file must be in a format as given by output from an ECLIPSE simulation.

The second record contains the list of arrays to be read.

The keyword can be used for fast initialization of the grid arrays. This is especially useful when running SECTOR models.

Note: In order to obtain the correct information from the INIT file, this keyword also requires the grid file. The EGRID file, if present, is used in preference to the GRID file.

Example

-- Import from OLDCASE.INIT
IMPFILE
  'OLDCASE.INIT' /
  PORO PERMX PERMY PERMZ /
