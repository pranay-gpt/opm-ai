The keyword should be followed by the name of a file from which input is to be taken. This file will be opened, and read to the end of the file unless an ENDINC keyword is encountered. The file is then closed, and input resumed from the main file, starting from the next keyword after the INCLUDE keyword.

The INCLUDE file name may have up to 132 characters.

The data should be terminated by a slash (/).

Nested INCLUDE files are possible.

INCLUDE files have restrictions when used in the RUNSPEC section.
