This keyword requests that an Initial Index file should be written to describe the arrays in the INIT file. By default, an Initial Index file is always written, but this can be disabled by using the NOINSPEC keyword.

See "File handling in ECLIPSE" in the ECLIPSE Technical Description.

The keyword has no associated data.
