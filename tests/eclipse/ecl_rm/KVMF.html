KVMF specifies the mole fractions of the nominated component at which K-value tables are available. The interpolation component is specified using the KVCOMP keyword.

The number of K-value tables and hence the number of values required by this keyword is set with 24th item in the TABDIMS keyword in the RUNSPEC section. Values must lie in the interval [0,1] and be monotonically increasing.
