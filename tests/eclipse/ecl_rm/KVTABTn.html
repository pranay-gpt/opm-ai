The keyword family KVTABTn (where n is an integer between 1 and 9) enables K-values to be entered to control liquid-vapor phase equilibrium at the temperature Tn, corresponding to the nth value specified in the KVTEMP keyword.

These keywords can only be used with the THERMAL option.

KVTABTn is a pressure table, and it is possible to enter more than one table; these can be assigned to cells using the PVTNUM keyword in the Regions section.

The table has Ncomps +1 columns, where Ncomps is the number of components in the run. The first column is of pressure values, the remaining columns are the K-values for each component at these pressures. The K-values should be positive and greater than 10-20.

Column 1 The oil phase pressure.

Values should increase monotonically.

UNITS: barsa (METRIC), psia (FIELD), atma (LAB), atma (PVT-M)
The following Ncomps columns

The corresponding K-values for each component. All values should be greater than 10-20.

The K-value for component c is K c=yc /xc , where y c and xc are mole fractions of component c in vapor and liquid phases respectively.

If temperatures are encountered that are less than T1, then the K-value is linearly extrapolated to 0 at an absolute temperature of 0.

See also keyword KVTEMP.

Notes

  • Thermal simulation stability can be affected by the pressure spacing with this keyword. It is recommended that equal intervals are used between the pressures.
  • There may be convergence problems in the thermal flash if all the K-values in a row are 1.
  • When performing compositional calculations per EOS region, if the PVT, saturation and EOS region allocation is not the same, which PVT and saturation table is to be used is poorly defined. It will be assumed that the region sets are the same, so the table used will correspond to the EOS number (with 1 used for EOS regions beyond the number of PVT or saturation regions). Item 381 of the OPTIONS3 keyword can be set to 1 to always use table 1 for EOS region-based separator calculations.
