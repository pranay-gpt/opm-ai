This keyword is specific to the coal bed methane option.

The data comprises NTCREG (see keyword REGDIMS, item 6) tables of Langmuir isotherm data for the solvent component, each terminated by a slash (/). Each table consists of the following columns of data:

  1. The fracture pressure.

    Values should increase monotonically down the column.

    The pressure used to look up the adsorption capacity is scaled with the coal grid cell LANGMPL values if this keyword is present.

    UNITS: barsa (METRIC), psia (FIELD), atma (LAB), atma (PVT-M)

  2. The corresponding surface solvent concentration.

    Values should be level or increasing down the column.

    UNITS: sm3/m3 (METRIC), Mscf/ft3 (FIELD), scc/cc (LAB)

Each table must contain at least two, and no more than NSSFUN (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table.

The entire table may be defaulted, provided the table is not the first. Defaulted tables are replaced with a copy of the previous table.

The coal region number COALNUM is used to look up the table.

If item 180 in OPTIONS is activated, the number of tables should equal NTSFUN (set in the TABDIMS keyword) and the region keyword SATNUM is used to look up the table.

See also the LANGMUIR and COALADS keywords and "Coal bed methane model" in the ECLIPSE Technical Description for further information.

With NTCREG = 2 and NSSFUN = 7
