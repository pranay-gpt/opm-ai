ECLIPSE 100

This keyword may optionally be used to reserve ECLIPSE 100 option FLEX licenses at the beginning of the run, rather than waiting until a keyword activating the option is encountered. For certain options the activating keyword is not encountered until the SCHEDULE section, perhaps part way through a run, and it is possible that the run could be stopped at that point if an appropriate license is not available.

The data consists of one or more records, each containing the name of an ECLIPSE 100 option terminated by a slash (/). The set of records must be terminated by a blank record containing just a slash.

The option names are:

Table 247.738.1.1 LICENSES options
LICENSES option ECLIPSE option
'eclipse4d' The Petro-elastic Model
'friction' The Wellbore Friction Model
'gasfield' Gas Field Operations Model
'gaslift' Gas Lift Optimization
'lgr' Local Grid Refinement and Coarsening
'multisegwells' Multisegment Wells
'networks' The Network Option
'unencodedhmd' Allow unencoded sensitivities output from the Gradient option.

Each option name can be in upper or lower case, and must be spelled out fully. Abbreviations are not recognized.

For the 2014.1 release of ECLIPSE, a number of license options were retired. If the LICENSES keyword is used with the following options, a warning message will be issued advising that the option has been retired.

  • CO2 Storage
  • Coal Bed Methane Model
  • Environmental Tracers
  • Flux Boundary Conditions
  • Foam Model
  • Gas Calorific Value Control
  • Polymer Flood Model
  • Gi Pseudo-Compositional Model
  • Solvent Model
  • Surfactant Model

ECLIPSE 300

This keyword is used to tell the simulator whether to use an ECLIPSE-specific license or a shared license, for thermal and compositional licenses only.

The data consists of one record containing the name of an ECLIPSE 300 thermal or compositional license type terminated by a slash (/). Additional records will be ignored (and are allowed only for compatibility with ECLIPSE 100). The set of records must be terminated by a blank record containing just a slash.

The option names are:

Table 247.738.2.1 LICENSES options
LICENSES option ECLIPSE behavior
'compositional' Use an ECLIPSE compositional license
'sim_compositional' Use a shared simulator compositional license
'thermal' Use an ECLIPSE thermal license
'sim_thermal' Use a shared simulator thermal license

Each option name can be in upper or lower case, and must be spelled out fully. Abbreviations are not recognized.

Inappropriate requests, such as a thermal license for a non-thermal dataset, will be ignored.

All other ECLIPSE 300 license types are determined by the dataset contents and will be ignored by ECLIPSE 300 if entered in this keyword.

If this keyword is not present, or does not contain a valid option name in the first record, the appropriate ECLIPSE (i.e. not shared) license will be used. If a shared license is requested but not found, an ECLIPSE license will not be used instead and the run will fail.

Note: This keyword is used (in addition to the dataset contents) by the Simulation launchers to work out which licenses are used in order to implement the license aware job scheduling for ECLIPSE 100 and ECLIPSE 300. Please refer to the appropriate documentation in the ECLIPSE distribution, which details which license names are supported.

Example (E100)

LICENSES
 'networks' /
 'lgr' /
 'friction' /
/
