The ECLIPSE simulators use dynamic memory allocation and so this keyword is not needed in any dataset. It is recommended that you do not use it and remove it from any datasets that contain it.

The keyword is ignored by ECLIPSE 300. It contains two integers:

  1. Unused.
  2. A fixed amount of character memory in thousands of CHARACTER*8 strings.

    The simulation stops with an error if this memory allocation is exceeded.

    DEFAULT: in ECLIPSE 100 the character storage is allocated to an adequate value at run time.
