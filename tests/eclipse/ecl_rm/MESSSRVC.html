The keyword is optional and is used to activate and deactivate the message service output. It has one argument.

  1. ON

    Message service output is produced.

    OFF

    Message service output is not produced.

    DEFAULT: ON

The data must be terminated by a slash (/).

Notes

  • When message service output is turned on, runs will generate a .dbprtx file. This is a database file containing all output messages and associated metadata. It is not intended to be human-readable. Petrel RE 2016.1 onwards will use this file to enable users to automatically annotate line charts using the results charting and analysis tool, allowing the user to quickly understand changes in development strategy and how they affect the reservoir. A simple reader tool for the .dbprtx file may be found in the ECLIPSE installation area under the tools/SimulatorMessageSearch directory.
  • Additional well and connection messages will also be generated in order to improve visualisation of well events in Petrel. These will be output to both the dbprtx and PRT files. If these messages are not required, their output can be turned off by setting item 278 of the OPTIONS keyword to 1 in ECLIPSE 100, or item 355 of the OPTIONS3 keyword to 1 in ECLIPSE 300.

Example

This will turn the message service output off.

MESSSRVC
OFF /
