The keyword should be followed by an integer.

The possible values are:

  1. Control of the MSG file output
    0 A minimal MSG file is produced only containing those messages produced before the reading of this keyword.
    1 A full MSG file is produced.

    DEFAULT: 1

The data must be terminated by a slash (/).

If the MSGFILE keyword is not used, then by default, a MSG file is produced.

The message file feature is provided primarily for use by post-processors. Consult the print file for the full context of the messages produced.

Example

MSGFILE
0 /
