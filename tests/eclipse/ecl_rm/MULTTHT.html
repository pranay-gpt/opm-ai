The keyword is used in radial geometry and is analogous to MULTY in Cartesian geometry.

The keyword should be followed by one non-negative real number for every grid block in the current input box. The data must be terminated by a slash (/).

The values specified act as multipliers on the transmissibilities calculated by the program for the +Theta faces of each grid block.

Thus, a value of MULTTHT specified for block (I, J, K) multiplies the transmissibility between blocks (I, J, K) and (I, J+1, K).

Any MULTTHT values that are not specified when the end of the GRID section is reached, default to 1.0.

Grid blocks are ordered with the R axis index cycling fastest, followed by the theta and Z axis indices. Repeat counts may be used for repeated values (for example 115*0). Note that spaces must not be inserted on either side of the asterisk.

In ECLIPSE 100, MULTTHT can also be used in the EDIT section.

Note: For ECLIPSE 100 compatibility when using ECLIPSE 300, the SCHEDULE section keyword MULTTTHT has been aliased to MULTTHT. However, MULTTTHT can still be used in the SCHEDULE section as documented in previous releases.

See also keyword MULTTHT-.
