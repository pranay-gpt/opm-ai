In a dual porosity or dual permeability run (keywords DUALPORO or DUALPERM in the RUNSPEC section) the permeability values for the fracture cells are normally multiplied by the fracture porosity to yield a net bulk fracture permeability.

If the NODPPM keyword is used this operation is suppressed, so that you must enter net bulk permeability values directly.

This keyword has no associated data.
