Unless this keyword is specified, the program produces a file containing a definition of the grid geometry, to be used for graphical output.

If the NOGGF keyword is used then no GRID file of either form is output by ECLIPSE 300. ECLIPSE 100 will produce the file(s) requested in the GRIDFILE keyword if it appears in the dataset after the NOGGF keyword.

This keyword has no associated data.

See also keyword GRIDFILE and "File handling in ECLIPSE" in the ECLIPSE Technical Description.
