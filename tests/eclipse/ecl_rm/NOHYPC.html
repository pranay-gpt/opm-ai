This keyword suppresses the use of the hysteresis option in capillary pressure calculations. It is now strongly recommended to control this option using the item 5 of the EHYSTR keyword.

If the hysteresis option is selected using the HYST keyword, either HYPC or NOHYPC must be used.

This keyword has no associated data.
