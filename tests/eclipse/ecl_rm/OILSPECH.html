This keyword can only be used with the THERMAL option.

OILSPECH applies to runs where the DEADOIL keyword has been specified in the RUNSPEC section.

OILSPECH specifies the oil specific heat for each pressure table. A data record is entered for each pressure table, each record containing one item:

  1. The oil specific heat

    UNITS: kJ/kg/K (METRIC), Btu/lb/°R (FIELD), J/gm/K (LAB), kJ/kg/K (PVT-M)

    DEFAULT: 0.0

Example

OILSPECH
-- In Field units
0.5 /
