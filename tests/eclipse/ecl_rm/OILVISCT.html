This keyword can be used with either the Black-oil temperature option or the Compositional Thermal option to specify the temperature dependence of the oil phase viscosity. The way the keyword is used is discussed separately for each option in the next two sections, since there are some slight differences.

The interpolation method for the OILVISCT data can be specified with the OILVTIM keyword.

Temperature option

The Temperature option can be used in either ECLIPSE 100 or ECLIPSE 300; see keyword TEMP. When the OILVISCT keyword is used with the temperature option the VISCREF keyword should be specified to supply the reference conditions for the oil viscosity.

The data comprises NTPVT (set in the TABDIMS keyword) tables of oil component viscosities versus temperature for each pressure table. Each table consists of two columns of data (described below), and is terminated by a slash (/).

Column

  1. Temperature values.

    The values should increase monotonically down the column.

    UNITS: °C (METRIC), °F (FIELD), °C (LAB), °C (PVT-M)

  2. The corresponding values of oil viscosity.

    The values should decrease or stay level down the column.

    UNITS: cP (METRIC), cP (FIELD), cP (LAB), cP (PVT-M)

    Each table must contain at least two, and no more than NPPVT (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table.

The values of oil viscosity in the OILVISCT keyword are assumed to be at the reference pressure and Rs value given in the VISCREF keyword. The oil viscosity at the prevailing pressure and Rs is calculated as follows:

μo=μT⁡(T) μp (P,R s) μp ⁡( Pref  ,R s ref ) [Eq. 247.1]

where

μ T Viscosity from the OILVISCT keyword.
μ p Viscosity from the PVTO (or PVDO) keyword.
P ref  Reference pressure from the VISCREF keyword.
R s ref  Reference Rs from the VISCREF keyword.

See "Temperature option" in the ECLIPSE Technical Description.

ECLIPSE 100

Note: ECLIPSE 100 linearly interpolates the reciprocal of the oil viscosities between data points, rather than the values themselves.

ECLIPSE 300

Note: The interpolation method used to obtain oil viscosities between data points can be set with the OILVTIM keyword. By default oil viscosities are linearly interpolated between data points.

ECLIPSE 300 Thermal option

The Thermal option can only be used in ECLIPSE 300; see keyword THERMAL. Either this keyword or OILVISCC or OILVISCF or THANALV should be specified to determine the oil viscosity. Keyword VISCREF is optional and is only needed if a pressure dependence is required, as discussed below.

The data comprises NTPVT (set in the TABDIMS keyword) of oil component viscosities versus temperature for each pressure table. Each table consists of Ncomps +1 columns of data (described below), and is terminated by a slash (/).

Column 1  Temperature values.

 The values should increase monotonically down the column. 

UNITS: °C (METRIC), °F (FIELD), °C (LAB), °C (PVT-M)
Columns 2 to Ncomps +1    The corresponding values of oil component viscosity.

The values should decrease or stay unchanged down the column. 

UNITS: cP (METRIC), cP (FIELD), cP (LAB), cP (PVT-M)

Each table must contain at least two, and no more than NPPVT (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table.

The oil phase viscosity is calculated from the component viscosities:

μo=μT(T) =Πi⁢= 1 Nc omps μoi fi(xi) [Eq. 247.2]

where

μ oi are the component viscosities
x i are the component mole fractions in the oil phase
fi (xi) are the viscosity indices defined by the OILVINDX keyword.

For temperature values outside the interval specified, constant value extrapolation is performed.

If both the PVCO and VISCREF keywords are specified, a pressure dependence modifies the temperature dependent viscosities described above. The oil viscosity at the prevailing pressure is then calculated as follows:

μo=μT⁡(T) μp ⁡(P) μ p⁡(Pr ef) [Eq. 247.3]

where

μ T Viscosity from this keyword.
μ p Viscosity from the PVCO keyword.
P ref The reference pressure defined by the VISCREF keyword.

See "Thermal option" in the ECLIPSE Technical Description.

Note: Oil viscosity in the DEADOIL option cannot be lower than 0.1 cP. It will be reset to 0.1 cP.
Note: In a thermal CO2STORE run, values for the CO2STORE special components can be defaulted. If additional oil and/or gas components are present, their values should be set. For all components, all values for that component in all tables must be defaulted. Individual defaulted values are not permitted.
