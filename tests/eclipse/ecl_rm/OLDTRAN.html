The use of OLDTRAN implies that transmissibilities are calculated from cell DX (or DR), DY (or DTHETA) and DZ values, without reference to corner point positions. This does not permit the automatic calculation of geological fault non-neighbor transmissibilities, but allows back-compatibility with existing simulation codes using block center transmissibility calculations.

OLDTRAN has no associated data.

This is the default type of transmissibility calculation for grids specified using the DX (or DR), DY (or DTHETA) and DZ keywords.

(See also keywords NEWTRAN and OLDTRANR.)
