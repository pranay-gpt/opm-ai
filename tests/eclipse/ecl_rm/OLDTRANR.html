The use of OLDTRANR implies that transmissibilities are calculated from cell DX (or DR), DY (or DTHETA) and DZ values, without reference to corner point positions. This does not permit the automatic calculation of geological fault non-neighbor transmissibilities, but allows back-compatibility with existing simulation codes using block center transmissibility calculations.

See also the keywords OLDTRAN and NEWTRAN.

The calculation of transmissibility when OLDTRANR is specified is slightly different from the calculation used with OLDTRAN. See "Transmissibility calculations" in the ECLIPSE Technical Description for a description of the formulae used for Cartesian calculations.

OLDTRANR has no associated data.
