In compositional runs, the program supplies a default value of the equation of state Ω a coefficient. However, should you wish to modify this value, the OMEGAA keyword may be used. Note that only small variations around the default value are advisable and that the default value will only be modified if the user-defined value is larger than 0. A separate value may be specified for each component.

If multiple equations of state are being used, a set of data should be entered for each reservoir EoS. The number of reservoir equation of state regions is entered as NMEOSR in keyword TABDIMS. The use of multiple EoS regions is discussed in "Equations of state regions" in the ECLIPSE Technical Description.

DEFAULT: Peng-Robinson: 0.457235529, RK, SRK and ZJ: 0.4274802
