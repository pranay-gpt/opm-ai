OPTIMIZE section

Note: The OPTIMIZE section is for use only with ECLIPSE 300.

The OPTIMIZE section header must not be specified in an included file.

The OPTIMIZE section is used to define the main components of an optimization loop:

  • The objective function
  • The parameters to vary to maximize the objective function
  • Constraints to observe during the optimization
  • Optimization tuning parameters, and reporting options.

The use of the above specifications is described in "Optimization" in the ECLIPSE Technical Description.
