This keyword is used to declare a threshold orthogonality error for interfaces in the X-direction to employ nine-point transmissibilities whenever the MPFA keyword is used to select the nine-point MPFA scheme.

See "Tensor permeability" in the ECLIPSE Technical Description for further information.

The keyword should be followed by a single positive real number, the dimensionless minimum orthogonality error in order to calculate nine-point transmissibilities for an X-direction interface.

DEFAULT: 0.000000

The data must be terminated by a slash (/).

The keyword causes any interfaces in the X-direction cell with an orthogonality error less than the input value to use the normal five-point transmissibilities.

Example

ORTHERRX
0.001 /
