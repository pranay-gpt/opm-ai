In a run with Ncomps components, this keyword associates a critical pressure with each component.

The keyword should be followed by Ncomps values.

If multiple equations of state are being used, a set of data should be entered for each reservoir EoS. The number of reservoir equation of state regions is entered as NMEOSR in keyword TABDIMS. The use of multiple EoS regions is discussed in "Equations of state regions" in the ECLIPSE Technical Description.

UNITS: barsa (METRIC), psia (FIELD), atma (LAB), atma (PVT-M)

DEFAULT: There are no component-wise default values. You are recommended not to default these to the internal default value.

Note: When using the CO2STORE option, the special components have specific internal values and any values specified for them in this keyword will be ignored.
