This keyword sets viscosities to be calculated using the Pedersen method rather than the default Lorentz-Bray-Clark method. For information on these methods, refer to "The Pedersen method" and "The Lorentz-Bray-Clark method" in the ECLIPSE Technical Description.

There is no data associated with this keyword.

Note: The coefficients used in the mixture molecular weight calculation, which forms part of this viscosity correlation, may be modified by multiplicative tuning parameters specified using either the PEDTUNE or the PEDTUNER keywords.

Example

PEDERSEN
