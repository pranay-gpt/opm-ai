The data consists of two items, describing the number of regions and the maximum table lengths. The tables are entered in the PROPS section by keywords PEKTABx and PEGTABx.

The data consists of two integers terminated by a slash (/).

  1. The number of regions to be entered in the PENUM keyword.

    DEFAULT: 0

  2. The maximum number of pressure points in each table for keywords PEKTABx and PEGTABx.

    DEFAULT: 0
