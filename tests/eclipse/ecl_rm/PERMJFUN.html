This keyword specifies user-defined permeability values which can be used in the Leverett J-function option by setting the permeability direction to U in the JFUNC or JFUNCR keywords.

The keyword should be followed by one real number for every grid block in the current input box specifying the user-defined permeability. Permeability values must be non-negative. The data must be terminated by a slash (/).

UNITS: mD (METRIC), mD (FIELD), mD (LAB), mD (PVT-M)

Grid blocks are ordered with the X axis index cycling fastest, followed by the Y and Z axis indices. Repeat counts may be used for repeated values (for example 115*208.4). Note that spaces must not be inserted on either side of the asterisk.

Note: If the user-defined permeability is specified for only some of the grid blocks, the default directional permeability will be used to calculate the J-function for the others.
