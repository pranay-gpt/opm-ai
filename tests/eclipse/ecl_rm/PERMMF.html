The PERMMF keyword is followed by a value for each matrix cell. Nx⋅Ny ⋅N z/2 values are required in all, in normal grid order with the X-index changing fastest.

UNITS: mD (METRIC), mD (FIELD), mD (LAB), mD (PVT-M)

Example

-------- IX1-IX2 JY1-JY2 KZ1-KZ2
BOX
          11  14   3   8   6   6   /
PERMMF
 8*0.5 16*0.66 /
ENDBOX
