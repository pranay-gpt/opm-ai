x SCHEDULE

This keyword controls the calculation of the generalized pseudo-pressure option for modeling the effects of condensate drop-out on the fluid mobilities at producing well connections (see "Special inflow equations" in the ECLIPSE Technical Description). The PICOND keyword is optional; if this is not specified, the default values specified below are applied in its absence.

The GPP option can be activated for individual wells by entering GPP in item 8 of the WELSPECS keyword or item 9 of the WELSPECL keyword. In ECLIPSE 300, the option may also be activated for all wells by entering the PSEUPRES keyword. Alternatively the WPICOND keyword can be used to combine the functions of the PICOND and PSEUPRES keywords and to provide control over the GPP calculation on a per well basis.

The keyword should be followed by some or all of the following data items, terminated with a slash (/).

  1. The maximum interval between pressure quadrature points below the dew point pressure to be used in the construction of the generalized pseudo-pressure integral table.

    UNITS: bars (METRIC), psi (FIELD), atm (LAB), atm (PVT-M)

    DEFAULT: 4 x atmospheric pressure.

    Note: The interval size used in the construction of the table may differ slightly from the value specified here in order to ensure a set of equally spaced points.
  2. The maximum interval between pressure quadrature points above the dew point pressureto be used in the construction of the generalized pseudo-pressure integral table.

    ECLIPSE 100

    If a zero or negative quantity is entered, the quadrature points are the same as the pressure points input in the PVTG table.

    UNITS: bars (METRIC), psi (FIELD), atm (LAB), atm (PVT-M)

    ECLIPSE 100

    DEFAULT: 0.0

    ECLIPSE 300

    DEFAULT: 10 x atmospheric pressure

    Note: The interval size used in the construction of the table may differ slightly from the value specified here in order to ensure a set of equally spaced points.
  3. Blocking factor damping coefficient Df.

    This value must lie between 0.0 and 1.0 and provides a means of damping any oscillations that may result from the explicit calculation of the blocking factor β by averaging it with its value from the previous timestep according to the formula βused=Dfβcurrrent+(1-Df)βprevious.

    DEFAULT: 1.0

    Note: If a value of zero is specified for the damping coefficient, this will result in the blocking factors remaining constant at the previously calculated values for all well connections. If this keyword is specified at the start of the simulation prior to any calculation of the blocking factors, the blocking factors will be calculated once and these values will be used as the constant values.

    ECLIPSE 300

  4. Include velocity dependent relative permeability (VDRP) and Forchheimer effects in the pseudo-pressure calculation.

    Either YES or NO.

    DEFAULT: NO

    If this data item is set to YES, capillary number VDRP and Forchheimer effects will be included in the pseudo-pressure calculation according to the VDRP options selected via the VELDEP keyword. The properties of the capillary number and Forchheimer models are specified via the keywords VDKRO, VDKRG and VDKRGC.

    ECLIPSE 300

  5. The multiplicative factor Fl which determines the lower pressure bound Pl to be used in construction of the generalized pseudo-pressure integral table.

    This is expressed as a multiplier upon the current pressure Pb of the grid block containing the well connection, that is, Pl=FlPb.

    This lower bound is the base pressure described in "Generalized pseudo-pressure in ECLIPSE 300" in the ECLIPSE Technical Description. The lower bound should be chosen such that the required range of cell and well pressures will be covered by the pseudo-pressure integral table.

    This is a dimensionless value which must lie between 0.0 and 0.95. This lower limit used will be constrained to the minimum of the value specified and the saturation pressure.

    DEFAULT: 0.0

    ECLIPSE 300

  6. The multiplicative factor Fu which determines the upper pressure bound Pu to be used in construction generalized pseudo-pressure integral table.

    This is expressed as a multiplier upon the current pressure Pb of the grid block containing the well connection, that is, Pu=FuPb.

    This upper bound should be chosen such that the required range of cell and well pressures will be covered by the pseudo-pressure integral table.

    This is a dimensionless value which must lie between 1.05 and 2.0.

    DEFAULT: 1.1

    ECLIPSE 300

  7. Change in water saturation in the grid block containing the well connection which will result in a recalculation of the generalized pseudo-pressure integral table.

    By default this change is treated as the magnitude of the difference between the current value and the value when the table was previously calculated. This change may alternatively be treated as a fractional value, that is, the magnitude of the difference between the current and previous values normalized by the previous value, if item 330 of the OPTIONS3 keyword is set to 2. In addition, this recalculation control may be disabled by specifying a negative value.

    DEFAULT values:

    • DEFAULT (with OPTIONS3 item 330 = 0): 0.01

      The test is applied to the magnitude of the difference between the current and previous values.

    • DEFAULT (with OPTIONS3 item 330 = 1): 0.1

      For the pre-2015.1 version, the test is applied to the magnitude of difference between the current and previous values normalized by the previous value.

    • DEFAULT (with OPTIONS3 item 330 = 2): 0.1

      The test is applied to magnitude of difference between current and previous values normalized by the previous value.

    ECLIPSE 300

  8. Change in saturation or grid block pressure in the grid block containing the well connection which will result in a recalculation of the generalized pseudo-pressure integral table.

    By default, this change is treated as the magnitude of the difference between the current value and the value when the table was previously calculated is applied to both decreasing and increasing pressures. This change may alternatively be treated as a fractional value, that is, the magnitude of the difference between the current and previous values normalized by the previous value, if item 330 of the OPTIONS3 keyword is set to 2. In addition, this recalculation control may be disabled by specifying a negative value.

    DEFAULT values:

    • DEFAULT (with OPTIONS3 item 330 = 0): 1.0 x atmospheric pressure.

      The test is applied to the magnitude of the difference between the current and previous values for increasing and decreasing pressures.

      UNITS: bars (METRIC), psi (FIELD), atm (LAB), atm (PVT-M)

    • DEFAULT (with OPTIONS3 item 330 = 1): 0.1

      For the pre-2015.1 version, the test is applied to the difference between the current and previous values normalized by previous value for decreasing pressures. An increasing pressure will trigger a recalculation.

    • DEFAULT (with OPTIONS3 item 330 = 2): 0.1

      The test is applied to the magnitude of the difference between the current and previous values normalized by the previous value for increasing and decreasing pressures.

    ECLIPSE 300

  9. Fractional change in composition (of any component) in the grid block containing the well connection which will result in a recalculation of the generalized pseudo-pressure integral table, that is, for any component, the difference between the current value and the value when the table was previously calculated normalized by the previous value.

    This recalculation control may be disabled by specifying a negative value.

    DEFAULT: 0.01

    ECLIPSE 300

  10. Maximum simulation time change between recalculation of generalized pseudo-pressure integral table.

    This recalculation control may be disabled by specifying a negative value.

    UNITS: day (METRIC), day (FIELD), hr (LAB), day (PVT-M)

    DEFAULT: -1 (that is, no maximum simulation time change limit imposed)

    ECLIPSE 300

  11. Adaptive ordinate control.

    A positive value specifies that a set of adaptively spaced ordinates is to be included in the vicinity of the dew-point pressure where the change in mobility with pressure is potentially non-linear. The number of additional ordinates and their spacing in pressure are determined automatically subject to the minimum step size specified in item 12 below.

    For the pre-2015.1 version of the GPP option, when calculating the generalized pseudo-pressure integral table, if this value is positive more ordinates are placed where the change in mobility with pressure is potentially non-linear, and fewer ordinates are placed where the mobility is linear. This item determines how many ordinates are used. If the area defined by three ordinates is different from the area defined by the outer two by more than this fraction, an extra ordinate will be added between the first two ordinates. A reasonable value for this item would be between 0.001 and 0.05.

    DEFAULT: -1 (that is, use regularly spaced pressure ordinates only when constructing table)

    ECLIPSE 300

  12. Adaptive ordinate minimum spacing.

    This is the minimum possible distance between any pair of ordinates when the adaptive ordinate spacing scheme is active.

    UNITS: bars (METRIC), psi (FIELD), atm (LAB), atm (PVT-M)

    DEFAULT: 0.1 x atmospheric pressure.

End the data record with a slash (/).

Notes

ECLIPSE 300

  • The lower and upper bound factors (items 5 and 6) can be used to adjust the size of the pressure range covered by the generalized pseudo-pressure integral. In conjunction with the intervals below and above the dew-point pressure (items 1 and 2), these can be used to increase the accuracy of the integration without having to use too many quadrature points (which can be computationally expensive). Unfortunately there is no good rule for selecting these bounds so the defaults should be used unless long calculation times are experienced.

    ECLIPSE 300

  • The generalized pseudo-pressure integration table recalculation criteria (items 7, 8, 9 and 10) may be used to control the frequency at which the tables are recalculated. If anomalous behavior is observed, for example, unexpectedly high blocking factors, the frequency of recalculation can be increased by reducing the sizes of one or more of the recalculation controls. In addition, if any of items 7, 8, 9 or 10 is set to 0.0, a recalculation will be enforced at each timestep. The overall computation time will increase with the frequency of recalculation. In general, some experimentation may be necessary to find an acceptable compromise between recalculation frequency and calculation accuracy. (If items 7, 8, 9 or 10 are set to a negative value, the associated recalculation control will be disabled.)
  • In some circumstances, a rapidly changing blocking factor may be encountered. Significant damping of the blocking factor, that is, too small a value for item 3 the damping coefficient, can lead to inaccurate results (for example, a sudden change in the well BHP). If this problem is encountered, the damping coefficient should be increased to a value close to 1.0. If this does not resolve the problem, setting the well to be a single-segment multisegment well (see item 62 in OPTIONS3) may fix the problem.
  • The values specified above will apply to all wells in the simulation. The WPICOND keyword can be used to specify these values individually on a per well basis.
  • Item 14 of the WELLDIMS keyword can be used to specify the maximum number of points available in the pseudo-pressure integral table. (This is not available for the pre-2015.1 version of the GPP model, that is, if item 330 of the OPTIONS3 keyword is set to 1.)
