This keyword describes the thermal degradation of polymer due to temperature. The data comprises NTPVT (set in the TABDIMS keyword) tables of polymer thermal degradation functions, each terminated by a slash (/). Each table consists of the following columns of data:

  1. The local temperature in the solution.

    The values should increase monotonically down the column.

    UNITS: °C (METRIC), °F (FIELD), °C (LAB)

  2. The corresponding half-life of the polymer.

    UNITS: day (METRIC), day (FIELD), hr (LAB)

Each table must contain at least two, and no more than NPPVT (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table.

Note: Changes made in the SCHEDULE section will not be honored in a restart run unless the re-specification is also included in the restart data file. This may be done either by placing the new data for PLYDHFLF in the PROPS section or by leaving the SCHEDULE section keywords in place and using the SKIPREST keyword.

See the "Polymer flood model" in the ECLIPSE Technical Description for further information.

Example

With NTPVT = 2 and NPPVT ≥ 5:
