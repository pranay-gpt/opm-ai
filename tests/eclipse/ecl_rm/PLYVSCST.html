This keyword is for polymer studies when the salt-sensitivity option has been activated (keyword BRINE in the RUNSPEC section) and when the temperature option has been activated (keyword TEMP in the RUNSPEC section). You use PLYVSCST with associated settings in keywords SALTNODE and TEMPNODE to specify a full three-dimensional polymer/salt solution/temperature viscosity function.

The data comprises NTPVT (set in the TABDIMS keyword) tables of polymer viscosity multiplier functions, each terminated by a slash (/). These describe the effect on the viscosity of pure water of increasing the concentration of polymer and salt in the solution, and the temperature of the solution.

Each table consists of up to NPPVT (set in keyword TABDIMS) sets of data records, one for each polymer concentration. Each set contains a subset of information for each salt concentration defined in SALTNODE. Each subset has an entry for the temperatures specified in TEMPNODE.

For example, to show a single table containing three sets of records for polymer concentrations (PC1, PC2 and PC3), with the polymer viscosity multipliers (PCMs) for two salt concentrations (SC1 and SC2) and three temperatures (T1, T2 and T3):

SALTNODE
  SC1
  SC2 /
TEMPNODE
  T1
  T2
  T3 /
PLYVSCST
<PC1>  <PCM for SC1, T1>
       <PCM for SC1, T2>
       <PCM for SC1, T3>  / PCMs for PC1 at SC1 and temperatures T1, T2, T3
       <PCM for SC2, T1>
       <PCM for SC2, T2>
       <PCM for SC2, T3>  / PCMs for PC1 at SC2 and temperatures T1, T2, T3
/ end of record set for polymer concentration PC1

The SALTNODE and TEMPNODE keywords provide SC1, SC2, T1, T2 and T3. The first set of records in PLYVSCST is for PC1. The first subset of data terminated by the first slash (/), defines the polymer viscosity multipliers (PCMs) for a polymer concentration PC1 at a salt concentration of SC1 for the three temperatures T1, T2 and T3. The second subset of data, terminated by the second slash, contains similar information for SC2. The set of records for PC1 is terminated by a slash. The remaining sets of records for PC2 and PC3 in PLYVSCST follow the same pattern, with a final terminating slash for the end of the table.

<PC2>  <PCM for SC1, T1>
       <PCM for SC1, T2>
       <PCM for SC1, T3>  / PCMs for PC2 at SC1 and temperatures T1, T2, T3
       <PCM for SC2, T1>
       <PCM for SC2, T2>
       <PCM for SC2, T3>  / PCMs for PC2 at SC2 and temperatures T1, T2, T3
/ end of record set for polymer concentration PC2
<PC3>  <PCM for SC1, T1>
       <PCM for SC1, T2>
       <PCM for SC1, T3>  / PCMs for PC3 at SC1 and temperatures T1, T2, T3
       <PCM for SC2, T1>
       <PCM for SC2, T2>
       <PCM for SC2, T3>  / PCMs for PC3 at SC2 and temperatures T1, T2, T3
/ end of record set for polymer concentration PC3
/ end of the table

Each elementary set of records refers to one polymer concentration and one salt concentration, and gives a single column of viscosity multipliers, one record for each temperature in the TEMPNODE keyword. Successive subsets of records contain data for the next salt concentration specified by the SALTNODE keyword. When the record set for the largest SALTNODE value has been completed, the next set of records refers to a new polymer concentration, and restarts at the first TEMPNODE and SALTNODE values. The multiplier is preceded by the polymer concentration value in the very first entry of a record set. In combination this allows the specification of a full three-dimensional polymer/salt solution/temperature viscosity function.

The multipliers should be greater than or equal to unity. Activating item 208 in OPTIONS relaxes this constraint by allowing any positive value.

Note that:

  • The polymer concentration in the solution should increase monotonically down the table.
  • The first entry must be 0.0

UNITS: kg/sm3 (METRIC), lb/stb (FIELD), gm/scc (LAB)

The set of records for one polymer concentration is terminated by a null record (that is a record with no data before the terminating slash) and the table is also terminated by a null record.

See the "Polymer flood model" in the ECLIPSE Technical Description for further information.

Example

In this example, there is one PLYVSCST table as NTPVT = 1. The table contains three set of records for three polymer concentrations (.0000, .0100 and .0300) which is at the limit set by NPPVT = 3. Two brine concentrations (1.0 and 5.0) are specified in keyword SALTNODE and three temperatures (10, 50 and 100) are specified in keyword TEMPNODE.

SALTNODE
  1.0
  5.0 /
TEMPNODE
  10
  50
  100 /
PLYVSCST
.0000   1.0
        1.0
        1.0  / multipliers for salt concentration 1.0 and temperatures 10,50 and 100 
        1.0
        1.0
        1.0  / multipliers for salt concentration 5.0 and temperatures 10,50 and 100
/ end of record set for polymer concentration 0.0000
.0100  10.0
        8.0
        6.0  / multipliers for salt concentration 1.0 and temperatures 10,50 and 100
        8.0
        4.0
        2.0  / multipliers for salt concentration 1.0 and temperatures 10,50 and 100
/ end of record set for polymer concentration 0.0100
.0300   50.0
        25.0
        15.0  / multipliers for salt concentration 1.0 and temperatures 10,50 and 100
        40.0
        30.0
        18.0  / multipliers for salt concentration 1.0 and temperatures 10,50 and 100
/ end of record set for polymer concentration 0.0300
/ end of table 1

The number of entries in SALTNODE and TEMPNODE cannot exceed the limit set by NPPVT.
