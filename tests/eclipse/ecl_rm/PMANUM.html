The keyword should be followed by one integer for every grid block in the current box specifying the pressure maintenance region to which it belongs. The region number should not be less than 1 or greater than the number of pressure maintenance tables, specified with TABDIMS.

Pressure maintenance region numbers are used to specify regions for pressure maintenance as described with the GPMAINT keyword.

Grid blocks are ordered with the X axis index cycling fastest, followed by the Y and Z axis indices.

By default all cells are in PMANUM region 1.
