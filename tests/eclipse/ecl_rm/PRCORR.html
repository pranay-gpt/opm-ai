This keyword requests that a slightly modified form of the Peng-Robinson equation of state is to be used, as described in "Equations of state" in the ECLIPSE Technical Description. This changes the usual form of the Ω a value as a function of the component acentric factor.

The keyword contains no items, and has no effect on equations of state other than the Peng-Robinson.
