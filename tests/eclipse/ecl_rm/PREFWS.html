This optional keyword supplies reference pressures for water components for use in the surface calculations. The default, if it is not supplied, is for these to follow the reservoir values supplied with PREFW. If this keyword is supplied, the use of defaulted items is not allowed; values shall be input for each water component (see keyword COMPW).

If multiple equations of state are being used, a set of data should be entered for each surface EoS. The number of surface equation of state regions is entered as NMEOSS in keyword TABDIMS. The use of multiple EoS regions is discussed in "Equations of state regions" in the ECLIPSE Technical Description.

UNITS: barsa (METRIC), psia (FIELD), atma (LAB), atma (PVT-M)
