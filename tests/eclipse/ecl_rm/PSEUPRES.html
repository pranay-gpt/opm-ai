This keyword requests that the Generalized Pseudo-Pressure (GPP) option be activated for the well inflow calculations in ECLIPSE 300 for all wells. It has been retained for backwards compatibility but it is recommended that the WPICOND keyword is used instead.

For the pre-2015.1 version of the GPP model (which can be selected by setting item 330 of the OPTIONS3 keyword to 1), this keyword should be specified early in the SCHEDULE section before any well operations or timestepping keywords are specified. For the current version of the GPP option, this restriction does not apply.

The GPP well inflow model can also be activated for individual wells by entering GPP in item 8 of the WELSPECS keyword or item 9 of the WELSPECL keyword. For the current version of the GPP model, the GPP option can be both activated and deactivated for individual wells using the WPICOND keyword.

The effect of the PSEUPRES keyword is to select the GPP inflow model for each well as and when it is defined via the WELSPECS or WELSPECL keyword irrespective of the value assigned to item 8 or 9 of the WELSPECS or WELSPECL keyword respectively. For the current version of the GPP model, the WPICOND keyword may subsequently be used to deselect the GPP option for one or more wells. If a well is subsequently redefined via the WELSPECS or WELSPECL keyword, the GPP option will be selected again if the PSEUPRES keyword has been specified.

For details of the GPP model, see "Special inflow equations" in the ECLIPSE Technical Description.

See also the keywords PICOND and WPICOND.
