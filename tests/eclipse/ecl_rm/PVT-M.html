This keyword specifies that PVT-metric units are to be used for the input data. These are essentially the same as METRIC units, but with pressures measured in atmospheres. Note that the default units are METRIC.

See "Units" in the ECLIPSE Technical Description for further details.

There is no data associated with this keyword.
