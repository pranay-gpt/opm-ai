The data comprises NTPVT (set in the TABDIMS keyword) records, each terminated by a slash (/).

Each record consists of the following items of data:

  1. The reference pressure (Pref) for items 2 and 4. This reference pressure should be close to field pressures.

    UNITS: barsa (METRIC), psia (FIELD), atma (LAB), atma (PVT-M)

    DEFAULT: ERROR (ECLIPSE 100), 1 atma = 14.6959 psia (ECLIPSE 300).

  2. The water formation volume factor at the reference pressure, Bw(Pref)

    UNITS: rm3/sm3 (METRIC), rb/stb (FIELD), rcc/scc (LAB), rm3/sm3 (PVT-M)

    DEFAULT: 1.0 (in all units)

  3. The water compressibility
    C =-( dBwdP )/Bw [Eq. 247.1]

    UNITS: 1/bars (METRIC), 1/psi (FIELD), 1/atm (LAB), 1/atm (PVT-M)

    DEFAULT: 0 (ECLIPSE 100), 4.0e-5 1/atm (ECLIPSE 300)

  4. The water viscosity at the reference pressure μw⁡(P ref) .

    UNITS: cP (METRIC), cP (FIELD), cP (LAB), cP (PVT-M)

    DEFAULT: 0.5 cP (ECLIPSE 100), 0.3 cP (ECLIPSE 300).

  5. The water “viscosibility”
    C v=( dμw dP )/μw [Eq. 247.2]

    UNITS: 1/bars (METRIC), 1/psi (FIELD), 1/atm (LAB), 1/atm (PVT-M)

    DEFAULT: 0.0

ECLIPSE 100

ECLIPSE 100 calculates B w using:

Bw ⁡(P) =Bw⁡ (P ref) 1+X+ (X2/2) [Eq. 247.3]

where

X= C(P- Pref)

ECLIPSE 100 calculates the product Bwμw using:

Bw μw ⁡(P )= Bw ⁡(Pref)μ w⁡ (Pref) 1+Y+ (Y 2/2) [Eq. 247.4]

where

Y= (C-Cv)( P-Pref)

Note that if X or Y above are ever greater than 1 then formation volume factors and viscosities will be unphysical, and for this reason reference pressure should be close to reservoir pressure.

ECLIPSE 300

ECLIPSE 300 calculates B w using equation 247.3. μw is calculated similarly:

μw ⁡(P) =μw⁡(P ref)1+Y+(Y2/ 2) [Eq. 247.5]

where

Y= (-Cv)(P -Pref )

Note that if Y above is ever greater than 1 then viscosities will be unphysical, and for this reason reference pressure should be close to reservoir pressure.

ECLIPSE 300 Thermal option

In the thermal option there are a several ways of defining B w and μw, which are described in "Water density" and "Water viscosity" in the ECLIPSE Technical Description. By default, most of the data given by this keyword is ignored.
