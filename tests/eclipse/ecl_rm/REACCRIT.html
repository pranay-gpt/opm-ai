This keyword can be used in Thermal simulations to improve stability when modeling combustion processes.

When calculating the chemical reaction rate, certain terms can be interpolated between their values at the current timestep and the previous timestep, for example, temperature:

T=θ⋅ Tn+(1- θ)⋅ Tn-1, 0< θ≤1

where θ is an interpolation parameter.

The keyword is followed by the following items of data, terminated with a slash.

  1. Interpolation parameter for temperature used in the reaction rate Arrhenius term

    DEFAULT: 0.5

  2. Interpolation parameter for oil saturation used in the reaction rate

    DEFAULT: 1 (that is, fully implicit)

See "Chemical reactions" in the ECLIPSE Technical Description.
