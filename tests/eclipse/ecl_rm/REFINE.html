This keyword is used to indicate that subsequent data refers to a named local grid. The keyword is followed by the local grid name, terminated with a slash. Subsequent keywords, from the available sets described below, are taken to refer to the specified local grid, until either an ENDFIN or another REFINE keyword is entered.

Local grid refinement is described in "Local grid refinement and coarsening" in the ECLIPSE Technical Description.

The REFINE keyword is available in the GRID, EDIT, PROPS, REGIONS, SOLUTION and SCHEDULE sections.

There are no restrictions on the keywords that can be used with this keyword in ECLIPSE 300.

ECLIPSE 100 imposes the following restrictions on the keywords that can be used with this keyword.

GRID section

ECLIPSE 100

The REFINE keyword can be used in the GRID section to return to a local grid that has previously been introduced with CARFIN or RADFIN, to make further modifications to its grid data or to supply additional data.

In addition, the BOX, COPY, EQUALS, MULTIPLY and COPYBOX keywords can be used to set or modify GRID section keywords in regions of the local grid.

EDIT section

ECLIPSE 100

The following grid arrays may be edited for a local grid:

PORV TRANX TRANR DIFFX DIFFR
DEPTH TRANY TRANTHT DIFFY DIFFTHT
  TRANZ   DIFFZ  

In addition, the BOX, COPY and EQUALS keywords can be used to set or modify the above keywords in regions of the local grid. If any grid block values are defaulted, the host global grid cell value is used.

In addition, the BOX, COPY, EQUALS and OPERATE keywords can be used to set or modify the above keywords in regions of the local grid. If any grid block values are defaulted, the host global grid cell value is used.

SOLUTION section

ECLIPSE 100

In the SOLUTION section, the REFINE keyword can be used only when the run is initialized by enumeration, to specify the initial conditions in the local grid cells. If the initial conditions for the local grid cells are not set in this way, they default to the initial conditions in their global grid host cells.

The REFINE keyword can be followed by any of the enumeration keywords that specify initial conditions on a cell by cell basis:

PRESSURE
SWAT
SGAS
SSOL
SURF
SFOAM
RS or PBUB
RV or PDEW

The BOX, EQUALS, ADD, MULTIPLY, COPY and OPERATE keywords are not available in the SOLUTION section.

SCHEDULE section

ECLIPSE 100

The REFINE keyword can be used in the SCHEDULE section to modify region data during a simulation, though modification of SATNUM or PVTNUM data during a simulation should be carried out with care and is not recommended in general.

The keyword may be used with the BOX, EQUALS, ADD or COPY modifiers.
