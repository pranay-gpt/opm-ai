This keyword is optional, and is used to allow COORD data to be read in on a reservoir-by-reservoir basis. This is useful when two or more reservoir models are being combined into a single larger grid.

The keyword is followed by a single integer to specify the number of the next reservoir to be input using the COORD keyword. The reservoir number should be between 1 and NUMRES. NUMRES should be set > 1 by the keyword NUMRES in the RUNSPEC section.

See also the COORD and COORDSYS keywords and "Independent reservoir regions" in the ECLIPSE Technical Description.
