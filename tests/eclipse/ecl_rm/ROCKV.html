This keyword can only be used with the THERMAL option (keyword THERMAL in the RUNSPEC section).

ROCKV should be followed by one real number for every grid block in the current input box, specifying the grid block rock volumes.

This keyword is used to overwrite the rock volumes calculated from the GRID data. Setting a zero rock volume causes a cell to be inactive if the cell also has a zero pore volume.

UNITS: rm3 (METRIC), rb (FIELD), rcc (LAB), rm3 (PVT-M)

Example

ROCKV
24*1.324E4 24*0 12*1876 /
