This keyword specifies the initial residual oil composition values for each cell. It can only be used with the SOR option. When flashed at the initial cell pressure the fluid must be a single phase oil.

The keyword should be followed by Nx⋅Ny ⋅N z⋅ Ncom ps values in normal order, with the X index changing fastest.

Note: Using this keyword will change the way saturations are calculated. Please refer to "SOR Initialization" for more details.

Example

ROMF
300*0.00
300*0.00
300*1.00
