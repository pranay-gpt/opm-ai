SCHEDULE

This keyword activates the output of a set of data (see the example output below) which can be used by programs that interface with ECLIPSE. This keyword can also be used as a shortcut to output this data.

This keyword is followed by a single record terminated by a slash (/). The record consists of two items of data:
  1. The time at which restart files are written:
    TIMESTEP At every nth timestep.
    MONTH At the first report time in every nth month.
    YEAR At the first report time in every nth year.
    REPORT At every nth report time.

    The reporting frequency n is defined in item 2.

    DEFAULT: TIMESTEP

  2. The frequency at which restart files are written (n in item 1).

    DEFAULT: 1

    End data record with a slash (/).

It outputs all the following:

  • an Initial Data file
  • an output of fault data and non-neighbor connections data to the print file
  • an extended GRID file
  • the following summary mnemonics for all connections of all wells: CWFR, COFR, CGFR, CGFRF, WWPR, WOPR, WGPR, WGPRF, WWIR, WOIR, WGIR, WGLIR, WBHP
  • the following summary mnemonics for all connections of all wells in any LGR (if any): LCWFR, LCOFR, LCGFR, LCGFRF
  • a Restart file for every time period defined in this keyword (including initial conditions) which contains phase flow rates, pressure, temperature (if the TEMP keyword is used), bubble point pressure, densities of each phase, viscosities, formation volume factors, phase relative permeabilities and the rock compaction multiplier (if the ROCKCOMP keyword is used).

Notes

  • The data file must have a summary section, even an empty one.
  • The summary mnemonics of an absent phase are not output.
  • If different requests for output are made by the following keywords, RPTCPL will ignore them: RPTGRID, RPTONLY, SUMTHIN and NOSUMLGR.
  • If different requests for output are made by the following keywords, RPTCPL will respect them: NOINSPEC, NORSSPEC, NOGGF, GRIDFILE and the NORST mnemonic in RPTRST.
  • Use of BASIC and FREQ under the RPTRST keyword will override the frequency at which restart files are written as defined in this keyword.
  • Additional properties requested in the RPTRST keyword will be output at every time step, for example, FIP.

RPTCPL
REPORT
3
