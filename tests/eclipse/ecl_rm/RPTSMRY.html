The keyword should be followed by a single integer which determines whether or not ECLIPSE prints a table of the variables to be written to the Summary file during the current run.

A value of 0 switches the output off.

A value of 1 switches it on.

The data field should be terminated by a slash (/).

Example

RPTSMRY
 1 /
