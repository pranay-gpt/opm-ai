The RTEMPA keyword is used to specify the initial reservoir temperature in runs where the Temperature option is active (keyword TEMP in the RUNSPEC section).

Note: The keyword RTEMP is accepted as an alias for RTEMPA.

See the description of keyword RTEMP for more details.

UNITS: °C (METRIC), °F (FIELD), °C (LAB), °C (PVT-M)

DEFAULT: 60 °F (ECLIPSE 100), 100 °C (ECLIPSE 300)

See also keywords RTEMPVD, SPECHEAT, SPECROCK and WTEMP, and "Temperature option" in the ECLIPSE Technical Description.
