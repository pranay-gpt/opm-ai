This keyword requests that the data in the SUMMARY files should be output in a tabulated format in addition to the usual summary files, which are unaffected.

ECLIPSE 100: The data will be appended to the end of the Print file unless the SEPARATE keyword is used, in which case the data is output in a separate RSM file.

ECLIPSE 300: The data is output to a separate RSM file.

Well and group control mode numbers ( SUMMARY section keywords WMCTL, F/ GMCTP, F/ GMCTW, F/ GMCTG) are printed as character strings, unless the keyword EXCEL is used.

The RUNSUM keyword has no associated data.

See also the keywords EXCEL and NARROW.

Example

RUNSUM
