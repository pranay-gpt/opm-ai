The SAKRORW keyword specifies the value of oil relative permeability at the critical water saturation within each grid block for scaling oil relative permeability to water for high concentrations of adsorbed solids.

The SAKRORW keyword should only be used if oil and water are present in the model and if end-point scaling has been specified via the RUNSPEC keyword ENDSCALE and the solid wettability adsorption option has been selected via the RUNSPEC keyword SOLID and the PROPS keyword SOLWTAB.

The SAKRORW keyword should be followed by one real number for each grid block in the current input box specifying the oil relative permeability at the critical water saturation. The data must be terminated by a slash (/).

Grid blocks are ordered with the X-axis index cycling fastest followed by the Y and Z indices. Repeat counts may be used for repeated values (for example 10*0.21). Note that spaces must not be inserted on either side of the asterisk.

If the keyword SAKRORW is omitted for some or all of the grid blocks in a model where it could be specified, the oil relative permeabilities at the critical water saturation will default to the values defined in the appropriate relative permeability tables via the SOLWNUM keyword.

See "Saturation table scaling" in the ECLIPSE Technical Description for details of the end-point scaling procedure.
