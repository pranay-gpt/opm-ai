This keyword defines the salt concentration value for the reservoir for restart runs where the base run water properties were specified with no salinity dependence, for example when specified using the PVTW keyword. This allows you to introduce salinity dependent water properties on restart, using, for example, PVTWSALT with LOWSALT or BRINE.

The keyword should be followed by one real number specifying the "initial" and assumed homogeneous salt concentration. The data field should be terminated by a slash (/).

UNITS: kg/sm3 (METRIC), lb/stb (FIELD), gm/scc (LAB)

Notes

  • The SALTREST keyword allows you to simulate the impact of salinity variation upon restart for a certain class of cases, such as when the base simulation contains no salt tracking functionality because the salinity variation had little physical impact and therefore the salt concentration was assumed to remain constant up to the point of restart. This might be because the reservoir contained water with homogeneous salinity and injected water was of a very similar salinity to the initial reservoir water. If these conditions were not met, it is strongly advised that the base model is rerun with the BRINE and/or LOWSALT options active from the start, allowing the simulation to more accurately represent the salinity, water density and possibly pressure distributions inside the reservoir.
  • Using SALTREST properly involves defining a saline water model consistent with the water model defined in the original black oil case. To do this:
    • When replacing PVTW by PVTWSALT. The lines corresponding to the salinity introduced in SALTREST should have the same definition as the water properties from the PVTW keyword in the base case. This ensures consistency between models for water properties like compressibility and viscosity.
    • If LOWSALT is used, the LSALTFNC keyword should have a value of 0 for the salinity entered in SALTREST. This ensures consistency between models for the relative permeabilities used. Failure to do so can lead to unstable situations and possible convergence problems.
