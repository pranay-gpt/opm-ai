The SASWCR keyword specifies the critical water saturation (that is, the largest water saturation for which the water relative permeability is zero) within each grid block for scaling the water relative permeability for high concentrations of adsorbed solids.

The tabulated water relative permeability functions are scaled between the critical water saturation defined by the SASWCR keyword and the maximum water saturation defined by the SASWU keyword.

The SASWCR keyword should only be used if water is present in the model and if end-point scaling has been specified via the RUNSPEC keyword ENDSCALE and the solid wettability adsorption option has been selected via the RUNSPEC keyword SOLID and the PROPS keyword SOLWTAB.

The SASWCR keyword should be followed by one real number for each grid block in the current input box specifying the critical water saturation. The saturation should be in the range 0.0 to 1.0 inclusive. The data must be terminated by a slash (/).

Grid blocks are ordered with the X-axis index cycling fastest followed by the Y-axis and Z-axis indices. Repeat counts may be used for repeated values (for example 10*0.21). Note that spaces must not be inserted on either side of the asterisk.

If the keyword SASWCR is omitted for some or all of the grid blocks in a model where it could be specified, the critical water saturations for the high solid adsorption concentration water relative permeability calculations will default to the values defined in the appropriate relative permeability tables via the SOLWNUM keyword.

See "Saturation table scaling" in the ECLIPSE Technical Description for details of the end-point scaling procedure.
