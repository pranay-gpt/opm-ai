This keyword writes the run summary output, as generated by using the RUNSUM keyword, to a separate file, rather than appending it to the end of the Print file. The separate run summary file name is the root with the extension RSM. The RUNSUM keyword does not need to be specified if SEPARATE is used.

It is possible to output the run summaries in a format suitable to be imported into a spreadsheet program such as Excel using the EXCEL keyword.

The SEPARATE keyword has no associated data.

See also keyword NARROW.

Example

SEPARATE
