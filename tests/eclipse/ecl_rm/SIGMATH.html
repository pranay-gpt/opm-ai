This keyword can only be used with the THERMAL option (keyword THERMAL in the RUNSPEC section).

If the dual porosity or dual permeability options are being used (keyword DUALPORO or DUALPERM in the RUNSPEC section), this keyword can specify an overall multiplier to be used in the construction of the matrix-fracture thermal conductivity coupling transmissibilities.

The SIGMATH keyword is followed by a value for each matrix cell. Thus ( Nx NyN z)/2 values are required in all, in normal grid order with the X-index changing fastest.

The dual porosity and dual permeability options are discussed in more detail in "Dual porosity" in the ECLIPSE Technical Description.

The Thermal option is described in "Thermal option" in the ECLIPSE Technical Description.
