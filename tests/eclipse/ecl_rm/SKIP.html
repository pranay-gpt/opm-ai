SKIP

x ECLIPSE 100
x ECLIPSE 300
x RUNSPEC
x GRID
x EDIT
x PROPS
x REGIONS
x SOLUTION
x SUMMARY
x SCHEDULE

This keyword causes all subsequent keywords to be ignored, up to the next ENDSKIP keyword.

The skipping of keywords is terminated by the ENDSKIP keyword.

The keywords SKIP, SKIP100 and SKIP300 can be nested provided each instance is matched with an ENDSKIP keyword.

Example

----GRID section
SKIP
CARFIN
'HUGE' 1 20 1 20 1 20 100 100 100 /
ENDFIN
ENDSKIP
