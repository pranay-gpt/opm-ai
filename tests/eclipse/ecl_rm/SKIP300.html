SKIP300

x ECLIPSE 100
x ECLIPSE 300
x RUNSPEC
x GRID
x EDIT
x PROPS
x REGIONS
x SOLUTION
x SUMMARY
x SCHEDULE

This keyword causes ECLIPSE 300 to ignore all subsequent keywords, up to the next ENDSKIP keyword. This keyword is has no effect in ECLIPSE 100 simulation runs.

The skipping of keywords is terminated by the ENDSKIP keyword.

The keywords SKIP, SKIP100 and SKIP300 can be nested provided each instance is matched with an ENDSKIP keyword.

Example

----Props section
SKIP300
INCLUDE
'BLACK.PVO' /
ENDSKIP
