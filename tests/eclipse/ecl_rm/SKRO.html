The SKRO keyword specifies the value of oil relative permeability at the maximum oil saturation within each grid block for scaling the surfactant oil relative permeability.

In ECLIPSE 100, the SKRO keyword should only be used if oil is present in the model and if both the end-point scaling and the surfactant options have been selected via the RUNSPEC keywords ENDSCALE and SURFACT respectively.

In ECLIPSE 300, the SKRO keyword should only be used if oil is present in the model and if both the end-point scaling and the surfactant options have been selected via the RUNSPEC keywords ENDSCALE and SURFST or SURFSTES respectively.

The SKRO keyword should be followed by one real number for each grid block in the current input box specifying the maximum oil relative permeability. The data must be terminated by a slash (/).

Grid blocks are ordered with the X-axis index cycling fastest followed by the Y-axis and Z-axis indices. Repeat counts may be used for repeated values (for example 10*0.21). Note that spaces must not be inserted on either side of the asterisk.

If the keyword SKRO is omitted for some or all of the grid blocks in a model where it could be specified, the oil relative permeabilities at the maximum oil saturation will default to the values defined in the appropriate relative permeability tables via the SURFNUM keyword.

See "Saturation table scaling" in the ECLIPSE Technical Description for details of the end-point scaling procedure.
