This keyword specifies the initial solid composition values for each cell. It can only be used with the SOLID option. If this keyword is used then keyword SSOLID should also be used to specify the amount of initial solids.

The keyword should be followed by Nx⋅Ny ⋅N z⋅ Ncom ps values in normal order, with the X index changing fastest. For thermal runs with water, Nx⋅Ny ⋅N z extra values are required, all set to zero.

Example

SMF
300*0.00
300*0.00
300*1.00
