This keyword specifies the initial residual oil saturation values for each cell. It can only be used with the SOR option. This keyword is optional, but if used, a value should be given for every cell in the grid.

The keyword should be followed by one real number for each grid block in the current input box, terminated with a slash (/).

Example

SOILR
4000*0.01 /
