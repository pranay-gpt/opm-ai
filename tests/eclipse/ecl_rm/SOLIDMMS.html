The data comprises NTSFUN (set in the TABDIMS keyword) tables of fluid mobility factors, describing the change in mobility caused by solid adsorbed on to the rock formation. See "Solid phase" in the ECLIPSE Technical Description for further information.

Each table consists of the following columns of data and is terminated by a slash (/):

  1. The saturation of solid adsorbed by the rock formation.

    These values should increase monotonically down the column.

  2. The corresponding mobility multiplier.

Each table must contain at least two, and no more than NSSFUN (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table.

The amount of solids adsorbed can be defined by the SOLIDADS keyword.

SOLIDMMC can be used as an alternative to this keyword; in that case the mobility multiplier is specified as a function of the adsorbed solid concentration.
