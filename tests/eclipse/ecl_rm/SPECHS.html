This keyword can only be used with the THERMAL option.

SPECHS specifies the first coefficient of the oil component solid phase specific heats, for each EoS region.

For multi-component simulations, the solid phase molar enthalpy is the mole fraction weighted sum of the component enthalpies:

hs=Σc⁢=  1 Ncom ps sc ⋅h c⋅ mwc [Eq. 247.1]

where

s c is the mole fraction of component c in the oil phase, and
mwc is the component molecular weight.

The component solid enthalpy hc has the form

hc=C p1c ⋅(T-T st)+12⋅ Cp 2c ⋅(T-Ts t) 2 [Eq. 247.2]

where

C p1c is the first coefficient of the component solid specific heat entered with this keyword
C p2c is the second coefficient of the component solid specific heat entered with the SPECHT keyword, and
T st is the standard temperature defined with keyword STCOND.

The data record contains one solid component specific heat value for each component (Ncomps values).

UNITS: kJ/kg/K (METRIC), Btu/lb/°R (FIELD), J/gm/K (LAB), kJ/kg/K (PVT-M)

DEFAULT: 0.0

If multiple equations of state are being used, a set of data should be entered for each reservoir EoS. The number of reservoir equation of state regions is entered as NMEOSR in keyword TABDIMS. The use of multiple EoS regions is discussed in "Equations of state regions" in the ECLIPSE Technical Description.
