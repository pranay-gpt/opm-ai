This keyword should only be used for runs with the Temperature option active (see keyword TEMP).

The data comprises NTSFUN (set in the TABDIMS keyword) tables, defining the volume specific heat of rock as a function of temperature. Each table consists of the following columns of data and is terminated by a slash (/):

  1. The temperature.

    The values should increase monotonically down the column.

    UNITS: °C (METRIC), °F (FIELD), °C (LAB), °C (PVT-M)

  2. The corresponding volume specific heat of rock.

    UNITS: kJ/m3/K (METRIC), Btu/ft3/°R (FIELD), J/cc/K (LAB), kJ/m3/K (PVT-M)

Each table must contain at least two, and no more than NSSFUN (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table.

See also the SPECHEAT keyword and the "Temperature option" in the ECLIPSE Technical Description.

Example

With NTSFUN = 2 and NSSFUN = 2:

SPECROCK
   0.0  25.0
 300.0  25.0
/
   0.0  27.0
 300.0  27.0
/
