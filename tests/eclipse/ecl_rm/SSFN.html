This keyword may be used with the solvent model as described in "Solvent model" in the ECLIPSE Technical Description.

The data comprises NTSFUN (set in the TABDIMS keyword) tables of gas/solvent saturation functions, each terminated by a slash (/).

The tables consist of the following columns of data. The first column is the phase fraction of either the gas or the solvent ( Sgas /( Sgas +S solvent) or Ssol vent /(Sgas +S solvent) ). The next two columns are respectively the relative permeability multiplier for the gas and the solvent (Krg* and Krs *).

The relative permeabilities of the 2 components are given by:

Kr g= Krgt (S gas+ Ssolvent ) Krg * K rs=Krgt(Sgas +S solvent) K rs* [Eq. 247.1]

where

K rgt is the total gas phase relative permeability input using the SGFN keyword.

Column:

  1. The phase fraction.

    Values should span the range 0 to 1 and increase monotonically down the column.

  2. The corresponding gas relative permeability multiplier.

    Values should be between 0 and 1 and should be level or increasing down the column.

  3. The corresponding solvent relative permeability multiplier.

    Values should be between 0 and 1 and should be level or increasing down the column.

Each table must contain at least two, and no more than NSSFUN (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table.

Example

With NTSFUN = 2 and >NSSFUN = 6

 0.0    0.0    0.0
 1.0    1.0    1.0
