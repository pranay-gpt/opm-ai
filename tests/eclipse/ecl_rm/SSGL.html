This keyword is available in both ECLIPSE simulators.

The SSGL keyword specifies the connate gas saturation (that is, the smallest gas saturation in a gas saturation function table) within each grid block for scaling the surfactant oil and water relative permeabilities.

ECLIPSE 100

The SSGL keyword should only be used if gas is present in the model and if both the end-point scaling and the surfactant options have been selected via the RUNSPEC keywords ENDSCALE and SURFACT respectively.

ECLIPSE 300

The SSGL keyword should only be used if gas is present in the model and if both the end-point scaling and the surfactant options have been selected via the RUNSPEC keywords ENDSCALE and SURFST or SURFSTES respectively.

The SSGL keyword should be followed by one real number for each grid block in the current input box specifying the connate gas saturation. The saturation should be in the range 0.0 to 1.0 inclusive. The data must be terminated by a slash (/).

Grid blocks are ordered with the X-axis index cycling fastest followed by the Y-axis and Z-axis indices. Repeat counts may be used for repeated values (for example 10*0.21). Note that spaces must not be inserted on either side of the asterisk.

If the keyword SSGL is omitted for some or all of the grid blocks in a model where it could be specified, the connate gas saturations will default to the values defined in the appropriate relative permeability tables via the SURFNUM keyword.

See "Saturation table scaling" in the ECLIPSE Technical Description for details of the end-point scaling procedure.
