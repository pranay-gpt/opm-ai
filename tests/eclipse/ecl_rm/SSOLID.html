This keyword specifies the initial solid saturation values for each cell. It can only be used with the SOLID option. If this keyword is used then keyword SMF should also be used to define the solid composition.

The keyword should be followed by one real number for each grid block in the current input box, terminated with a slash (/).

Example

SSOLID
4000*0.01 /
