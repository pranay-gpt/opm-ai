SCHEDULE

This keyword specifies the start date of the simulation. (Any report dates entered in the DATES keyword in the SCHEDULE section must be later than the start date.)

The keyword is followed by the following items of data, denoting the day, month, year and time of the start of the simulation, terminated with a slash (/).

  1. Day

    Day of the month (an integer between 1 and 31).

  2. Month

    Name of the month (JAN, FEB, MAR, APR, MAY, JUN, JUL, AUG, SEP, OCT, NOV, DEC).

    For July, the abbreviation JLY is a valid alternative.

    Note: A month name longer than three characters can be entered, but only the first three characters will be used.
  3. Year

    The year (a four-figure integer).

  4. Time

    The time (24 hour, in the format HH:MM:SS.SSSS)

ECLIPSE 300

DEFAULT: 1 Jan 1990 00:00:00

Example

START
 12  FEB  1987  /
