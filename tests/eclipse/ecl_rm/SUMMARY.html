SUMMARY section

The SUMMARY section specifies a number of variables that are to be written to Summary files after each timestep of the simulation. The graphics post-processor may be used to display the variation of variables in the Summary files with time and with each other. If there is no SUMMARY section, ECLIPSE does not create any Summary files.
