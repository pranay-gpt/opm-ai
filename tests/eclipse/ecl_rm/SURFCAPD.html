The data comprises NTSFUN (set in the TABDIMS keyword) tables of surfactant capillary de-saturation functions terminated by a slash (/). The de-saturation function describes the transition between immiscible conditions (low surfactant concentration) and miscibility (high surfactant concentration) as a function of the dimensionless capillary number. Each table consists of trhe following columns of data:

  1. The log of the capillary number (log⁡ 10( CAPN) )

    The values should increase monotonically down the column and should lie in the range -20 to 20.

  2. The miscibility function at the value of the log capillary number.

    A value of 0 implies immiscible conditions and a value of 1 miscible conditions.

    The values should not be greater than 1 or less than 0

Each table must contain at least two, and no more than NSSFUN (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table.

Note: NTSFUN tables must be supplied; however, only the SATNUM table numbers are used, and any tables referred to by SURFNUM and not by SATNUM are ignored. If any table after the first is defaulted, then that table is copied from the previous table.

See "Surfactant model" in the ECLIPSE Technical Description for further information.

Example

With NTSFUN = 2 and NSSFUN = 4

SURFCAPD
 -10   0.0
  -3   0.0
  -2   1.0
  10   1.0   /
/ default the second table to the first table
