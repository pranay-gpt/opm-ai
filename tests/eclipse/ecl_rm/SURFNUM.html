This keyword specifies the saturation table numbers used by the surfactant model to calculate the relative permeabilities when a high surfactant concentration implies that oil and water are miscible. The usual SATNUM keyword is used to specify the immiscible saturation functions.

The keyword should be followed by one integer for every grid block in the current input box, specifying the miscible (high surfactant) saturation function region to which it belongs. The region number should not be less than 1 or greater than NTSFUN (set in the TABDIMS keyword). The data must be terminated by a slash (/).

The oil-water saturation functions are specified using the SWFN, SOF2, SOF3 or SWOF keywords. A non-zero capillary pressure entered in the SWFN or SWOF keyword is ignored for the miscible tables.

Grid blocks are ordered with the X axis index cycling fastest, followed by the Y and Z axis indices. Repeat counts may be used for repeated values (for example 115*2). Note that spaces must not be inserted on either side of the asterisk.

ECLIPSE 100

The SURFNUM keyword should be specified when the SURFACT option has been specified.

ECLIPSE 300

The SURFNUM keyword should be specified when surfactant is being modeled. If either the keyword SURFST or SURFSTES is specified, the relative permeabilities will be interpolated between immiscible and miscible saturation functions. If neither of these keywords is specified, only the immiscible saturation functions specified via the SATNUM keyword will be used, that is, no interpolation will be applied.

If the SURFNUM keyword is undefined or only partially specified when the Surfactant option has been specified, the unspecified miscible saturation region numbers will default to 1.
Note: If end-point scaling has been specified via the ENDSCALE option, the immiscible and miscible saturation functions (specified via the SATNUM and SURFNUM keywords respectively) will use the associated immiscible and miscible sets of end-points, for example, SWL, SWCR, SWU and related end-points for immiscible and SSWL, SSWCR, SSWU and related end-points for miscible.

Example

With NTSFUN = 4 specified in the TABDIMS keyword; NDIVIY = 10 and NDIVIZ = 1 specified in the DIMENS keyword; no input BOX is set.
