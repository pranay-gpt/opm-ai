This keyword should only be used for surfactant studies when the salt sensitivity option has been activated (in ECLIPSE 100 keyword BRINE in the RUNSPEC section, in ECLIPSE 300 the use of this keyword will activate the salt sensitivity option). See the "Surfactant model" in the ECLIPSE Technical Description for further information.

The data comprises NTPVT (set in the TABDIMS keyword) tables of oil-water surface tension, each terminated by a slash (/). These describe the effect on the oil-water surface tension of increasing the concentration of surfactant and salt in the solution. Each table consists of up to NPPVT (set in the TABDIMS keyword) data records. Each record within a table consists of up to NPPVT surface tension values that correspond to a single specified surfactant concentration and several values of salt concentration (or effective salinity) that are specified elsewhere via the ESSNODE keyword. A set of such records therefore allows you to specify a two dimensional oil-water surface tension function with respect to surfactant concentration and salt concentration (or effective salinity). Each record therefore contains the following items of data:

  1. Surfactant concentration.

    UNITS: kg/sm3 (METRIC), lb/stb (FIELD), gm/scc (LAB), kg/sm3 (PVT-M)

  2. Oil-water surface tension values corresponding to the surfactant concentration given by item 1 and each salt concentration (or effective salinity) specified in the corresponding ESSNODE table.

    UNITS: N/m (METRIC), lbf/in (FIELD), dynes/cm (LAB), N/m (PVT-M)

The number of surface tension values per surfactant concentration node must equal the number of salt concentration (or effective salinity) values that are entered within the corresponding table in ESSNODE.

The surfactant concentrations specified in successive records should be monotonically increasing.

The data for each table is terminated by a null record (that is a record with no data before the terminating slash).
