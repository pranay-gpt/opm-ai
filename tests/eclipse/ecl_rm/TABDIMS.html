The data consists of some or all of the following items which describe the sizes of saturation and PVT tables used in the run, and also the number of fluid-in-place regions. The data must be terminated by a slash (/).

  1. NTSFUN. The number of saturation tables entered using SGFN for example. (Different saturation tables may be used in different parts of the reservoir - see SATNUM.)

    Default: 1

  2. NTPVT. The number of PVT tables entered using PVTG and PVTO in the PROPS section. (Different PVT tables may be used in different parts of the reservoir - see PVTNUM.)

    Default: 1

  3. NSSFUN. The maximum number of saturation nodes in any saturation table - for example SGFN and SGOF.

    Default values

    ECLIPSE 100: 20
    ECLIPSE 300: 50
  4. NPPVT. The maximum number of pressure nodes in any PVT table (PVTG, PVTO, PVDG and PVDO for example), or in any rock compaction table ( ROCKTAB).

    Default values

    ECLIPSE 100: 20
    ECLIPSE 300: 50
  5. NTFIP. The maximum number of FIP regions defined using FIPNUM.

    Default: 1

    This may also be set using item 1 of the REGDIMS keyword. If it is set in both places, the greater of the two settings is used. Additionally, if item 1 of DYNRDIMS is defined, the greatest of the three settings is used.

  6. NRPVT.

    ECLIPSE 100

    The maximum number of Rs nodes in a live oil PVT table (PVTO or PVCO) or Rv nodes in a wet gas PVT table (PVTG). This item is ignored unless either DISGAS or VAPOIL is specified. In API tracking runs this number needs to be the maximum number of distinct valued Rs nodes across all the PVT tables.

    ECLIPSE 300

    The maximum number of Rs nodes in a live oil PVT table (PVTO or PVCO).

    Default: 20

    ECLIPSE 300

  7. NRVPVT. The maximum number of Rv nodes in a wet gas PVT table (PVTG).

    Default: 20

  8. NTENDP. The number of saturation end-point versus depth tables is specified.

    This item may also be specified by item 3 of keyword ENDSCALE; if set in both places the maximum of the two values will be used.

    Default: 1

    ECLIPSE 300

  9. NMEOSR. The number of equation of state regions for reservoir conditions with equations of state set using EOS. The maximum value which can be specified in this item is 10.

    Default: 1

    ECLIPSE 300

  10. NMEOSS. The number of equation of state regions for surface conditions with surface equations of state set using EOSS. The maximum value which can be specified in this item is 10.

    Default: NMEOSR

  11. MXNFLX. The maximum number of flux regions.

    This item may also be specified by item 4 of keyword REGDIMS; if set in both places the maximum of the two values will be used.

    Default: 10

    ECLIPSE 300

  12. MXNTHR. The maximum number of thermal regions (see keyword THERMNUM).

    Default: 1

  13. NTROCC. The number of rock tables (see keyword ROCK).

    ECLIPSE 100

    Note: If the data set contains no other rock-related keywords, this value must be set explicitly to a value greater than zero in order to allow a data set which contains the ROCKNUM keyword to be read. If it is defaulted, PVTNUM will be used instead.

    ECLIPSE 300

    This value also sets the number of rock tables for keywords ROCKTAB, ROCKTABH and ROCKPAMA.

    Default: number of pressure tables

    ECLIPSE 300

  14. MXNPMR. The maximum number of pressure maintenance regions (see keyword GPMAINT).

    Default: 0

    ECLIPSE 300

  15. NTABKT. The maximum number of temperature dependent K-value tables (Thermal option). See keywords KVTEMP / KVTABTn and KWTEMP / KWTABTn.

    A maximum of nine temperature dependent K-value tables are allowed.

    Default: 0

    ECLIPSE 300

  16. NTALPHA The number of transport coefficient table ( ALPHA, ALPHAD, ALPHAI) regions.

    Default: NTPVT

    ECLIPSE 300

  17. NASPKA. The maximum number of rows in the ASPKDAM keyword table when permeability damage is not correlated to porosity change (Asphaltene option).

    Default: 10

    ECLIPSE 300

  18. MXRAWG. The maximum number of rows in the ASPREWG keyword table (Asphaltene option).

    Default: 10

  19. ECLIPSE 300

    MXRASO. The maximum number of rows in the ASPVISO table when a look-table is used to model the oil viscosity changes with asphaltene precipitate (Asphaltene option).

    Default: 10

  20. Not used

    ECLIPSE 300

  21. MCASPP. The maximum number of columns in the ASPPW2D keyword table.

    Default: 5

    ECLIPSE 300

  22. MRASPP. The maximum number of rows in the ASPPW2D keyword table (Asphaltene option).

    Default: 5

    ECLIPSE 300

  23. MXRATF. The maximum number of rows in the ASPWETF keyword table (Asphaltene option).

    Default: 5

    ECLIPSE 300

  24. MXNKVT. The number of composition dependent K-value tables. See keyword KVTABCn.

    A maximum of nine composition dependent K-value tables are allowed.

    Default: 0

    ECLIPSE 100

  25. Reserved.
