This keyword can only be used with the THERMAL option (see "Thermal option" in the ECLIPSE Technical Description).

The data consists of the following items, describing the dimensions of the TCB table data to be used in the run.

  1. The number of temperature cutback tables.

    DEFAULT:  1

  2. The maximum number of rows in any TCB table.

    DEFAULT:  10

The use and interpretation of temperature cutback tables is discussed in the definition of the keyword WELLTCBT.
