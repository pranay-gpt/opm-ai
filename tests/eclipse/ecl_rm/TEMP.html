This indicates that the Temperature option is required, to allow the modeling of the temperature effects of cold water injection. See "Temperature option" in the ECLIPSE Technical Description for more information.

In ECLIPSE 300 this option is only valid for black oil simulation using the BLACKOIL keyword.

If the dual porosity option is also used, see the thermal option documentation for "Dual porosity" in the ECLIPSE Technical Description for how the rock volume is represented.

The keyword has no associated data.
