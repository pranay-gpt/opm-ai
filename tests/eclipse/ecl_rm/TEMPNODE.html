This keyword describes the nodal values for temperature, to be used in the calculation of the polymer solution viscosity when the temperature option ( TEMP) is active. The data comprises NTPVT (set in the TABDIMS keyword) tables of temperature values, each terminated by a slash (/).

Each table consists of up to NPPVT (set in the TABDIMS keyword) values of the temperature. Within each table the values should be positive and strictly increasing.

UNITS: °C (METRIC), °F (FIELD), °C (LAB)

The number of entries in each table must correspond to the number of polymer solution viscosity entries used in the PLYVISCT keyword or to the number of polymer-solution/brine viscosity entries used in the PLYVSCST keyword.

Example

With NTPVT = 2 and NPPVT ≥ 4:
