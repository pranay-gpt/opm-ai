This keyword enables the THERMAL option (see "Thermal option" in the ECLIPSE Technical Description).

Either the DEADOIL or LIVEOIL keyword must also be specified. LIVEOIL is the default.

If the dual porosity option is also used, see the thermal option documentation for "Dual porosity" in the ECLIPSE Technical Description for how the rock volume is represented.

This keyword has no associated data.

Note: A list of features that are not compatible with the thermal option is given in the note at the end of "Instability in AIM runs due to thermal conduction" in the ECLIPSE Technical Description.
