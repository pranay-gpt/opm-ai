This keyword should only be used in a Thermal USEFLUX run, and only if the base full field model was an ECLIPSE 300 Black-oil model or a Compositional model.

For any type of simulation, the transmissibilities are taken from the base run and stored in the flux file.

For a Thermal simulation the heat transmissibilities are needed. However, these are not calculated from a full field non-thermal simulation.

So, for a USEFLUX case where the base run is non-thermal, and the reduced run is thermal, the heat transmissibilities are calculated as follows:

Ψni =α× ϒni

where

Ψni is the heat transmissibility between cells n and i
ϒ ni is the flow transmissibility between cells n and i
and α is the heat transmissibility factor, defined using this keyword.

DEFAULT: 0.0

The flux boundary option is discussed in more details in "Flux boundary conditions" in the ECLIPSE Technical Description.
