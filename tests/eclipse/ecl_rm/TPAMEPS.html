This keyword is specific to the coal bed methane option and the ROCKPAMA Palmer-Mansoori rock compaction model.

The data comprises NTCREG (see keyword REGDIMS, item 6) tables of volumetric strain values to be used in the Palmer-Mansoori model as a function of the coal gas concentrations. The table consists of Ncomps +1 columns of data in ECLIPSE 300 and 2 columns of data in ECLIPSE 100. If the SOLVENT model is activated in ECLIPSE 100, the keyword TPAMEPSS should be used to specify the solvent strain term.

Column:

  1. The surface coal gas concentration

    Values should increase monotonically down the column.

    UNITS: sm3/m3 (METRIC), Mscf/ft3 (FIELD), scc/cc (LAB)

  2. The corresponding volumetrics strain term (eps)

    Values should be level or increasing down the column. This look up value replaces the term

    εlβ P1+ βP

    in the normal Palmer-Mansoori formulation. See the ROCKPAMA keyword.

    UNITS: Dimensionless

  3. [Ncomps+1]   The corresponding volumetric strain term for the remaining components.

    Values should be level or increasing down the column.

    UNITS: Dimensionless

The entire table may be defaulted, provided the table is not the first. Defaulted tables are replaced with a copy of the previous table. In a table that is not defaulted, each table must contain at least two, and no more than NSSFUN (set in the TABDIMS keyword) rows. Each row must be complete, containing an entry in every column of the table.

Note: The first column refers to the coal gas of the component, IC, with the corresponding strain value as given in columns IC+1, IC=1, ... Ncomps, and is not the total coal gas concentration.

The coal region number COALNUM is used to look up the table.

See also the "Coal Bed Methane Model" in the ECLIPSE Technical Description for further information.

Example

With (Ncomps = 1 for ECLIPSE 300), NTCREG = 1 specified in the REGDIMS keyword and NSSFUN = 14 specified in the TABDIMS keyword.
