This keyword can be used to specify global-local connections explicitly, rather than have ECLIPSE work them out. If this keyword is entered, then ECLIPSE does not calculate any additional global-local connections for the current refinement. This keyword must be specified when using local grid refinements in an unstructured grid (see the EXTFIN, EXTHOST and EXTREPGL keywords). The keyword should be specified between the corresponding EXTFIN and ENDFIN pair.

The keyword is followed by any number of records, each terminated with a slash (/). End the set of records with a slash.

The items in each record are:

  1. IL, JL, KL The coordinates of the local cell.
  2. IG, JG, KG The coordinates of the connecting global cell.
  3. TRAN The transmissibility for the connection.

    UNITS: cP.rm3/day/bars (METRIC), cP.rb/day/psi (FIELD), cP.rcc/hr/atm (LAB), cP.rm3/day/atm (PVT-M)

    DEFAULT: 0.0

Example

TRANGL
1 2 3   5 3 5  2.0 /
3 2 3   5 6 7  2.0 /
/
