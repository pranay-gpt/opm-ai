The TRDIF keyword inputs the tracer diffusion coefficient. The keyword should be concatenated with the tracer name.

For example:

TRDIFXXX is the keyword required to input the diffusion coefficient for tracer XXX as specified in the TRACER keyword.

The data comprises NTPVT (set in the TABDIMS keyword) tables of diffusion data, each terminated by a slash (/). Each table applies to its corresponding PVT region, defined by keyword PVTNUM (if NTPVT> 1).

Each table consists of one diffusion coefficient for each phase that the tracer exists in.

UNITS: m2/day (METRIC), ft2/day (FIELD), cm2/hr (LAB)

Note: When used with the partitioned tracer option, the diffusion applies to the solution phase. When used with the generalized, multi-partitioned tracer option (that is a tracer with MULT specified in item 4 of the TRACER keyword) independent diffusion coefficients can be entered for each phase that the tracer exists in.

See "Environmental tracers" in the ECLIPSE Technical Description for further information.

Note: Heterogeneous diffusion can be input by making use of the dispersion keywords DISPDIMS, TRDIS, DISPERSE and TRNHD.

Example

With NTPVT = 2 for single phase tracers WT1 and WT2 and partitioned tracers PT1 and PT2:

TRACER
  WT1  WAT /
  WT2  WAT /
  PT1  OIL  1*  WAT /
  PT2  OIL  1*  MULT /
/
