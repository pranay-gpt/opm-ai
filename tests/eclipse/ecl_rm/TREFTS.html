This keyword can only be used with the thermal option (keyword THERMAL in the RUNSPEC section).

TREFTS is an alias for TREFS. This keyword was introduced to facilitate export of thermal data from PVT i. It makes no difference to the simulator whether this keyword or the older TREFS keyword is used.
