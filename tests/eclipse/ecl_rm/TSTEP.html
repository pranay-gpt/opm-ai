x SCHEDULE

The keyword should be followed by up to 1000 real numbers, each of which is a time interval through which the simulator is to be advanced. The data should be terminated with a slash (/).

UNITS: day (METRIC), day (FIELD), hr (LAB), day (PVT-M)

After each timestep a report of the current state of the reservoir is produced (see the RPTSCHED keyword).

Note that repeat counts (for example 6*30.5) can be used if required (with no spaces before or after the asterisk).

If values are specified to several decimal places, item 125 of the OPTIONS keyword should be used to ensure that timestamps of report output are sufficiently accurate.

TSTEP
31 28 31 30 31 30
31 31 30 31 30 31 /
