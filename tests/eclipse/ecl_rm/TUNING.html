The TUNING keyword should be used with great care. In general, the only parameters which may need to be altered from their default values are TSINIT, TSMAXZ and LITMAX. For example, Coning studies usually require a small timestep initially or following a significant well rate change in order to avoid a timestep chop. Changes to other parameters, and in particular to the convergence controls in section 2, are not recommended. See also the keyword NEXTSTEP, and "Convergence reports" in the ECLIPSE Technical Description.

The data comprises 3 records, each of which must be terminated by a slash (/). If a slash is encountered before the end of a record, the remaining items in the record are not altered.
