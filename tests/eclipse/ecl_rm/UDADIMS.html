The UDADIMS keyword enables users to define argument quantities in the SCHEDULE section for well keywords:

  • WALKALIN, WCONINJE, WECON, WFOAM, WSALT, WSURFACT, WAPI, WCONPROD, WELLSTRE, WPOLYMER, WSOLVENT, WTRACER, WELDRAW, WTADD, WTMULT, WINJEDET, WECONCMF, WINJTEMP, WELTARG, WNETDP, WVFPDP

and group keywords:

  • GCONPRI, GCONPROD, GCONINJE, GECON, GCONSALE, GCONSUMP, GRUPFUEL, GRUPSALE, GTADD, GTMULT, GRUPNET, GNETINJE, GSATPROD

and segment keywords:

  • WSEGTABL
  • WSEGVALV

and connection keywords:

  • CECON, CSKIN, CPIFACT and CPIFACTL

and keywords:

  • LINCOM and DELAYACT.

The User-Defined Arguments (UDAs) are specified by a corresponding UDQ, which can either be constants, or be composed of ECLIPSE summary keywords in conjunction with a number of mathematical functions. The required values for UDAs are taken from the corresponding UDQs. A UDA can only be used after the initialization of the corresponding UDQ.

The data consists of some or all of the following items which specify dimensions associated with the UDAs. The data must be terminated by a slash (/).

  1. The number of keyword arguments in which UDQs replace numeric values.

    DEFAULT: 0

  2. This item is used for back-compatibility.

    DEFAULT: 0

  3. The maximum number of unique instances in which a particular UDQ is used in a keyword argument.

    DEFAULT: 100

Item 3 is different from item 1 in some cases. If only the oil rate argument of WCONPROD is specified by a UDQ, then item 1 and item 3 both equal 1. If a second WCONPROD uses a different UDQ, then item 1 equals 2, but item 3 would only need to be 1. However, if the same UDQ is used separately in two lines of WCONPROD data, then both item 1 and item 3 equal 2. (Please note that this is an oversimplified example, since in practice item 3 has a minimum value of 100, so it only needs to be increased for data sets where the same UDQ is used as a UDA more than 100 times.)

Note: Only compatible UDQs are acceptable in the user-defined arguments — for example, for a segment keyword, a segment UDQ must be used.
Note: In the pre-2010.1 version, items 1 and 2 were used for well and group UDAs respectively.
Note: UDAs are associated with the keyword and item for which they are specified. For values which can be specified in more than one way, for instance well targets with both WCONPROD and WELTARG keywords, respecifying a value with a different keyword does not disable a UDA from the first keyword, which will continue to update the value at every report step.

This behavior can be replaced for certain pairs of keywords and items using item 326 of the OPTIONS keyword in ECLIPSE 100 or item 446 of the OPTIONS3 keyword in ECLIPSE 300. For these keyword and item combinations, the UDAs are synchronized and treated as the same UDA when the option switch is set to 1. Additionally, if the option switch is set to 2, if a UDA-controlled item is modified using a keyword such as WTADD, the original UDA will be disabled and no longer update the value.
