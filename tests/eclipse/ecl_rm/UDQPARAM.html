The data consists of some or all of the following items which specify control parameters associated with the UDQ keyword. The data must be terminated by a slash (/).

  1. Integer seed value for the RANDN and RANDU random number functions. This item should be a integer greater than 0.

    DEFAULT: 1

  2. The permitted range (+/-) of the user-defined quantities. This item should be in the range 1.0 to 1.0E+20.

    DEFAULT: 1.0E+20

  3. Value given to undefined elements when outputting data or using in an ACTION ( ACTIONG, ACTIONR, ACTIONW, ACTIONS) keyword. This item should be in the range specified by item 2.

    DEFAULT: 0.0

  4. The fractional equality tolerance used in the ==, !=, <= and >= functions.

    DEFAULT: 1.0E-4

  5. Can be used to activate the enhanced per-well functionality for connection UDQ sets. This item must be set to either WELL or FIELD.

    DEFAULT: FIELD

Example

UDQPARAM
 100 1* -1.0 1* WELL /
