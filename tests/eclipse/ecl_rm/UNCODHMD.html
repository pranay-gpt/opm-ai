This keyword indicates that gradient, or sensitivity, information produced by the simulator for history matching purposes is to be unencoded.

Note: The “ unencodedhmd ” license feature is required in order to use this keyword.

This keyword has no associated data.

It affects the following areas of functionality:

  • When used in conjunction with "Gradient option" in the ECLIPSE Technical Description, this keyword indicates that the HMD file produced by the Gradient option is to be unencoded. By default, the sensitivities contained in the HMD file are encoded and can only be interpreted by SimOpt. If unencoded sensitivities are required for use in an external program, an unencoded gradients license feature is also required.

    ECLIPSE 300

  • When used in conjunction with the "Adjoint gradient screening" in the ECLIPSE Technical Description, this keyword indicates that the sensitivities written to the restart files are unencoded. By default, these sensitivities are encoded.
