In a run with Ncomps components, this keyword associates a critical molar volume with each component, to be used for viscosity calculations only.

If VCRITVIS or ZCRITVIS is not entered, then values entered with VCRIT or ZCRIT will be used.

If multiple equations of state are being used, a set of data should be entered for each reservoir EoS. The number of reservoir equation of state regions is entered in NMEOSR in keyword TABDIMS. The use of multiple EoS regions is discussed in "Equations of state regions" in the ECLIPSE Technical Description.

The form of VCRITVIS is the same as that of VCRIT.

UNITS: m3/kg-M (METRIC), ft3/lb-M (FIELD), cc/gm-M (LAB), m3/kg-M (PVT-M)
