The data is an integer value, specifying the size of the integer table used for fast property lookups. A default size of 1000 is used, but if this does not allow an integer table to be initialized then ECLIPSE 300 suggests using the VECTABLE keyword and report the minimum integer that allows a fast lookup table to be generated.
