If the vertical equilibrium option is being used (keyword VE in the RUNSPEC section), this keyword can be used to specify the relative fractions of the rock relative permeability curve and VE relative permeabilities to be used in the run.

This keyword is used to input the VEFRAC parameter on a cell-by-cell basis.

DEFAULT: 1.0 (throughout the entire grid.)

When VEFRAC is set to 1.0 (the default value), the relative permeabilities derived from the vertical equilibrium model are used, replacing the rock curves entered using keywords such as SWFN.

By setting VEFRAC to a value less than 1.0, it is possible to mix the VE and rock curves; a fraction (1.0 - VEFRAC) of the rock curve and VEFRAC of the VE curve is taken.

The keyword can be used in conjunction with the EQUALS, ADD and MULTIPLY keywords.

See also keywords VEFRAC, VEFRACP, VEFRACPV.
