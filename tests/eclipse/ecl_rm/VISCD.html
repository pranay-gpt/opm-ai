This keyword requests that the viscous displacement mechanism should be modeled in dual porosity runs. If this option is used, the average size of the matrix blocks should be entered with the LX, LY and LZ keywords in the GRID section. VISCD is not available with the PARALLEL keyword.

See "Viscous displacement (ECLIPSE 100)" in the ECLIPSE Technical Description for further information.

The keyword has no associated data.
