Note: This keyword is for use only with the Petrel Reservoir Geomechanics module and you must not add it to ECLIPSE datasets. The information about the keyword is for reference only.

The workflow is described in the "Geomechanics" section of the ECLIPSE Technical Description. In this workflow, the Petrel Reservoir Geomechanics module couples the VISAGE and ECLIPSE simulators, using the ECLIPSE fluid simulation results to compute the geomechanical response of the reservoir to changes in pressure, fluid saturations/composition and temperature. These calculations are performed at particular report steps in the simulation called coupled timesteps.

The Petrel Reservoir Geomechanics module activates the workflow by adding the VISAGE keyword to the RUNSPEC section. It uses the VISDATES keyword to specify a list of report dates to be used as coupled timesteps.

Information about each coupled timestep date must be on a separate line terminated by a slash (/). The data is terminated by a null record (a slash on a line by itself).

A date consists of the following items of data:

  1. The day of the month

    An integer between 1 and 31.

  2. The name of the month abbreviated to three characters

    JAN, FEB, MAR, APR, MAY, JUN, JLY, AUG, SEP, OCT, NOV or DEC.

    JUL is an acceptable alternative to JLY.

  3. The year

    A positive 4 digit integer.

  4. The time

    A string of the format HH:MM:SS.SSSS

    DEFAULT: 00:00:00

Notes

  • If a copupled timestep date does not correspond to a report date then it will have no effect. Duplicate dates are ignored (that is, the simulator will act as though that particular stress step date had only been specified once). Any coupled timestep dates which are specified as being before the simulation start date are ignored.
  • If this keyword is present more than once, the combined list of dates specified in all the VISDATES keywords is treated as the stress step dates for the simulation.
  • The Petrel Reservoir Geomechanics module can only handle a maximum of 9999 stress steps in its workflow. If it requests more than 9999 copupled timesteps in the VISDATES keyword, or if a coupled timestep would be triggered after 9999 stress steps have already occurred, then ECLIPSE will exit with an error.

Example

VISDATES
 1 FEB 1985 /
 1 MAR 1985 11:15:00 /
 1 MAY 1985 /
 1 JAN 1986 11:15:30.3333 /
 1 JAN 1987 /
