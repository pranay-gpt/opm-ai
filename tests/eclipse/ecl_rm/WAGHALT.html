This indicates that the alternative WAG hysteresis model is to be used. This corresponds more closely with the ECLIPSE 100 WAG hysteresis model as compared to the default ECLIPSE 300 WAG hysteresis model. This keyword requires no data items and should be terminated with a slash (/). The hysteresis models are described in more detail under "Hysteresis in WAG floods" in the ECLIPSE Technical Description.
