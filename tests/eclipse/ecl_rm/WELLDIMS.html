The data consists of some or all of the following items, describing the dimensions of the well data to be used in the run. The data must be terminated by a slash (/).

  1. The maximum number of wells in the model.

    DEFAULT in ECLIPSE 100:   0

    DEFAULT in ECLIPSE 300:   10

  2. The maximum number of connections per well (that is the maximum number of grid blocks connected to any one well).

    DEFAULT in ECLIPSE 100:   0

    DEFAULT in ECLIPSE 300:   Number of layers in field

    Note: For models which have a large number of layers and a relatively small number of well connections, defaulting this value can lead to excessively large memory requirements and is not recommended. If supplying a value is difficult, a better approximation of the actual memory requirements for the well connections can be obtained by using the WCOMPRES keyword.
  3. The maximum number of groups in the model.

    DEFAULT in ECLIPSE 100:   0

    DEFAULT in ECLIPSE 300:   5

  4. The maximum number of wells in any one group (or child groups in a group; keyword GRUPTREE).

    ECLIPSE 100

    This is also the maximum number of wells in a particular local grid refinement (keyword WELSPECL).

    ECLIPSE 300

    This is taken as the maximum of the value specified in item 4 and the value specified in item 1.

    ECLIPSE 100

    DEFAULT:   0

    ECLIPSE 300

    DEFAULT:   10

    ECLIPSE 300

  5. The maximum number of stages per separator, including the last stage, which represents the stock tank (see keywords SEPCOND and FIELDSEP).

    DEFAULT:   5

    ECLIPSE 300

  6. The maximum number of well streams (see keyword WELLSTRE).

    DEFAULT:   10

    ECLIPSE 300

  7. The maximum number of mixtures (see keywords WINJMIX and WINJORD).

    DEFAULT:   5

    ECLIPSE 300

  8. The maximum number of separators, including the field separator (see keywords SEPCOND and FIELDSEP).

    DEFAULT:   4

    ECLIPSE 300

  9. The maximum number of mixture items in a mixture (see keywords WINJMIX and WINJORD).

    DEFAULT:   3

    ECLIPSE 300

  10. The maximum number of completions allowed to cross domain boundaries within a parallel run (see "Parallel option" in the ECLIPSE Technical Description).

    DEFAULT:   0

  11. The maximum number of well lists that a well may belong to at any one time (see keywords WLIST and WLISTDYN).

    DEFAULT:   1

  12. The maximum number of dynamic well lists in the simulation (see keyword WLISTDYN).

    DEFAULT:   1

  13. ECLIPSE 300

    The maximum number of secondary wells in the simulation.

    DEFAULT:   10

  14. ECLIPSE 300

    The maximum number of rows available in the generalized pseudo-pressure (GPP) tables used for each well completion to calculate the blocking factor associated with condensate drop-out in gas condensate reservoirs. If the GPP option is not selected or if item 330 of the OPTIONS3 keyword is set 1, this item will be ignored

    DEFAULT:   201
