This keyword controls the calculation of the generalized pseudo-pressure (GPP) option for modeling the effects of condensate drop-out on the fluid mobilities at producing well connections (see "Special inflow equations" in the ECLIPSE Technical Description). The WPICOND keyword is optional and provides an alternative to the PICOND and PSEUPRES keywords. The GPP option can also be activated for individual wells by entering GPP in item 8 of keyword WELSPECS keyword or item 9 of the WELSPECL keyword. The WPICOND keyword affords control over the GPP table calculation parameters on a per well basis and additionally permits the GPP option to be activated or deactivated during the course of the simulation.

The keyword is followed by any number of records, each containing some or all of the following data items terminated with a slash (/). The set of records must be followed by a blank record containing only a slash (/).

  1. Well name, well name template, well list or well list template.

    A template enclosed in quotes can be used to refer to multiple wells or well lists. See "Well name and well list template matching" in the ECLIPSE Technical Description for further details. Well list names should be enclosed in quotes and begin with an asterisk (*). Well lists are constructed with the keyword WLIST.

  2. Select or deselect the generalized pseudo-pressure integral option to be applied to the inflow performance for this well.

    Either YES or NO.

    DEFAULT: YES

  3. The maximum interval between pressure quadrature points below the dew point pressure to be used in the construction of the generalized pseudo-pressure integral table.

    UNITS: bars (METRIC), psi (FIELD), atm (LAB), atm (PVT-M)

    DEFAULT: 4 x atmospheric pressure.

    Note: The interval size used in the construction of the table may differ slightly from the value specified here in order to ensure a set of equally spaced points.
  4. The maximum interval between pressure quadrature points above the dew point pressure to be used in the construction of the generalized pseudo-pressure integral table.

    UNITS: bars (METRIC), psi (FIELD), atm (LAB), atm (PVT-M)

    DEFAULT: 10 x atmospheric pressure.

    Note: The interval size used in the construction of the table may differ slightly from the value specified here in order to ensure a set of equally spaced points.
  5. Blocking factor damping coefficient Df.

    This value must lie between 0.0 and 1.0 and provides a means of damping any oscillations that may result from the explicit calculation of the blocking factor β by averaging it with its value from the previous timestep according to the formula βused=Dfβcurrrent+(1-Df)βprevious.

    DEFAULT: 1.0

    Note: If a value of zero is specified for the damping coefficient, this will result in the blocking factors remaining constant at the previously calculated values for all connections corresponding to the wells matching the well names specified in item 1 above. If this keyword is specified at the start of the simulation prior to any calculation of the blocking factors, the blocking factors will be calculated once and these values will be used as the constant values.
  6. Include velocity dependent relative permeability (VDRP) and Forchheimer effects in the pseudo-pressure calculation.

    Either YES or NO.

    DEFAULT: NO

    If this data item is set to YES, capillary number VDRP and Forchheimer effects will be included in the pseudo-pressure calculation according to the VDRP options selected via the VELDEP keyword. The properties of the capillary number and Forchheimer models are specified via the keywords VDKRO, VDKRG and VDKRGC.

  7. The multiplicative factor Fl which determines the lower pressure bound Pl to be used in construction of the generalized pseudo-pressure integral table. This is expressed as a multiplier upon the current pressure Pb of the grid block containing the well connection, that is, Pl=FlPb.

    This lower bound is the base pressure described in "Generalized pseudo-pressure in ECLIPSE 300" in the ECLIPSE Technical Description. The lower bound should be chosen such that the required range of cell and well pressures will be covered by the pseudo-pressure integral table.

    This is a dimensionless value which should lie between 0.0 and 0.95. The lower limit used will be constrained to the minimum of the value specified and the saturation pressure.

    DEFAULT: 0.0

  8. The multiplicative factor Fu which determines the upper pressure bound Pu to be used in construction generalized pseudo-pressure integral table. This is expressed as a multiplier upon the current pressure Pb of the grid block containing the well connection, that is, Pu=FuPb.

    This upper bound should be chosen such that the required range of cell and well pressures will be covered by the pseudo-pressure integral table.

    This is a dimensionless value which should lie between 1.05 and 2.0.

    DEFAULT: 1.1

  9. Change in water saturation in the grid block containing the well connection which will result in a recalculation of the generalized pseudo-pressure integral table.

    By default, this change is treated as the magnitude of the difference between the current value and the value when the table was previously calculated. This change may alternatively be treated as a fractional value, that is, the magnitude of the difference between the current and previous values normalized by the previous value, if item 330 of the OPTIONS3 keyword is set to 2. In addition, this recalculation control may be disabled by specifying a negative value.

    DEFAULT values:

    • DEFAULT (with OPTIONS3 item 330 = 0): 0.01

      The test is applied to the magnitude of difference between the current and previous values.

    • DEFAULT (with OPTIONS3 item 330 = 2): 0.1

      The test is applied to the magnitude of difference between the current and previous values normalized by the previous value.

  10. Change in saturation or grid block pressure in the grid block containing the well connection which will result in a recalculation of the generalized pseudo-pressure integral table.

    By default, this change is treated as the magnitude of the difference between the current value and the value when the table was previously calculated is applied to both decreasing and increasing pressures. This change may alternatively be treated as a fractional value, that is, the magnitude of the difference between the current and previous values normalized by the previous value, if item 330 of the OPTIONS3 keyword is set to 2. In addition, this recalculation control may be disabled by specifying a negative value.

    DEFAULT values:

    • DEFAULT (with OPTIONS3 item 330 = 0): 1.0 x atmospheric pressure

      The test is applied to the magnitude of difference between the current and previous values.

      UNITS: bars (METRIC), psi (FIELD), atm (LAB), atm (PVT-M)

    • DEFAULT (with OPTIONS3 item 330 = 2): 0.1

      The test is applied to the magnitude of difference between the current and previous values normalized by previous value.

  11. Fractional change in composition (of any component) in the grid block containing the well connection which will result in a recalculation of the generalized pseudo-pressure integral table, that is, for any component, the difference between the current value and the value when the table was previously calculated normalized by the previous value. This recalculation control may be disabled by specifying a negative value.

    DEFAULT: 0.01

  12. Maximum simulation time change between recalculation of the generalized pseudo-pressure integral table. This recalculation control may be disabled by specifying a negative value.

    UNITS: day (METRIC), day (FIELD), hr (LAB), day (PVT-M)

    DEFAULT: -1 (that is, no maximum simulation time change limit imposed)

  13. Adaptive ordinate control.

    A positive value specifies that a set of adaptively spaced ordinates is to be included in the vicinity of the dew-point pressure where the change in mobility with pressure is potentially non-linear. The number of additional ordinates and their spacing in pressure are determined automatically subject to the minimum step size specified in item 14 below.

    DEFAULT: -1 (that is, use regularly spaced pressure ordinates only when constructing the table)

  14. Adaptive ordinate minimum spacing. This is the minimum possible distance between any pair of ordinates when the adaptive ordinate spacing scheme is active.

    UNITS: bars (METRIC), psi (FIELD), atm (LAB), atm (PVT-M)

    DEFAULT: 0.1 x atmospheric pressure.

End the data record with a slash (/).

Notes

  • The lower and upper bound factors (items 7 and 8) can be used to adjust the size of the pressure range covered by the generalized pseudo-pressure integral. In conjunction with the intervals below and above the dew-point pressure (items 3 and 4), these can be used to increase the accuracy of the integration without having to use too many quadrature points (which can be computationally expensive). Unfortunately there is no good rule for selecting these bounds so the defaults should be used unless long calculation times are experienced.
  • The generalized pseudo-pressure integration table recalculation criteria (items 9, 10, 11 and 12) may be used to control the frequency at which the tables are recalculated. If anomalous behavior is observed, for example, unexpectedly high blocking factors, the frequency of recalculation can be increased by reducing the sizes of one or more of the recalculation controls. In addition, if any of items 9, 10, 11 or 12 is set to 0.0, a recalculation will be enforced at each timestep. The overall computation time will increase with the frequency of recalculation. In general, some experimentation may be necessary to find an acceptable compromise between recalculation frequency and calculation accuracy. (If items 9, 10, 11 or 12 are set to a negative value, the associated recalculation control will be disabled.)
  • In some circumstances, a rapidly changing blocking factor may be encountered. Significant damping of the blocking factor, that is, too small a value for item 5 the damping coefficient, can lead to inaccurate results (for example, a sudden change in the well BHP).

    If this problem is encountered, the damping coefficient should be increased to a value close to 1.0. If this does not resolve the problem, setting the well to be a single-segment multisegment well (see item 63 of the OPTIONS3 keyword) may resolve this problem.

  • If the GPP well inflow option has been specified for all wells using the PSEUPRES keyword, the GPP well inflow model will be selected automatically for each well as and when defined via the WELSPECS or WELSPECL keyword. The WPICOND keyword may be used subsequently to deselect the GPP well inflow model for one or more wells. If a well is subsequently redefined via the WELSPECS or WELSPECL keyword, the GPP well inflow model will be selected again if the PSEUPRES keyword has been specified.
  • The default values above for items 3 to 14 correspond to those of the PICOND keyword items 1 to 12 respectively.
  • Item 14 of the WELLDIMS keyword can be used to specify the maximum number of points available in the pseudo-pressure integral table.

Example

The following example illustrates the use of the WPICOND keyword selectively for three wells. Different sets of calculation control parameters are applied to the first two wells (PROD1 and PROD2) for which the GPP well inflow calculation is selected. For the third well (PROD3), the GPP well inflow calculation is deselected. The WPICOND keyword may be specified any number of times during the simulation but can only be applied to wells which have already been defined in the simulation. When a new well is defined, the default calculation control parameters will apply until the WPICOND keyword is specified for this well or until the PICOND keyword is specified for all wells. The default parameters are those described above, but noting that if the PICOND keyword has previously been specified, the calculation control parameters will become the default values (see "Special inflow equations" in the ECLIPSE Technical Description).
