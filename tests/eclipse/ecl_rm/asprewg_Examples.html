Examples

Example 1

The first item of the ASPHALTE keyword is WEIGHT, and precipitation set as a function of pressure:

ASPP1P 
-- pressure
   'P'    /
ASPREWG
-- pressure      % weight
     3000            30.0
     3500            70.0
     4000           100.0 /

Example 2

The first item of the ASPHALTE keyword is WEIGHT, and precipitation set as a function of the molar fraction of the 2nd component.

ASPP1P
-- molar fraction 2nd component
   'Z'   2  /
ASPREWG
--    Z2      % weight
     0.001         100.0
     0.005          70.0
     0.010          10.0 /
