Examples

Example 1

In this example you specify two matrix cells using the NMATRIX keyword and two coal region numbers with COALNUM. The primary matrix grid cells with region number 1 are redefined to have no coal region number and the next sub-grid matrix cell uses the Langmuir /diffusion data for region number 1. The next record is for cells with region number 2. These are also set to conventional pore volume cells while the inner sub-grid matrix cells uses coal region number 3. 

COALNUMR
1 0 1 /
2 0 3/
/

Example 2

In this example you specify the instant desorption model using CBMOPTS. A coal region is then defined for each of the sub-grid matrix cells, while the time dependent method requires coal connections to be with pore volume grid cells or to cells with the same coal region numbers. Instant desorption model coal cells also have pore volume.

Coal region number 1 in the primary matrix grid cells is set to 1. The sub-matrix grid cells are in coal region number 2. The next record specifies that coal region number 2 in the primary matrix grid cells is set to 1, while the following sub-grid matrix cells are in coal region number 3. 

COALNUMR
1 1 2/
2 1 3/
/
