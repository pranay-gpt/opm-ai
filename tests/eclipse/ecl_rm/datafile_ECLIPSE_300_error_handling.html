ECLIPSE 300 error handling

In the event of an error arising during keyword input, the offending line is displayed, with question mark (?) characters under the field that is causing difficulties. The error number quoted may be of two types:

  • Up to and including 100.

    These are errors detected within the ECLIPSE 300 data parser. Descriptions of these errors are given in table 9.1.

  • Above 100.

    System data errors, usually caused by internal read operations used to convert a character to its value.
