Changing pore volumes

As in the case of DEPTH, the calculated pore volumes may be changed. The PORV keyword may be used to set new values for all the cells, or EQUALS, ADD and MULTIPLY to alter boxes of values.

Note: If the pore volume value is added to a cell that is inactive, it remains inactive unless the ACTNUM array is also modified.

ECLIPSE 100

Note: If a cell is defined with zero pore volume in the GRID section, then making it active by changing the pore volume in the EDIT section using PORV, is not allowed with the polymer, surfactant, foam, temperature or environmental tracer options.
