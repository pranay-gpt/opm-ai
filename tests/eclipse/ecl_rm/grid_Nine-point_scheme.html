Nine-point scheme (ECLIPSE 300)

ECLIPSE 300 keyword Description
NINENUM Specifies the extent of the nine-point discretization scheme.
MINPORV9 Set a minimum pore volume for calculation of nine-point transmissibilities.
ORTHERRO Set a minimum orthogonality error for calculation of nine-point transmissibilities.
ORTHERRX Set a minimum orthogonality error for calculation of nine-point transmissibilities for interfaces in the X-direction.
ORTHERRY Set a minimum orthogonality error for calculation of nine-point transmissibilities for interfaces in the Y-direction.
ORTHERRZ Set a minimum orthogonality error for calculation of nine-point transmissibilities for interfaces in the Z-direction.
