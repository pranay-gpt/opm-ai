Examples

Example 1

In the following ECLIPSE 100 example there is a maximum of 3 gradient regions, each with up to 4 subregions with only 6 gradients required and 5 faults (with gradients required for two faults). There are two analytic aquifers with up to 100 grid block connections each and a default influence table.

FAULTDIM
--MFSEGS 
    5    /
AQUDIMS
--MXNAQN  MXNAQC  NIFTBL  NRIFTB  NANAQU NCAMAX
    0       0       1       36       2        100  /
HMDIMS
--MHISTM  NHMSTR  NHRPAR  MFHIST  MHAQUF
    3       4       6       2       2   /
