The ISGL, ISGLPC, ISGCR, ISGU, ISWL, ISWLPC, ISWCR, ISWU, ISOGCR and ISOWCR keywords scale the imbibition saturation table on a block by block basis. The keywords can only be used when both the end-point scaling and hysteresis options are in use (see keywords ENDSCALE and SATOPTS in the RUNSPEC section).

The imbibition tables can be scaled in exactly the same manner as the drainage tables. A full description of the use of each keyword can be found in the documentation of the equivalent drainage keywords, shown in the following table.

Table 247.2 Imbibition saturation table end-point keywords
Imbibition keyword Drainage keyword End-point scaled

ISGLPC SGLPC Connate gas, Pc curves only. ECLIPSE 100
