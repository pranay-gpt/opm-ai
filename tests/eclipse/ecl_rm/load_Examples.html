Examples

Example 1

A typical ECLIPSE 100 fast restart data file has this form.

--
-- Typical ECLIPSE 100 case, restarting from a SAVE
-- file and a RESTART file.
--

LOAD
 'BASE' /
RESTART
 'BASE' 11 /
SCHEDULE
 :
 :
TSTEP
 30.0 /
END

Example 2

A typical ECLIPSE 300 restart from a SAVE file.

--
-- Typical ECLIPSE 300 case, restarting from a SAVE file
--
LOAD 
 'CASE1' 12 /

SCHEDULE
 :
 :
DATES
 1 'FEB' 1990 /
/
END

Example 3

An example NOSIM case in ECLIPSE 100.

--
-- Formatted NOSIM case in ECLIPSE 100
--

LOAD 
 'CASE1' 1* 'NOSIM' 'FORMATTED' /
RESTART
 'CASE1' 12 /
RPTSOL
 1 0 1 1 /
SUMMARY
ALL
SCHEDULE
 :
 :
DATES
 1 'FEB' 1990 /
/
END
