Use dependence on surface tensions in properties (ECLIPSE 300)

The keyword does not require items 1 to 3 above. Any values are skipped. The keyword should be followed by a single slash (/).

If this option is used, parachor values should be entered in the PROPS section using the PARACHOR keyword, or the STVP keyword added to provide the variation of surface tension with pressure.

Note this keyword had no items in pre-99A versions of ECLIPSE 300; existing data sets with this format will continue to run with no apparent difference although it is strongly advised to avoid this deprecated syntax.
