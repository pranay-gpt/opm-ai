ECLIPSE 300

SCHEDULE section

  • An alternative treatment for multiple UDAs which act on the same value in different keywords has been added. Pairs of keywords and items can be equivalenced by setting item 446 of the OPTIONS3 keyword to 1, and setting it to 2 also activates a similar treatment for pairs of keywords and items where a value can be modified directly by a UDA in one keyword and via a different mechanism in another keyword.
  • Chord segment links for looped flow paths are now output to the RFT file for multisegment wells when segment information is requested in the WRFTPLT keyword.
  • Production rates can now be specified using user-defined arguments in items 2, 3, 4, and 5 of the GSATPROD keyword.
  • The reservoir fluid volume production rate target or upper limit can now be specified using a user-defined argument in item 14 of the GCONPROD keyword.
