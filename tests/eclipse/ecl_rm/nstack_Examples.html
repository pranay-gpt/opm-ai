Examples

Example in ECLIPSE 100

There is no point in setting NSTACK larger than the maximum number of linear iterations (see LITMAX in keyword TUNING). The maximum possible NSTACK is printed by ECLIPSE as soon as it has computed the amount of memory required for the run.

NSTACK can only be specified in the RUNSPEC section.

NSTACK
25/

Example in ECLIPSE 300

The maximum number of linear iterations, specified using the CVCRIT keyword, should usually be at least the size of the stack.

NSTACK can be specified in either the RUNSPEC or the SCHEDULE section.

NSTACK
50/
