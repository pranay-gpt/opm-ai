Examples

Example 1

Set DY equal to DX:

OPERATER
--result region  operate  param 
  DY       2     'COPY'    DX   / 
/

Example 2

OPERATER
PERMX   1  'MULTA'  PORO   .444 .5555 /
PERMX   2  'POLY'   PERMX  .234   2   /
PERMX   2  'POLY'   PERMX  .034   3   /
PERMX   2  'POLY'   PERMX  .004   4   /
PERMX   1  'SLOG'   PERMX  .000   1.0 /
PERMX   1  'MULTX'  PERMX  2.44       /
PERMZ   3  'COPY'   PERMX             / 
/

Example 4

Use of work arrays (item 8 of REGDIMS must be appropriately specified).

--result reg   operate  arg   param
OPERATER
WORK1     1    'MULTX'    PORO   .45 /
WORK2     1    'LOG10'    PERMX /
WORK2     1    'MULTIPLY'  WORK1 /
PERMY     1    'ABS'      WORK2 /
 /

--result box   operate  argument  param
OPERATER
IWORK1    1    'MULTX'     SATNUM   2 /
FIPNUM    1    'ADDX'     IWORK1   1 /
 /

For the example above, since two double precision work arrays (WORK1, WORK2) are used, item 8 of REGDIMS should be set to 2; and since only 1 integer work array (IWORK1) is needed, then item 9 of REGDIMS should be set to 1.

  SATNUM    1   'IFLT'    PORO 0.1 2   /
