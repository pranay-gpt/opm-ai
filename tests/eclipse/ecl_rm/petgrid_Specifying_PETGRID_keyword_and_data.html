Specifying PETGRID keyword and data

The PETGRID keyword should be followed by a single data item specifying the complete name, including any suffix, of the . GSG file containing the required grid information.

The PETGRID keyword is incompatible with auto refinement. The grid should be altered inside Petrel in this case.

The data should be terminated by a slash (/).

ECLIPSE 100

CAUTION: This keyword is also not recommended for use with the vertical equilibrium option.
