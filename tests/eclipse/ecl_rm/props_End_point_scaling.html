End point scaling

In some cases the relative permeability and capillary pressure tables vary from cell to cell. Rather than enter large numbers of tables it is possible to scale fixed points on a table to new cell-dependent positions. This may be done horizontally - along the saturation axis - or vertically - rescaling the values of K r and P c.

To use end point scaling, the ENDSCALE keyword should be included in the RUNSPEC section.

See "Saturation Table Scaling" in the ECLIPSE Technical Description.
