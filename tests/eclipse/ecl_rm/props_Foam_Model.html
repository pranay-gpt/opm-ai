Foam Model

This option is available in both simulators, though some keywords are only available in ECLIPSE 100.

Common keywords

Restriction Keyword Description
Functional model FOAMFCN Gas mobility reduction dependence upon capillary number
Functional model FOAMFRM Gas reference mobility reduction factor
Functional model FOAMFSC Gas mobility reduction dependence upon surfactant concentration
Functional model FOAMFSO Gas mobility reduction dependence upon oil saturation
Functional model FOAMFST Gas-water surface tension dependence upon concentration
Functional model FOAMFSW Gas mobility reduction dependence upon water saturation
