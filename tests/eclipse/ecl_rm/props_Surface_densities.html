Surface densities

The three possible surface densities are set using the DENSITY keyword. This is required when formation volumes are used, in order to define reservoir densities. For compositional runs, the equation of state defines the hydrocarbon reservoir densities, and only the water value is required. DENSITY always contains three items, even if water is not present in the run.

DENSITY
--deno     denw       deng
  45.0000  63.0200   .07020 /

If a run has more than one pressure table region set with TABDIMS in the RUNSPEC section, these must be entered in sequence, each terminated by a slash character (/), for both DENSITY and the pressure table data such as ROCK and PVTW. As an alternative to DENSITY, the GRAVITY keyword enables the same data to be entered in specific gravity form.

When using the Brine option, the water density can also be entered with the BDENSITY keyword.
