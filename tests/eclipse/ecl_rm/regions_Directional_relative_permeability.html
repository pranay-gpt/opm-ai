Directional relative permeability

Restriction Keyword Description
Keywords should not be used unless DIRECT is selected in keyword SATOPTS. KRNUMX, KRNUMY, KRNUMZ Saturation table numbers for the +X, +Y, +Z faces of a grid block.
Keywords should not be used unless IRREVERS is also selected in keyword SATOPTS. KRNUMX-, KRNUMY-, KRNUMZ- Saturation table numbers for the -X, -Y, -Z faces of a grid block.
