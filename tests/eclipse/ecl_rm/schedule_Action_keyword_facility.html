Action keyword facility

Keyword Description
ACTION Initiates a set of actions (defined by SCHEDULE section keywords) to be executed when a specified field condition is satisfied.
ACTIONG Defines actions to be triggered by group quantities.
ACTIONR Defines actions to be triggered by region quantities.
ACTIONW Defines actions to be triggered by well quantities.
ACTIONS Defines actions to be triggered by well segment quantities.
ACTIONX Defines actions to be triggered by a set of conditions on various quantities
DELAYACT Defines actions to be triggered a given time after another action has been triggered.
ENDACTIO Indicates the end of the set of actions initiated with the ACTION keyword family.
