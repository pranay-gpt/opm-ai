Alkaline model

The following keywords control output of data specific to the Alkaline Model.

Table 195.1 Alkaline SUMMARY output controls (ECLIPSE 100)
E100 Field Group Well Connection Block Information
x       CTFRALK   Flow Rate (+ or -)
x FTPRALK GTPRALK WTPRALK     Production Rate
x FTPTALK GTPTALK WTPTALK CTPTALK   Production Total
x FTIRALK GTIRALK WTIRALK     Injection Rate
x FTITALK GTITALK WTITALK CTITALK   Injection Total
x         BTCNFALK Concentration
x         BTADSALK Adsorption
x         BTSTMALK Surface tension multiplier
x         BTSADALK Surfactant adsorption multiplier
x         BTPADALK Polymer adsorption multiplier
Note: When requesting output of alkaline or surfactant (or any other active tracer) properties on an LGR, the corresponding SUMMARY mnemonics may exceed 8 characters in length, for example LBTCNFALK or LBTIPTSUR. In these special cases ECLIPSE will recognize the truncated forms of the mnemonics, that is LBTCNFSU and LBTIPTAL.

E300 Block Information
