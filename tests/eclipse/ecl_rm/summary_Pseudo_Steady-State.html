Pseudo Steady-State (ECLIPSE 100)

The following keywords control output of data relevant to the calculation of a pseudo steady state solution, see keyword PSTEADY. They will automatically be output from a steady-state run if the PERFORMA keyword is present in the summary section.

Table 191.1 Steady state SUMMARY output controls
E100 Field Description
x PSSPR Log of the pressure change per unit time, see PSTEADY
x PSSSO Log of the oil saturation change per unit time, see PSTEADY
x PSSSW Log of the water saturation change per unit time, see PSTEADY
x PSSSG Log of the gas saturation change per unit time, see PSTEADY
x PSSSC Log of the salt concentration change per unit time, see PSTEADY
