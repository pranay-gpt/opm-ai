Rivers (ECLIPSE 100)

The following keywords control output of reach data specific to rivers

Table 188.1 River SUMMARY output controls
E100 Segment Information
x SRRQR Reach flow at current time
x SRRQT Reach cumulative flow
x SRBQR Branch flow at current time
x SRBQT Branch cumulative flow
x SRTQR River total flow at current time
x SRTQT River total cumulative flow
x SRRFLOW Reach flux through cross-sectional area at current time
x SRRAREA Reach area at current time
x SRRDEPTH Reach depth at current time
x SRREXCH Exchange flux at current time
x SRRFRODE Reach Froude number at current time
x SRRHEAD Reach hydraulic head at current time
x SRTFR Reach tracer flow rate
x SRTFC Reach tracer concentration
x SRSFR Reach brine flow rate through connections
x SRSFC Reach brine concentration

The river reach controls are:

Table 188.2 River reach SUMMARY controls
E100 Connection Information
x CRREXCH Exchange flux at current time
x CRRPROT Connection cumulative water production
x CRRINJT Connection cumulative water injection
