Solvent Model (ECLIPSE 100)

The following keywords control output of data specific to the Solvent Model.

Table 193.1 Solvent SUMMARY output controls (ECLIPSE 100)
E100 Field Group Well Connection Region Block Information
x       CNFR     Solvent Flow Rate (+ or -)
x FNPR GNPR WNPR       Solvent Production Rate
x FNPT GNPT WNPT CNPT     Solvent Production Total
x FNIR GNIR WNIR     Solvent Injection Rate
x FNIT GNIT WNIT CNIT     Solvent Injection Total
x           BNSAT Solvent SATuration
x FNIP       RNIP BNIP Solvent In Place
x         RNFT Solvent inter-region Flow
x         BNKR Solvent relative permeability
Note: ECLIPSE reports the field, group and well gas rates and totals for the total gas phase, including the solvent gas. The connection gas flow rates and totals are reported solely for the component gas phase, excluding the solvent gas.
