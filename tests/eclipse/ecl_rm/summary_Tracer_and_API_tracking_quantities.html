Tracer and API tracking quantities

The tracer and API tracking options are given in the table below. Notes for this table:

  1. ECLIPSE 100 tracer production rates and totals are in units defined using the TRACER keyword. ECLIPSE 300 tracer production rates and totals depend upon the component that carries the tracer; for water components the units are the same as water production rates and totals, and are based on water properties for the simulation. For other components the rates and totals are as for wet gas, and are determined from molar rates using the ideal gas law.

Keywords which belong specifically to the Tracer Tracking option (that is with T as the second letter in the list above) should be compounded with the name of the tracer to which they refer. For example, if the field production rate of a tracer called OL1 is required on the Summary files, then the keyword FTPROL1 should be used.

Note: Small errors in the material balance may lead to large fluctuations in the reported concentrations where the fraction of the host phase is very small. This is most evident at the block level. These fluctuations can be limited by reducing the maximum material balance and linear convergence errors using the TUNING keyword.
