How to use conditional UDQs

A UDQ can take a certain value depending on a predefined condition. In the example below

UDQ
DEFINE FUBOOL WBHP I > 3573 /
DEFINE WUMULT ((1-FUBOOL)*2.5) +(FUBOOL*1.5)/
/

The value of WUMULT, 2.5 or 1.5 in this example, depends on the value of BHP in well I. The same syntax can be used for a multiple condition.

UDQ
DEFINE FUBL1 WBHP I > 3573 /
DEFINE FUBL2 WWIR I < 6200 /
DEFINE WUMULT (FUBL1*1)+((1-FUBL1)*((FUBL2*2)+((1-FUBL2)*3)))/
/
