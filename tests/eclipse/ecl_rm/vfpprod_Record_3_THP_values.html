Record 3:THP values

Enter in ascending order, terminated with a slash (/).

The number of values, NTHP, must be between 1 and MXMTHP, which is item 2 in VFPPDIMS. If only one value is entered, the derivative of the BHP w.r.t. the THP is treated as unity.

UNITS: barsa (METRIC), psia (FIELD), atma (LAB), atma (PVT-M)
