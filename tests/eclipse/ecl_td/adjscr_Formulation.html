Formulation

ECLIPSE forces the fully implicit residual in each simulator grid block, R, to be zero (see "Formulation of the equations") by solving for solution variables X (t) at discrete points in time, t1,t2,… ,tN , so that for a dynamic well parameter, the following vector notation can be used.

W[X( t)]→W ̲=[W[X( t1 )] W[X(t2 )] … W[X( tN )] ]≡[ W 1 W2 … WN ]

Assuming that a parameter p, which is normally a constant in the flow equations, can be varied, then W= W(p, X(t,p )) which has the following differential:

dW=( ∂W∂ p)⋅ dp+( ∂W∂X)⋅ dX [Eq. 838.1]

and that the flow equations still have to be honored:

dR 1( X1,X0 ,p) =0 dR2( X2 ,X 1,p)=0d R3 (X3,X 2,p)= 0… … dRN(X N, XN-1,p)= 0 [Eq. 838.2]

then the term containing solution variables in equation 838.1 can be eliminated. To do this, apply Lagrange multipliers, Ψ, for each equation in equation 838.2, and insert them into equation 838.1 to give the following:

dWdp ={( ∂W∂ p)+Ψ⋅(∂ R∂p )}+{(∂W ∂X)+Ψ⋅( ∂R∂X )}⋅ dXd p [Eq. 838.3]

Then choose the Lagrange multipliers so that the right hand term in equation 838.3 is equal to zero - this choice has the benefit that there is no need to calculate the (expensive) dX/d p term.

These Lagrange multipliers can be represented as a lower triangular matrix:

Ψ=Ψ 1,1 000… Ψ2, 1Ψ2,20 0…Ψ3,1 Ψ3, 2Ψ3,30 ……… ……… ΨN,1 …ΨN,N-2 ΨN ,N-1 ΨN ,1N

where both row and column indices indicate the report step number.

So, at each time level, k, the Lagrange multipliers can be calculated by solving the “adjoint” equations, equations 838.4 and 838.5:

∂Wk∂ Xk +Ψ k,k ⋅∂Rk ∂X k=0 [Eq. 838.4]
Ψk,m ⋅∂ Rm ∂X m+ Ψk,m+1 ⋅∂Rm+1 ∂Xm =0 [Eq. 838.5]

where m= 1,…, k-1.

The residual derivatives required in this system are the same as the ones already used in the non-linear iterations inside the simulator, so they are already calculated and available for this method to use.

Note: With this adjoint method, the number of equations that must be solved grows quadratically with the number of report steps. However, for a given report step, the number of parameters are not limiting as the residual derivatives required in equation 838.3 are relatively cheap to obtain.
