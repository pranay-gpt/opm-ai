Summary of keywords

RUNSPEC section

ALKALINE activates the Alkaline model.

PROPS section

Restriction Alkaline model keyword Description
Only if the surfactant option is activated. ALSURFST tables of oil/water surface tension as a function of alkaline concentration.
Only if the surfactant option is activated. ALSURFAD tables of surfactant adsorption as a function of alkaline concentration.
Only if the polymer option is activated. ALPOLADS table for polymer adsorption as a function of alkaline concentration.
  ALKADS table for alkaline adsorption function as a function of alkaline concentration
  ADSORP analytical adsorption isotherm (alternative to ALKADS)
  ALKROCK alkaline-rock adsorption/desorption properties

SUMMARY section

Refer to Alkaline SUMMARY output controls in the ECLIPSE Reference Manual.

SCHEDULE section

Keyword Description
RPTSCHED Controls output from the SCHEDULE section to the print file. Mnemonic ALKALINE outputs the alkaline concentrations and the alkaline adsorption when active.

Outputs are:

  • ALKALINE: alkaline concentration
  • ALKADS: alkaline concentration adsorbed
  • ALKMAX: maximum alkaline concentration adsorbed
WALKALIN Specifies the alkaline concentration for a water injector. This concentration can be set as a UDA (user-defined argument).
