Summary of keywords

RUNSPEC

  • AQUDIMS sets dimensions for aquifers

GRID

Restriction Keyword Description
  AQUCON specifies connection data for numerical aquifers
  AQUCT specifies the property data for Carter-Tracy aquifers
ECLIPSE 100 AQUNNC set non-neighbor connection values explicitly for numerical aquifers.
  AQUNUM assigns a numerical aquifer to a block.
  INIT send aquifer connection data to the INIT file: Aquifer connection arrays AQUIFERN, AQUIFERA and AQUIFERG are written to the INIT file depending on whether numerical or analytic aquifers are present.
  RPTGRID controls output from the GRID section to the print file: Use AQUCON and AQUNUM to output numerical aquifer connections and definitions respectively

PROPS

Restriction Keyword Description
ECLIPSE 300 AQUCT specifies the property data for Carter-Tracy aquifers
  AQUTAB influence function tables for Carter-Tracy aquifers.
ECLIPSE 100 RPTPROPS controls output from the PROPS section to the print file: AQUTAB outputs Carter-Tracy influence tables.

SOLUTION

Restriction Keyword Description
  AQANCONL specifies local grid refinement connection data for analytic aquifers
ECLIPSE 100 AQANNC sets connection values explicitly for analytic aquifers.
  AQANTRC sets initial tracer concentrations for analytic aquifers.
ECLIPSE 300 AQSTREAM sets the composition of the injected gas stream for an AQUCHGAS aquifer; or sets the composition of the water analytic aquifers AQUCHWAT, AQUCT, AQUFETP or AQUFLUX for the GASWAT and CO2STORE options.
ECLIPSE 300 AQSTREAW sets the composition of a multi-component water analytic aquifer
ECLIPSE 100 AQUALIST sets up lists of aquifers for output
  AQUANCON specifies connection data for analytic aquifers
  AQUCHGAS specifies the property data for constant head/pressure gas aquifers
  AQUCHWAT specifies the property data for constant head/pressure water aquifers
  AQUCT specifies the property data for Carter-Tracy aquifers
ECLIPSE 100 AQUFET specification data for Fetkovich aquifers
  AQUFETP specifies the property data for Fetkovich aquifers
  AQUFLUX specifies a constant flux aquifer
ECLIPSE 100 RAINFALL specifies a monthly varying flux rate for a constant flux aquifer.
  RPTSOL controls output from the SOLUTION section to the print file:

To output analytic aquifer data such as Fetkovich, Carter-Tracy, Constant Flux or Constant Head use the AQUFET, AQUFETP, AQUCT, AQUFLUX, AQUANCON or AQANCONL arguments.

ECLIPSE 100: If set to 2: data for each aquifer-grid block connection will also be printed (input using AQUANCON).

ECLIPSE 300: Data for each aquifer-grid block connection will be printed using the argument. Note: AQUFET applies only for ECLIPSE 100.

Note: AQANCONL applies only for ECLIPSE 300

  • Numerical aquifer quantities

SCHEDULE

Restriction Keyword Description
  AQSTREAM sets the composition of the injected gas stream for an AQUCHGAS aquifer; sets the composition of an AQUCHGAS aquifer; or sets the composition of a GASWAT water analytic aquifer
ECLIPSE 300 AQSTREAW sets the composition of a multi-component water analytic aquifer.
  AQUCHGAS specifies the property data for constant head/pressure gas aquifers
  AQUCHWAT specifies the property data for constant head/pressure water aquifers
  AQUCT specifies the property data for Carter-Tracy aquifers
ECLIPSE 100 AQUCWFAC changes the property for all constant head aquifers
  AQUFETP specifies the property data for Fetkovich aquifers
  AQUFLUX specifies a constant flux aquifer
ECLIPSE 100 RAINFALL specifies a monthly varying flux rate for a constant flux aquifer.
ECLIPSE 300 RPTPRINT controls output of printed reports. Use item 13 of keyword to report aquifer flows.
  RPTSCHED controls output from the SCHEDULE section to the print file:

Use AQUCT to output the Carter-Tracy aquifer status or AQUFET, AQUFETP to output the Fetkovich aquifer status.

Use AQUCHWAT, AQUCHGAS and AQUFLUX to output constant head/pressure or flux aquifer information.

Note: AQUFET applies only to ECLIPSE 100.
