The polymer flood option

ECLIPSE 100

The polymer flood model (see "Polymer flood model"), activated using the option POLYMER in the RUNSPEC section, allows you to investigate the effect of varying brine concentrations on the efficiency of the polymer flood. The study of the interaction of brine with the polymer solution is, however, optional within the model.

For models which have the polymer and brine options activated, the viscosity of a fully mixed polymer solution needs to be entered as a function of the salt concentration. The keywords SALTNODE and PLYVISCS should be used to enter two-dimensional tables for the viscosity of the solution. The maximum polymer and salt concentrations to be used in calculating the effective fluid component viscosities are entered using the keyword PLYMAX.

The polymer adsorption can be set to depend on the brine concentration and on the rock permeability using the ADSORP keyword with POLYMER as an argument. Polymer adsorption can also be set to depend on brine concentration using the keywords PLYADSS and ADSALNOD.

The concentration of polymer and salt for the injection wells can be specified using the WPOLYMER keyword. The default polymer and salt concentrations are zero.

Multi-component brine and polymer

ECLIPSE 100

The multi-component brine model (ECLMC keyword in the RUNSPEC section) cannot currently be used with the polymer/brine flood model (that is, the combination of polymer and brine using the SALTNODE keyword; ECLMC can be used with the basic polymer flood model).
