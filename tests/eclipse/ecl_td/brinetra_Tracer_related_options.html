Tracer related options

ECLIPSE 100

As brine is modeled as a tracer it is possible to use some of the tracer related options for brine. It is possible to use a form of velocity and concentration dependent dispersion using the keywords TRDIS, DISPERSE and DIAGDISP. The tracer dispersion option is activated by specifying DISPDIMS in the RUNSPEC section.

For a brine tracer it is possible to replace the tracer concentration dispersion dependence by water density dispersion dependence by using the keyword DSPDEINT.
