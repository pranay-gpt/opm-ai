GASWAT

The GASWAT option uses a modified Peng-Robinson equation of state in order to model gas/aqueous phase equilibriums.

GASWAT allows a multi-component gas phase. CO2, N2, and H2S solubilities in water are treated with the Peng Robinson equation of state (EOS) modified by Soreide and Whitson. However, solubilities of other gases like methane are treated by the original Peng Robinson EOS by default. "GASWAT option" provides an exhaustive description of this feature.

Molecular diffusion between gases can be modeled using the DIFFUSE option. See "Diffusion".
