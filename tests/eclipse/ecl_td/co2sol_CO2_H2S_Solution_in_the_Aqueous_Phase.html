CO2/H2S solution in the aqueous phase

ECLIPSE 100
x ECLIPSE 300

The CO2 and H2S solution algorithm allows carbon dioxide and/or hydrogen sulfide to dissolve in the aqueous phase. This is switched on using respectively the CO2SOL and/or H2SSOL keyword in the RUNSPEC section. The basic model is a fugacity function for aqueous CO2 and H2S which is constructed to match solubility data and which takes the form:

fco2 A=PaC O2 φ CO 2(P) [Eq. 429.1]

fH 2S A=P aH2S  φ H2S (P)

The phase equilibrium between the aqueous CO2 or H2S and the hydrocarbon phases is then defined by the conditions that the fugacity values are equal. It is also possible to construct a CO2 and H2S aqueous phase Gibbs energy contribution.

The water phase properties may be entered using the SOLUBILI keyword. Alternatively, a default set of data is provided for CO2:

  • The CO2 solubility is calculated from the correlations of Chang et al (1998).
  • The effects of salt and CO2 on water density are calculated using Ezrokhi’s method (Zaytsev and Aseyev, 1993)
  • Water compressibility and viscosity are taken from the PVTW data.

For H2S no default values exist.

To obtain details of the solubility data used in a simulation the SOLU mnemonic may be specified with the RPTPROPS keyword.

The function φ(P) is constructed by considering a pure CO2 or H2S/aqueous mixture. The gas phase fugacity is obtained using the equation of state.

The initial dissolved CO2 or H2S solubility as a function of depth may be specified using the RSWVD keyword. This initial solution honors this value unless it exceeds the saturated CO2 concentration in which case the saturated value is used.

Notes

  • The initial CO2 or H2S concentration may not be in exact equilibrium with the hydrocarbon phases and initial flash modifies the input values slightly.
  • The first line of the solubility table defined using the SOLUBILI keyword represents water at standard conditions, when the dissolved CO2 or H2S amount is at a minimum. The simulator does not assume that the amount of CO2 or H2S in water at the lowest pressure is zero; if you want to specify it as such then you should set it to zero in the first line of the table. The data of this first line can be set to obtain a satisfying density of water with a small amount of dissolved CO2 or H2S.

For further information see "CO2SOL".

Water solubilities of both CO2 and H2S

If both components are made soluble this should be entered by the keywords SOLUCO2H and SOLUH2SC specifying the solubility of CO2 in the presence of H2S and the solubility of H2S in the presence of CO2. Please note that no default values exist in this case. If only CO2 or H2S is made soluble the keyword SOLUBILI is used to specify either CO2 or H2S as the component reacting with the aqueous phase.

Note: The CO2 component is always regarded as the first component followed by the H2S component when entering composition dependent data with RSW or AMF.
