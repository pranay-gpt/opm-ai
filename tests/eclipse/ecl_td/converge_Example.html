Example

If 'CONV=40' is used with the RPTRST keyword, then the three records CONV_VBR, CONV_PRU and CONV_NEW are output to the RESTART files during the simulation. If a given cell reports a value of 1000 for the CONV_VBR data then this implies that the cell has been in the top 40 cells with the largest volume balance residual for 1000 non-linear iterations in the simulation so far. Similarly for the CONV_PRU data and the pressure solution update. If a cell reports a value of 3 for the CONV_NEW data then this implies that at the previous timestep that particular cell satisfied the solution change convergence criteria on the 3rd non-linear iteration.
