Compatibility

The feature has been made explicitly compatible with the restart mechanism, and will run in parallel mode. It is currently restricted to family (ii) saturation table keywords - SWFN, SGFN and SOF2/SOF3.

The development is known not to be compatible with the following options:

  • radial grids
  • analytic saturation functions
  • MPFA
  • Up-front memory
  • LGRs
  • The Leverett J-function option per saturation function JFUNCR
