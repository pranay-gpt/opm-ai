Summary of keywords

RUNSPEC section

Keyword Description
TRACERS Specify dimensions and options for tracers.
EQLDIMS Specify dimensions for tracer concentration versus depth tables used for equilibration.
PARTTRAC Enables and dimensions the partitioned tracer option.

PROPS section

Keyword Description
RPTPROPS Controls output from the PROPS section: TRACER outputs passive tracer names. TRADSxxx, TRROCK and TRDCYxxx output environmental tracer properties.
TRACER Define the tracers.
TRACERKP Define the partitioning functions K(P) for partitioned tracers (max two phases).
TRACERKM Define the partitioning functions K(P) for partitioned tracers (any no. of phases).
TRADS Specify adsorption data (tabulated isotherm).
ADSORP Specify adsorption data (coefficients for analytical isotherm).
TRDCY Specify decay data.
TRDIF Specify diffusion data.
TRROCK Specify rock data for adsorption.

REGIONS section

Keyword Description
RPTREGS Controls output from the REGIONS section: TNUM outputs tracer versus depth region numbers.
TNUM Specify tracer concentration regions.
TRKPFxxx Specify partitioning function regions for tracer xxx.

SOLUTION section

Keyword Description
RPTSOL Controls output from the SOLUTION section: FIPTR outputs tracer fluid in place reports ROCKMASS outputs rock mass TBLK outputs initial grid block tracer concentrations TVDP outputs initial tracer concentration versus depth tables.
TBLK Specify initial tracer concentrations.
TVDP Specify initial tracer concentration versus depth.

SUMMARY section

Refer to Environmental tracer SUMMARY output controls in the ECLIPSE Reference Manual.

SCHEDULE section

Keyword Description
RPTSCHED Controls output from the SCHEDULE section: FIPTR outputs tracer fluid in place reports TBLK outputs initial grid block tracer concentrations TRADS or TRDCY output tracer adsorption and decay.
WTRACER Set tracer concentration in injection wells.
RIVTRACE Set tracer concentration for injection into rivers.
