Temperature dependent well cutback

Well production rates can be reduced if the well temperature exceeds given limits. Keywords TCBDIMS and WELLTCBT can be used to set up tables of temperatures and cut back factors. The keyword WELLTCB can be used to associate a well with a table and the keyword WELLTCBC can be used to control the switching from one rate to another. Note, these keywords have no effect if the well is controlled by BHP.

The WECON keyword can also be used to close a well if the temperature exceeds a given limit.
