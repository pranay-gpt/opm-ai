Thermal features

Heat loss

Heat loss to the overburden, underburden and sides of the reservoir can be modeled. The ROCKDIMS, keyword should be used to define the number of rock types outside the reservoir. Each rock type can have different properties, defined using the ROCKPROP keyword. The ROCKCON keyword is used to define which cells on the edge of the reservoir connect to each rock type, and the ROCKCONL keyword is used to specify the local grid refinement connection data for these cap and base rocks.

Two methods can be used to calculate the heat loss, a numerical method and an analytic method. In the numerical method the heat loss rate per unit area is given by

- k⋅∂ T∂n |n=0

where

k is the conductivity, and

the temperature gradient outside the reservoir ∂T∂ n is found by solving the temperature equation

c ⋅∂T ∂t =k⋅ ∂2 T∂ n2

where c is the rock heat capacity.

In the analytic method, Vinsome and Westerveld’s approximate solution of the temperature equation is used ( Vinsome and Westerveld, 1980 ). The heat loss per unit area in time Δt is given by

∫0∞ c⋅T(t+Δt )dn-∫0∞ c⋅T(t)dn

Summary keywords FHLR and FHLT can be used to obtain information on the field heat loss rate and field heat loss total.
