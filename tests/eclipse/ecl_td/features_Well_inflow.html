Well inflow

Keywords COMPMOBI and COMPMBIL can be used to set the mobility used in calculating the completion flow for injection wells. Alternatively keywords COMPKRI and COMPKRIL can be used to set the relative permeability used in calculating the completion flow for injection wells.

Use of these keywords may improve the speed and stability of thermal runs - although there may be a slight loss in accuracy of the calculated injector BHP. This is not usually a matter of concern if the well is on a rate control. Furthermore, for steam injection, the injection pressure may not depend strongly on the mobility.

Keywords COMPAGH and COMPAGHL can be used to set average gravity heads for completions.

See "Well Inflow Performance" for further information on well inflow calculations.
