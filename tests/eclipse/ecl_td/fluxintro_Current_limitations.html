Current limitations

  • DUMPFLUX and USEFLUX cannot be used simultaneously in the same run.
  • SUMMARY section keywords which depend upon information from outside of the active region in a USEFLUX case will not include that information; volume quantities such as fluid in place will not sum in volumes from inactive cells and flow quantities will not include flows where either cell is inactive.

    Gas Field Operations

  • The flux boundary option should not be used in conjunction with automatic DCQ reduction in the gas field operations model.

    Parallel Option

  • Using DUMPFLUX, the WARP linear solver cannot be used, instead the pre-2002A linear solver is activated.
  • The nine-point schemes (NINEPOIN keyword) cannot be used when the flux boundary option is used.
