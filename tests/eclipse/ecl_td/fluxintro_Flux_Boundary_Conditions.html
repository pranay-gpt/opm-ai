Flux boundary conditions

x ECLIPSE 100
x ECLIPSE 300

Flux boundary conditions enable runs to be performed on a small section of a field using boundary conditions established from a full field run. Flows across the boundary of the reduced field are written to a FLUX file at each mini timestep of the full field run.

The FLUX file is read during the reduced field run to generate the appropriate boundary conditions. Timesteps of the reduced field run may be quite different from those of the full field run.

A small amount of editing is required to convert a full field run that generates a FLUX file into a run, which runs one or two flux regions with the appropriate boundary flows being read from the FLUX file.
