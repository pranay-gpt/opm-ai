Reading ECLIPSE 100 flux files into ECLIPSE 300

Flux runs are usually run by ECLIPSE 300 and use a FLUX file generated by ECLIPSE 300. It is possible to read an ECLIPSE 100 FLUX file. An ECLIPSE 100 FLUX file contains flows in terms of stock tank oil and gas volumes, and you must then also enter XSTC and YSTC, the stock tank oil and gas compositions, in order that the program can generate component flows.

It is not possible to use an ECLIPSE 100 FLUX file to run a thermal reduced data nor it is possible to use it to run a model with the "Water components" option active.
