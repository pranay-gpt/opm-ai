Summary of keywords

RUNSPEC

  • REGDIMS Item 4 specifies the maximum number of flux regions in the run.

GRID

Restriction Keyword Description
  ADDREG Adds a constant to the specified array in a flux region.
  COPY Copies data from one array to another.
  DUMPFLUX Makes a full field run write a FLUX file.
  EQUALREG Sets an array to a constant in a flux region.
  FLUXNUM Identifies extent of each flux region.
  FLUXREG Identifies which flux regions are active.
  FLUXTYPE Specifies the type of flux boundary condition.
  MULTIREG Multiplies an array by a constant in a given flux region.
ECLIPSE 100 RPTGRID Controls on output from the GRID section: FLUXNUM outputs flux region numbers.
  USEFLUX Specifies the FLUX file used for a reduced run.
ECLIPSE 100 USENOFLO Allows a USEFLUX data set to be run without a FLUX file.
ECLIPSE 300 XSTC Specifies oil composition at standard conditions.
ECLIPSE 300 YSTC Specifies gas composition at standard conditions.
ECLIPSE 300 THFLXTF Specifies the heat transmissibility or flow transmissibility ratio T

Options keywords

Restriction Keyword Description
ECLIPSE 100 OPTIONS Activates special program options

item 25: Drainage regions are written to the DEBUG file.

item 65: Remove certain error messages about wells connecting in multiple flux regions, or for local grids adjacent to flux boundaries in a DUMPFLUX run.

item 232: Removes the ban on EOR/tracer functionality with DUMPFLUX and USEFLUX runs. In this case, you must ensure that on EOR/tracer data is needed from outside the flux boundary.
ECLIPSE 300 OPTIONS3 Activates special program options

item 69: Remove certain error messages about wells connecting in multiple flux regions in a DUMPFLUX run.

ECLIPSE 300 FLUXOPTS Activates special program options

Item 1: When set to YES, makes a full-field run output the necessary information for a thermal reduced run.

Item 2: Provides a factor to improve convergence on non-thermal reduced models.
