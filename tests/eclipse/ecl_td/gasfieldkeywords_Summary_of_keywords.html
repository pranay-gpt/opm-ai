Summary of keywords

RUNSPEC

Restriction Keyword Description
ECLIPSE 100 GASFIELD Enables special options in the gas field operations model: the extended compressor option, multiple contract groups, and the accelerated iteration scheme for calculating the DCQ. The keyword may be omitted if the gas field operations model is used without these options.

SUMMARY

Refer to Gas field operations SUMMARY keywords in the ECLIPSE Reference Manual.

SCHEDULE

Restriction Keyword Description
ECLIPSE 100 COMPOFF Switches off automatic compressors defined by the GASFCOMP keyword (or NETCOMPA if you are using the extended network model).
  GASBEGIN Denotes start of keywords to go into the annual scheduling file. This is required only if you want to change well controls or request printed reports in the middle of a contract period, when using GASYEAR or GASPERIO to advance the simulation
Required only if there is an annual scheduling file. GASEND Denotes end of keywords to go into the annual scheduling file.
ECLIPSE 100 GASFCOMP Defines automatic compressors in network branches. Omit this keyword if you do not require automatic compressors. If you are using the extended network model (see "The extended network model"), automatic compressors must be defined with keyword NETCOMPA instead.
  GASFDELC Specifies the definition of the delivery capacity. If this keyword is omitted, the default definition is used, in which all group and well limits are honored except those on the group and field gas production rate.
  GASMONTH Denotes the times within each year that operations on the annual scheduling file should be performed, and requests printed reports. Omit this keyword if there is no annual scheduling file (see GASBEGIN and GASEND).
  GASPERIO Advances the simulation through one or more complete contract periods, with the field sales gas target set equal to the DCQ multiplied by the monthly Profile Factor. Offers the option of automatic DCQ reduction to obey the Swing Requirement. TIME, TSTEP or DATES may be used instead, but the field target rate would have to be set manually each month and there would be no option of automatic DCQ reduction.
  GASYEAR Advances the simulation through one or more complete contract years. This may be used instead of GASPERIO if the contract period is exactly one year.
  GDCQ Sets the initial DCQs for individual contract groups. This keyword should only be used if there are multiple contract groups (keyword GSWINGF must be entered previously), in which case it must be entered before the first GASYEAR or GASPERIO keyword, and optionally again at later times if the initial DCQs need to be reset.
ECLIPSE 100 GDCQECON Defines a minimum economic DCQ value for a contract group. All the producers in this group are shut when the DCQ falls below its minimum economic value. If the group is the FIELD, the run is terminated.
  GSWINGF Turns on the gas field operations model in the multiple contract groups mode. It identifies the groups having gas supply contracts, and sets their swing and profile factors. Use this keyword only if you wish to apply separate gas supply contracts to two or more individual groups, in which case the keyword should be used in place of SWINGFAC
ECLIPSE 100 NETCOMPA Defines automatic compressors in the extended network model. use this instead of GASFCOMP if you are using the extended network mode
ECLIPSE 100 OPTIONS Item 34 prevents wells being drilled automatically in the second pass of the contract period, in the same month that they were drilled in the first pass, if they are not needed to meet the second pass production target.
ECLIPSE 100 SWINGFAC Specifies the swing factors and profile factors for each month, which are applied to the FIELD. Use this keyword if you wish to apply a single gas supply contract to the FIELD. (If you wish to apply separate gas supply contracts to two or more groups, use keyword GSWINGF instead.) Use of either SWINGFAC or GSWINGF is compulsory, as they both turn on the gas field operations model. They activate the following features:
  • Calculation of the delivery capacity
  • Automatic compressor switching
  • Control of sales gas rate instead of gross production rate.
ECLIPSE 100 GASFTARG Specifies a gas rate at which the field is to be produced in the second pass of the gas field operations model.
ECLIPSE 100 GASFDECR Specifies a decrement to the gas rate at which the field is to be produced in the second pass of the gas field operations model.
