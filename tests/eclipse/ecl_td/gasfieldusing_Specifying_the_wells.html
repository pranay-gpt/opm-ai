Specifying the wells

Specify the wells in the usual way with WELSPECS, COMPDAT and WCONPROD (and WCONINJE for any water injectors). The optional keywords (for example WECON, WEFAC) are not mentioned explicitly in this example.

If there is a multilevel grouping hierarchy (more than one level of groups below the FIELD), set it up with GRUPTREE. For the purposes of this example, consider a grouping hierarchy as given by:

GRUPTREE
--  CHILD     PARENT
    PLAT-A    FIELD   /
    PLAT-B    FIELD   /
    G-B1      PLAT-B  /
    G-B2      PLAT-B  /
/
