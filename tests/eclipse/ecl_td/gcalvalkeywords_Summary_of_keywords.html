Summary of keywords

SUMMARY section

Refer to Gas calorific value control option in the ECLIPSE Reference Manual.

SCHEDULE section

Keyword Description
CALTRAC Specifies which tracer is to be equated with the calorific value.
DCQDEFN When using the Gas Field Operations Model, use this to tell ECLIPSE whether the DCQ targets refer to energy or gas rate.
GCALECON Allows minimum economic energy rates and mean calorific values to be defined for groups and the field.
GCONCAL Specifies the target calorific value for a group or the field.
GCONENG Specifies the target energy rate for a group or the field.
GUIDECAL Scales the guide rates calculated for each well by a function of the well's calorific value.
WCALVAL Specifies the calorific value of gas at a well.
