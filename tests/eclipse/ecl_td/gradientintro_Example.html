Example 1

To set three transmissibility multiplier parameters (with NX=3 NY=3 NZ=3), set the number of parameters, gradient regions and subregions using RUNSPEC keyword HMDIMS 

HMDIMS
  1 1 3 /

and set appropriate keywords in the REGIONS section

HMTRANZ
 3*0 3*1 3*0 /
COPY
 'HMTRANZ' 'HMTRANX' /
/
EQUALS
 'HMTRANY' 9*1 /
/

Example 2

To set one pore volume multiplier parameter (with NX=3 NY=3 NZ=3), set the number of parameters, gradient regions and subregions using RUNSPEC keyword HMDIMS 

HMDIMS
  1 1 1 /

and set appropriate keyword in the REGIONS section

HMPORVM
 3*0 3*1 3*0 /
