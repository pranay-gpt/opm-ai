Miscellaneous keywords

Keyword Description
GRADRESV Specifies derivatives of solution quantities to be output to the RESTART file.
GRADRFT Specifies derivatives of RFT quantities to be output to the RFT file.
GRADWELL Specifies well quantities to be output to the HMD file.
GRADGRUP Specifies group quantities to be output to the HMD file.
HMPROPS Flags start of HMPROPS section.
HMRREF Specifies reference pressures for rock compaction modifiers.
NOHMD Switch off gradient calculations.
NOHMO Switch off gradient calculations.
RPTHMG Configure output of derivatives for groups.
RPTHMW Configure output of derivatives for wells.
TUNINGH Tuning parameters for gradient calculations.
