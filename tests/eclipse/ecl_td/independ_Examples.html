Examples

Example 1

To merge a 2*4*1 grid with a 3*2*1 grid side by side in the X direction.

RUNSPEC section:
DIMENS
 6  4  1  /
GRID section:
BOX
 1 2   1 4   1 1   /
COORD....    for the first grid.
ZCORN....
BOX
 4 6   1 2   1 1   /
COORD....    for the second grid.
ZCORN....
EQUALS
 ‘ACTNUM’ 0 3 3 1 4 1 1 /   inactivate the row between the grids.
 ‘ACTNUM’ 0 4 6 3 4 1 1 /   inactivate the redundant region of
/                           the grid.

 2 /

COORDSYS
 1 2 /
 3 3 /
RESVNUM
 1 /

 1 2   1 4   1 1   /

ZCORN....
RESVNUM
 2 /
BOX
 1 3   1 2   3 3   /

ZCORN....

 ‘ACTNUM’ 0  1 3  3 4  3 3 /  the grid.
