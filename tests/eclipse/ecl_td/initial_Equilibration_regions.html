Equilibration regions

The reservoir can be divided into a number of ‘equilibration regions’ in which hydrostatic equilibrium exists independently of other regions. The number of equilibration regions (NTEQUL) is specified by using the EQLDIMS keyword in the RUNSPEC section. Cells are associated with these regions using the EQLNUM keyword. Cells in a given equilibration region should have the same pressure table for their PVT properties, but they can use different saturation tables.

Cells in different equilibration regions should be non-communicating, otherwise they may not be in equilibrium. See "The threshold pressure option".
