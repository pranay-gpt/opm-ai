Grid and solution reports

Just as WELSPECL and COMPDATL (or COMPDATM) replace WELSPECS and COMPDAT for refined wells, so RPTGRIDL replaces RPTGRID in the GRID data section grid reports for all local grids. RPTGRID may also be used in the normal way to produce global grid reports.

ECLIPSE 100

Refined cells have the decimal point replaced by R in reports output to the PRT file using the RPTGRID, RPTSOL, and RPTSCHED keywords.
