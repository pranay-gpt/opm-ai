Example LGR problem

This data set describes the seventh SPE Comparative Solution Project (1991) - a horizontal well with friction. The data set describes CASE 3A, having a 900 ft. horizontal well completed across 3 global cells in the x-direction. These 3 cells, plus an additional cell at each end (making 5 in all), are refined as follows:

Z-direction: 3 layers with a 2: 1: 2 thickness ratio.

Y-direction: 3 rows with a 2: 1: 2 thickness ratio.

X-direction: The two global cells at each end were refined into 4, with equal DX values. The central global cell was not refined in the x-direction.
