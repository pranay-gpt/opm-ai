GRID section

Restriction Keyword Description
ECLIPSE 100 AUTOCOAR Is analogous to the COARSEN keyword and may be used in auto-refined grids.
ECLIPSE 100 AMALGAM Defines groups of LGRs which are to be amalgamated.
  CARFIN Sets up a Cartesian local grid refinement.
  COARSEN Defines a box of cells for grid coarsening.
  EXTFIN Specifies an unstructured local grid refinement.
  EXTHOST Used to specify the global host cells for an unstructured local grid refinement.
  EXTREPGL Specifies the replaced global cells for an unstructured local grid refinement.
  GRIDFILE Controls the contents of the Grid Geometry file.
  HRFIN Can be used to dictate the size ratios of DRV values within radial local grids.
  HXFIN Can be used to dictate the size ratios of DXV values within Cartesian local grids.
  HYFIN Can be used to dictate the size ratios of DYV values within Cartesian local grids.
  HZFIN Can be used to dictate the size ratios of DZV values within Cartesian local grids.
  INRAD Specifies the inner radius of the radial refinement.
  NXFIN Sets the number of local cells in each global cell in the x-direction.
  NYFIN Sets the number of local cells in each global cell in the y-direction.
  NZFIN Sets the number of local cells in each global cell in the z-direction.
ECLIPSE 100 OUTRAD Inner radius of the outer annulus in a radial LGR.
ECLIPSE 100 QMOBIL Controls the mobile end point correction in an LGR.
  RADFIN Sets up a radial LGR.
ECLIPSE 100 RADFIN4 Sets up a 4 column radial LGR.
  RPTGRIDL controls grid section output for LGRs
  TRANGL Specifies the global-local connections and associated transmissibilities for an unstructured local grid refinement.
ECLIPSE 100 SMULTX, SMULTY, SMULTZ Alternative transmissibility multipliers for auto-refinement.
ECLIPSE 100 VEFIN May be used in LGR runs with Vertical Equilibrium in the global grid, to control the Vertical Equilibrium model in the local grid systems.

SOLUTION section

  • GETGLOB Read only the global restart data.

SUMMARY section

Well, block and connection data for an LGR can be obtained by prefixing the appropriate keywords with an L. Each subsequent data item to which the keyword refers is then prefixed by and LGR name. (See the SUMMARY section overview for further details.)

SCHEDULE

Restriction Keyword Description
ECLIPSE 300 COMPAGHL Sets the gravity head in local grid completion cells.
  COMPDATL Defines well completions in an LGR.
ECLIPSE 300 COMPKRIL Sets injection relative permeabilities in local grid completion cells.
  COMPLMPL Lumps well completions for automatic workovers.
ECLIPSE 300 COMPMBIL Sets injection mobilities in local grid completion cells.
ECLIPSE 100 COMPRPL Scales saturations for local grid well connections.
ECLIPSE 100 COMPVEL Sets well connection depth data in local grids.
ECLIPSE 100 LGRFREE Switches to local timestepping.
ECLIPSE 100 LGRLOCK Switches to global timestepping.
ECLIPSE 100 LGROFF Switches a local grid refinement off
ECLIPSE 100 LGRON Switches a global grid on.
ECLIPSE 100 LSCRITS Sets WARP linear solver convergence criteria for sub-grids.
ECLIPSE 100 NEXTSTPL Sets the next local timestep.
ECLIPSE 100 TUNINGL Sets simulator control parameters for all local grids.
ECLIPSE 100 TUNINGS Sets simulator control parameters for specific local grids.
  WELMOVEL Moves a well into an LGR at a restart.
  WELOPENL Shuts or reopens wells or well connections in an LGR.
  WELSPECL Defines a well in an LGR.
ECLIPSE 100 WFRICTNL Designates a well in an LGR to be a wellbore friction well
  WPIMULTL Multiplies well connection factors for a well in an LGR.

Options keyword (ECLIPSE 100)

Switch Description
32 controls timestep chops due to wells dying under THP control
37 replaces local grid solution states with those of the global host cell.
46 controls the interpolation of MINPV or MINPVV to LGRs.
51 controls the first local grid solution following a global timestep.
52 controls the use of corner point depths in VE runs.
56 controls the application of LGRON/ LGROFF.
