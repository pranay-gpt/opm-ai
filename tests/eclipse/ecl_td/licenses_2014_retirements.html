2014.1 license retirements

This release of ECLIPSE allows a number of options to be used without the need for a special license where previous releases had required one. These options are as follows:

  • CO2 Storage
  • Coal Bed Methane Model
  • Environmental Tracers
  • Flux Boundary Conditions
  • Foam Model
  • Gas Calorific Value Control
  • Polymer Flood Model
  • Gi Pseudo-Compositional Model
  • Solvent Model
  • Surfactant Model
