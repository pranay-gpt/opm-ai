Block Parallel

The Block Parallel license is activated by the BPARA keyword. This is an alternative license option for parallel simulations with up to 32 parallel domains. In such cases, a single Block Parallel license can be used instead of the (up to) 32 parallel licenses that would normally be required. To use this option the PARALLEL keyword must also be present, with item 1 (the number of domains) set to a value in the range 2 to 32. If more than 32 domains are requested the simulation will stop with an error message. The Block Parallel license feature is not compatible with the Multiple Realization option.
