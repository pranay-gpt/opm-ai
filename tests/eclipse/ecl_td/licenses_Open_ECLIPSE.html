Open ECLIPSE

Open ECLIPSE enables ECLIPSE 100 and ECLIPSE 300 to be controlled by, and communicate interactively with, other applications. Although ECLIPSE is primarily used in a batch standalone mode controlled solely by the contents of the input data file, there are many situations in which it would be advantageous to have ECLIPSE controlled by another software application.

For instance, there may be a requirement to have ECLIPSE tightly coupled to a surface gathering system model, or a specialized production optimization application. It could also be useful to couple ECLIPSE to an interactive controller, to allow you to view the current status of the simulation and make well management decisions during the course of the run. In addition to the licenses that ECLIPSE usually checks out, the simulator will also request an openeclipse license.
