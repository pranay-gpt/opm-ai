Summary of keywords

RUNSPEC

  • MISCIBLE Initiates the mixing calculation.

PROPS

Keyword Description
MSFN Miscible gas/oil saturation functions.
PMISC Pressure dependent miscibility tables.
RPTPROPS Controls output from the PROPS section. Argument PMISC outputs the miscibility function and the pressure miscibility function.
SDENSITY Solvent density at surface conditions.
SGCWMIS Miscible critical gas saturation tables.
SORWMIS Miscible residual oil saturation tables.
TLMIXPAR Todd-Longstaff mixing parameter.

REGIONS

Keyword Description
MISCNUM Miscibility region numbers.
RPTREGS Controls output from the REGIONS section. Argument MISCNUM outputs miscibility region numbers.

SOLUTION

Keyword Description
RPTSOL Controls output from the SOLUTION section. Use as for gas phase output.

SUMMARY

No specific keyword is required for the miscible option. The outputs are those available for the gas phase.

SCHEDULE

  • RPTSCHED Controls output from the SCHEDULE section. Use as for gas phase output.
