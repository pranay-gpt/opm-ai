Using multiphase

The SOLID keyword must be used if multiphase components are present.

Multiphase components

The simulator can be used to predict when asphaltene precipitation first occurs. At the end of each timestep a multiphase flash is performed to determine whether a stable asphaltene phase exists. The multiphase flash first determines whether one or more liquid phases are stable. A liquid phase is then identified as an asphaltene phase if:

  • the heaviest hydrocarbon is an aromatic (see the HYDRO keyword), and
  • the heaviest hydrocarbon represents more than a third of the phase (by weight).

The saturation, density and molar density of the asphaltene phase are stored in the simulator as solid properties. At present the asphaltene phase is ignored in the flow calculations, so this model should only be used as an indicator of whether asphaltene precipitation occurs in the reservoir.

Asphaltene prediction is carried out in compositional runs using an Equation of State, if the SOLID keyword is used, and if the heaviest hydrocarbon is an aromatic (see the HYDRO keyword).
