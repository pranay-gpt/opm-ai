Matrix-matrix transmissibility and diffusivity

Each pore system is connected as described above.

The transmissibilities between the sub-grid cells are then calculated similar to the matrix-fracture transmissibilities as described in "Dual Porosity". Note that the innermost matrix grid cell properties are used to set up the transmissibilities and diffusivities.

The permeability factor used between the subgrid porosities can be set, similarly to dual porosity, by the keyword PERMMF.

For two grid cells where inner matrix cell I connects to the outer grid cell J (which could be matrix or fracture), the transmissibility is given as

TRIJ =CDARCY⋅ KI ⋅VBI ⋅σK

where

K I is taken as the X-direction permeability of the matrix blocks (unless PERMMF is also specified),
V BI is the matrix cell bulk volume (note that this is not the pore volume, having no porosity factor), and
σ K is a factor of dimensionality LENGTH-2 , to account for the matrix-matrix interface area per unit volume.

Note that the cell index for σK has been written as K rather than I. When I and J are both matrix cells, then K is the outer matrix cell J. However, when outer cell J is the fracture, then K is the inner cell: that is, K is the outermost matrix. The result of this is to have all the sigma values in contiguous locations in the first N -1 porosity locations in the SIGMAV keyword input. The innermost SIGMAV porosity (porosity N= NMATRIX +1) is not used.

The diffusivity is similarly given as

DIFFIJ =DIFFMMF I⋅VOLI ⋅σ K

where

D IFFMM FI is the diffusivity multiplier, and
V OLI is the matrix cell pore volume or coal volume (coal bed methane option)
