Summary of keywords (ECLIPSE 300)

RUNSPEC

  • RESOPT Activate the Reservoir Optimization License.

SCHEDULE section

  • RPTRST Set the restart output frequency using BASIC and FREQ

OPTIMIZE section

Keyword Description
OPTCONS Specify the optimization constraint functions
OPTDIMS Specify the key optimization dimensions
OPTFUNC Specify the optimization objective function
OPTLOAD Hot-start a reservoir optimization simulation
OPTOPTS Specify the optimization options (for example which optimizer to use)
OPTPARS Specify the optimization control parameters
OPTTUNE Define tuning for the optimization (for example, tolerances)
RPTOPT Request the style of optimization output

Miscellaneous

  • Item 77 of the OPTIONS3 keyword - compute and output constraint function gradients
