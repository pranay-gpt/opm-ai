ECLIPSE 100

ECLIPSE 100 partitions the reservoir either in the x or the y direction, whichever is the outer solver direction. It automatically divides the reservoir into domains with approximately equal numbers of active cells.

The number of planes allocated to each domain can be modified using the DOMAINS keyword in the GRID section. Since each domain is processed by an individual processor, it is advantageous to have broadly similar numbers of active cells within each domain. The partitions of the reservoir and the solver directions can be output to the Print file by including the DOMAINS mnemonic in RPTGRID, or graphically using the domains output to the INIT file.
