Summary of keywords

RUNSPEC

Restriction Keyword Description
ECLIPSE 300 NPROCX Defines the number of processors to be used in the x-direction.
ECLIPSE 300 NPROCY Defines the number of processors to be used in the y-direction.
  PARALLEL Initializes the Parallel option.
ECLIPSE 300 PDIVX Defines the partitioning in the x-direction.
ECLIPSE 300 PDIVY Defines the partitioning in the y-direction.
ECLIPSE 300 PSPLITX Specifies multiple domain decomposition in the x-direction.
ECLIPSE 300 PSPLITY Specifies multiple domain decomposition in the y-direction.

GRID (ECLIPSE 100)

ECLIPSE 100 keyword Description
DOMAINS Defines the partitioning of the grid.
IHOST Allocates LGRs to specific processes.
PARAOPTS Permits some fine tuning of the simulator.
RPTGRID Controls output from the GRID section. The DOMAINS argument outputs the domain split.

SOLUTION section (ECLIPSE 300)

ECLIPSE 300 keyword Description
RPTRST Controls solution output for flexible restarts. Argument PART outputs domain partitions
RPTSOL Controls output from the SOLUTION section. Argument PART outputs domain partitions.
