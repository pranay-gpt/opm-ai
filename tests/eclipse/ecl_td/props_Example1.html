Example

A typical set of dead oil keywords would be:

OILCOMPR
--Compressibility      therm.expansion coeff.
  5.00E-06             3.80E-04 0.0 /
OILSPECH
  specific heat
  0.5 /
OILMW
--effective molecular weight
  600.0 /
DENSITY
--for thermal, only oil density is needed.
  60.68 2* /

If multiple PVT regions are being used, a set of data should be entered for each PVT region. The number of PVT regions is entered as the second parameter of TABDIMS.
