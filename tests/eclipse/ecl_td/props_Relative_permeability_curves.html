Relative permeability curves

Keywords ENPTVT, ENKRVT, and ENPCVT specify the temperature-dependence of relative permeability curves. The form of these keywords is similar to the standard ECLIPSE 100/300 end-point-scaling keywords ENPTVD, ENKRVD, and ENPCVD. In the thermal option, end-point-scaling keywords cannot be used in the same data set as temperature-dependent relative permeability keywords.
