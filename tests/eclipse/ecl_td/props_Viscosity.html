Viscosity

Oil viscosity temperature dependence

Oil component viscosities can be input in functional form (OILVISCC or OILVISCF) or tabular form (OILVISCT). It is also possible to compute Lorentz-Bray-Clark viscosities for the oil phase by using the keyword COVTYPE. The interpolation method for the tabular form can be specified using the OILVTIM keyword.

If the OILVISCC keyword is used the viscosity μ c o for oil component c can be specified using one of four standard formulae:

The ASTM correlation:

log10 (μ oc ⁢+ A)⁡= B⋅T -C [Eq. 333.1]

The Andrade formula ( Perry and Green (1984) and Reid et al (1987) ):

log10 (μ oc )=A +B/T [Eq. 333.2]

The Vogel formula ( Perry and Green (1984) and Reid et al (1987) ):

log10 (μ oc )=A +B/(T +C) [Eq. 333.3]

A logarithmic formula:

log10 (μ oc )=A +B⋅log10 (T)⁡ [Eq. 333.4]

In these equations:

T is the temperature.

The coefficients A , B and C can either be specified directly, or values of viscosity and temperature can be specified, in which case the simulator calculates the correlation coefficients.

The ASTM correlation can be expressed in a form similar to Prats (1982) :

μ c o= (μ co1+ A)10 -x-A [Eq. 333.5]

where

x =C⋅log10 (T/T 1)⁡,

(1−A) is the limiting viscosity at infinite temperature,

B =log10( μo1 c+A )⋅ T1 -C and

μ c o1 is the viscosity at temperature T 1.

Note that the formula is given in terms of the viscosity μ and not the kinematic viscosity ν=μ/ρ .

The keyword OILVISCF can be used to fit each oil component viscosity according to the equation

μc o= D⋅T B [Eq. 333.6]

that is the same as the logarithmic formula specified by the OILVISCC keyword when A =log10D.

When all component viscosities have been calculated, the oil phase viscosity is calculated from

log⁡(μo) = ∑c=1N comps fc (xc)⋅ log⁡(μ c o) [Eq. 333.7]

where the functions fc are given by keyword OILVINDX, or are defaulted to

fc(x c)= xc.

Oil viscosity pressure dependence

The oil phase viscosity can be modified by a factor μp ⁡(P) /μ p⁡ (Pvref ) where μ p and Pvref are defined by the keywords PVCO and VISCREF.

Lorentz-Bray-Clark oil viscosities

The oil phase viscosities can be computed by the Lorentz-Bray-Clark (LBC) method. Here the components that should be used to form the mixture for the LBC calculation are selected using the keyword COVTYPE. The LBC viscosity is computed based on the fluid density, pressure and temperature. If LMIX is selected in this keyword, the components with this entry compute their densities and corresponding viscosities using the LBC method. If the LEMIX entry is present, the densities for these components are computed with an EoS and then applied for the LBC viscosity calculation. The entry NO means that the regular component viscosity calculation is applied for this component. Care must be taken when this method is applied for heavy oils.

Gas viscosity temperature dependence

Gas component viscosities can be input in functional form (GASVISCF) or tabular form (GASVISCT).

If the functional form is used, each gas component viscosity is fitted according to the equation

μc g= A⋅T B [Eq. 333.8]

where T is the temperature and c is the component number. The gas phase viscosity is calculated to be

μg ⁢= ∑ c=1 N comps +1 yc ⋅μ gc [Eq. 333.9]

Lorentz-Bray-Clark gas viscosities

The gas phase viscosities can be computed by the Lorentz-Bray-Clark (LBC) method. Here the components that should be used to form the mixture for the LBC calculation are selected using the keyword CGVTYPE. The LBC viscosity is computed based on the fluid density, pressure and temperature. If LMIX is selected with this keyword, the components with this entry compute their densities and corresponding viscosities using the LBC method. If the LEMIX entry is present, the densities for these components are computed with an EoS and then applied for the LBC viscosity calculation. The entry NO means that the regular component viscosity calculation is applied for this component.
