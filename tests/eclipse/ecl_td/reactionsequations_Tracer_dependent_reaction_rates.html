Tracer dependent reaction rates

In runs with tracers the reaction rate can contain extra terms that depend on the tracer concentrations. The tracers act as a catalyst. Equation 263.1 is replaced with:

Rr=V b⋅A r⋅ e(- Er /(RT ))⋅Πcri nri⋅ ΠT rj [Eq. 266.1]

The tracer multiplier terms T rj are calculated explicitly (at the previous timestep) as

Trj =(θ ⋅tj⋅c c) nt j [Eq. 266.2]

where

t j is the tracer concentration
c c is the concentration of the carrier component c in the tracer phase p j
n tj is the order of the tracer term.

If the tracer phase is oil then:

cc=bo ⋅S o⋅ xc [Eq. 266.3]

If the tracer phase is gas:

cc=bg ⋅S g⋅ yc [Eq. 266.4]

If the carrier is water and the tracer phase is water:

cc=bw ⋅S w [Eq. 266.5]

If the tracer is in all phases:

c c=mc [Eq. 266.6]

The reaction number r tracer t j, tracer phase p j and tracer order n tj for each tracer dependent term is defined by the REACTRAC keyword. The REACTION keyword should be used to specify the total number of tracer dependent terms. The tracer names and carrier components must be defined by the TRACER keyword. Values of the tracer multipliers can be output using the mnemonic REAC in keywords RPTRST or RPTSCHED.
