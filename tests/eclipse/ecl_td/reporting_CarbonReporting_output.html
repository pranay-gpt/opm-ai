Reporting

For each well and each group, summary output for the time-varying values of the rate of carbon molar production (where negative indicates injection) and the cumulative molar carbon production during the simulation can be requested. For example:

WNCPR
 'P*' /
 'I*' /
/

FNCPT

The FNCPT value for the field at the end of the simulation corresponds to the 'moles' row in the table at the end of the PRT file.

Carbon reporting can be added in a restart.

ECLIPSE 300

The cumulative carbon produced will account for production / injection during the base case using the value provided in the restart case.
