Summary of keywords

SUMMARY section

Refer to Reservoir coupling facility in the ECLIPSE Reference Manual.

SCHEDULE section

Keyword Description
DEBUG Switch 39 turns on debug from the systems annex for MPI calls. Switch 42 turns on debug from the reservoir coupling facility.
DUMPCUPL Instructs the master run to write a reservoir coupling file, containing the flows and applied constraints of the master groups.
GRUPMAST Must be used in the master run to identify the master groups and to indicate which slaves they are associated with.
GRUPSLAV Must be used in each slave run to identify the slave groups and their associated master groups in the master run, and to set the filter flags that determining which rate constraints are to be imposed on them
RCMASTS Sets a minimum length for timesteps restricted by a group’s limiting fractional change in flow rate.
SLAVES Must be used in the master run to identify the slave run data files and to indicate where they are located; their simulation processes will be started when this keyword is read
USECUPL Instructs ECLIPSE to read group flows or constraints from a reservoir coupling file
