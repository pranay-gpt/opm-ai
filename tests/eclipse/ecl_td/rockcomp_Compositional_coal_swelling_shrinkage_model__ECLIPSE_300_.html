Compositional coal swelling/shrinkage model (ECLIPSE 300)

A modified form of the Palmer-Mansoori rock model is available by using the ROCKPAME keyword. A similar approach is described in Mavor and Gunter (2006) . An important difference is that the model described here will not predict volume changes for undersaturated coal. Each component of the system can be assigned Langmuir curve parameters β k,εk , making the swelling or shrinkage of the coal dependent on composition. The strain of one component is computed as if the coal gas is instantly in equilibrium following the extended Langmuir formula for adsorption capacity

e k= εkβk akP 1+∑βj ajP

where a k=Lk /(∑Lj) represent the adsorbed mole fraction of component k , P the pressure and L k are the adsorption capacities of each component (see keyword LANGMEXT).

The total strain is then computed as

E= ∑ek

Using this in the Palmer-Mansoori equation the pore volume, V (P,Y) , at the current pressure, P, and gas phase composition Y=(y1 ,y2 ,…,y nc) are adjusted using

V⁡(P,Y) =V 0{1+cm φ0 (P -P 0) +1 φ0 ( KM -1)( E-E 0) }

where:

φ 0 is the initial porosity
P 0 is the initial pressure
V 0 is the pore volume at the initial pressure and composition
K is the bulk modulus
M is the constrained axial modulus
γ is the grain compressibility
β k, εk are parameters of the match between the Langmuir curve and the change in volumetric strain due to matrix shrinkage for component k.
f is a fraction between 0 and 1
the term c m is given as c m=1 M- [K M+f -1]γ

For undersaturated coal where the adsorbed gas is not changing the formula is modified so the strain is constant. The strain used then corresponds to the state where the gas would start to desorb.

Note also that the ROCKPAME keyword only apply to regions with cells connected to coal cells as assigned by COALNUM.

Note: The rock compaction models takes the input porosities as the porosities at reservoir conditions. In areas without coal different rock compaction models can be used but some care must be taken so the input porosities are treated consistently for the entire model.
