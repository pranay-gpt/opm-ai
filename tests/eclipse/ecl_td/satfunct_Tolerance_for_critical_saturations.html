Tolerance for critical saturations

Critical saturations are assigned from the saturation tables by establishing the highest value of saturation for which the associated relative permeability is zero. In practice, the exceeding of a threshold (tolerance) value is used to test whether the relative permeability value is zero or non-zero. For ECLIPSE 100 and 300 the default thresholds are 1 x 10 -6 and 1 x 10 -20 respectively. These default values may be modified using the TOLCRIT keyword.
