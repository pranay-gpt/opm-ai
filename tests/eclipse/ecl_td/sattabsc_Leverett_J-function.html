Leverett J-function

The Leverett J-function is a dimensionless group that allows the capillary pressure function to be correlated with the rock properties.

J⁡(Sw) = Pc σ(Kφ ) 12 [Eq. 167.1]

where

P c capillary pressure
σ surface tension
K rock permeability
φ rock porosity.

If either the JFUNC or the JFUNCR keyword is used in the GRID section then the capillary pressure is calculated as follows:

Pc=F⋅J( S) [Eq. 167.2]

where

J(S)  J-function. This is input as a function of saturation in the column for capillary pressure in the SWFN or SGFN table.

F  Scaling Factor given by:

F =σ⋅( φK )1 2 ⋅Uconst [Eq. 167.3]

where

σ Surface tension - specified in the JFUNC or the JFUNCR keyword
φ cell porosity
K  cell permeability
U const  constant depending on the unit system employed:

= 0.318316 (METRIC units, pressure in bars, perm in mD)

= 4.61678 (FIELD units, pressure in psi, perm in mD)

= 0.314153 (LAB units, pressure in atm, perm in mD)

= 0.314153 (PVT-M units, pressure in atm, perm in mD)

The permeability direction to be used in the calculation may be specified using item 6 of the JFUNC or the JFUNCR keywords. If this is defaulted, the permeability will be calculated from K= (Kx+ Ky)/ 2, unless the model is a cross section, in which case K is will be selected from the appropriate horizontal permeability. For a one-dimensional model, the permeability value K is obtained from the permeability corresponding to the direction of the row or column of cells. In addition, irrespective of the permeability direction specified:

  • if the numbers of cells in the x and y directions are both equal to 1, the z-direction permeability values will be used
  • if the number of cells in the x direction only is equal to 1, the y-direction permeability values will be used
  • if the number of cells in the y direction only is equal to 1 the x-direction permeabilities will be used.

ECLIPSE 100

JFUNC and JFUNCR have an additional option U which allows user-defined permeabilities specified in the PERMJFUN keyword to be used instead of directional permeabilities.

The JFUNC or the JFUNCR keyword in the GRID section causes the scaling factor F to be computed from the grid data and stored in the PCW or PCG array. The scaling factor can be output by using the mnemonic ENDPT in the RPTPROPS keyword.

ECLIPSE 100

Note that, if the surface tension is required to be a function of pressure, the pressure dependent capillary pressure option (STOW and STOG keywords) can be used to modify the surface tension. In this case:

Pc=J⁡( S)⋅σ⋅σ⁡ (P) σref ⋅ (φK) 12 ⋅U const [Eq. 167.4]

where σ (P) and σ ref are input using the STOG or STOW keywords.
