Sharing licenses with the slaves

There was a major change in the licensing model used with Reservoir Coupling in 2005A. Prior to 2004A a reservoir coupling job would check out only one eclipse license and one feature license no matter how many SLAVES there were.

From 2005A this policy was modified so that each SLAVE requires an ECLIPSE license as well as the master. Each SLAVE also requires one feature license for every feature it uses.

The following example indicates how works:

Master

SLAVE 1 uses LGR and Multisegwells

SLAVE 2 uses LGR and networks

SLAVE 3 uses networks

Prior to 2004A the following licenses would have been required to run this model:

  • 1 eclipse
  • 1 lgr
  • 1 network
  • 1 multisegwells
  • rescoupling

Since 2005A this is:

  • 4 eclipse
  • 2 lgr
  • 2 network
  • 1 multisegwells
  • 1 rescoupling
