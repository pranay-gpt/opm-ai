Solid properties

Solid phase
The SOLID keyword must be used if solid components are present.

The number of components (including solid components) must be specified using the COMPS keyword, or the COMPSOL keyword if it is a BLACKOIL simulation.

Solid-only components
The CVTYPE keyword can be used to specify solid phase components. The CVTYPES keyword can be used to specify solid phase components at surface conditions.

These solid components are ignored by the flash - they cannot enter the liquid or gas phase. The only way they can change is through a chemical reaction, when they can become a different component.
