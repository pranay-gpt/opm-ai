WARP solution procedure for sub-grids

Firstly consider the two color case, where S α and S β represents all the sub-grids in colors α and β respectively, L αβ and Uαβ are the lower and upper color-to-color connective terms (these are implemented using NNC connections). Let us assume that nested factorization can be performed on each sub-grid, and hence each color, as outlined in the previous sections. The matrix system A can be decomposed into a 2 x 2 block color matrix thus

A=[ 00 L αβ 0]+[ Sα 0 0S β ]+[ 0 Uαβ 0 0] [Eq. 683.1]

The procedure is to perform nested factorization on this block system, that is the pre-conditioner is

M ˜ =[Q α0L αβ Q β][ Qα0 0 Qβ ] -1[Q α Uαβ 0 Qβ ] [Eq. 683.2]

thus

M ˜ =[ Qα U αβ L αβ ( Lα β⁢  Qβ -1+ Qβ ) ] [Eq. 683.3]

The matrix Q is chosen to preserve rowsum (of pressure only) so

Qα=Gα [Eq. 683.4]

and

Qβ =G β⁢-  row sum⁢  (L αβ Qβ -1 Uα β) [Eq. 683.5]

where Gα and G β are the diagonal nested factorization matrices constructed from all the sub-grids associated with colors α and β respectively.

During this procedure Q -1 needs to be evaluated. If individual tolerances are imposed on sub-grids (through the LSCRITS keyword), then this inversion is approximated by multiple iterations of GMRES, rather than just one nested factorization inversion.

For multiple colors the above procedure is applied recursively. For example if four colors α,β,γ,δ are present, the matrix A could be written

A = SαU αβ Lα βSβ U{αβ,γδ}L{αβ ,γδ } SγU γδ Lγ δSδ [Eq. 683.6]

and then nested factorization can be performed on the 2 x 2 system, where the blocks are groups of colors. Up to four levels of nesting are currently available, which corresponds to a maximum of 16 colors.
