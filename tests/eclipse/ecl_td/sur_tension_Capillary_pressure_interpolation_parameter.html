Capillary pressure interpolation parameter

The capillary pressure interpolation parameter Fp (σ) is given as a linear function of the surface tension:

F p=mi n[σ 1σ 0, σσ 0] [Eq. 174.1]

where σ 1 is the maximum surface tension for capillary pressure calculation, which defaults to σ 1=σ0 but can be set larger than this value using the third data item in the MISCSTR or MISCSTRR keyword.

Therefore, the capillary pressure defined in equation 172.3 equals the miscible value of zero Pcog =0 when the surface tension is zero, σ=0, and equals the immiscible value Pco g=Pcog imm when the surface tension is equal to the reference surface tension σ=σ0 .

For surface tensions greater than the reference surface tension σ≥σ0, the capillary pressure can be extrapolated beyond the immiscible values, with the interpolation parameter being allowed to exceed 1:

Fp≤ σ1 σ0

For single-phase cells a value of 1 will be used for the interpolation parameter.

Values of Fp can be output to the print file or restart file using argument FPC with the RPTSOL, RPTSCHED, or RPTRST keywords.
