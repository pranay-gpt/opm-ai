Summary of ECLIPSE 100 keywords

RUNSPEC

Keyword Description
PARTTRAC Activates and dimensions the Partitioned Tracer option.
SURFACT Activates the Surfactant Model
SURFACTW Activates the Surfactant Model and enables modeling of changes of wettability.

GRID

Keyword Description
RPTGRID Controls output from the GRID section.

Argument KOVERD outputs the K/D values used in the calculation of the capillary number.

PROPS

Keyword Description
HWSWL, HWSWLPC, HWSWCR, HWSWU, HWSOWCR, HWSOGCR, HWKRW, HWKRWR, HWKRO, HWKRORW, HWKRORG and HWPCW Immiscible water-wet saturation end-points.
RPTPROPS Output of surfactant properties from the PROPS section (argument SURF).
SOCRS Scaled critical oil-in-water saturations at miscible conditions.
SURFADDW Defines weighting between oil-wet and water-wet relative permeabilities as a function of the adsorbed surfactant mass.
SURFADS Surfactant adsorption isotherm.
ADSORP Analytical adsorption isotherm with salinity dependence.
SURFCAPD Surfactant capillary de-saturation data.
SURFROCK Surfactant-rock properties and adsorption model indicator.
SURFST Water-oil surface tension in the presence of surfactant.
SURFSTES Water-oil surface tension as a function of surfactant and salt concentrations.
SURFVISC Modified water viscosity.
SWL, SWLPC, SWCR, SWU, SGL, SGLPC, SGCR, SGU, SOWCR, SOGCR, KRW, KRWR, KRG, KRGR, KRO, KRORW, KRORG, PCW and PCG Immiscible oil-wet saturation end-points.
TRACER Defines the tracers (for the Partitioned Tracer option).
TRACERKP Defines the functions K(P) for the partitioned tracers.

REGIONS

Keyword Description
HWSNUM Abbreviated alias for SURFWNUM.
SATNUM Defines the region number for oil-wet immiscible saturation function table.
SURFNUM Surfactant miscible region numbers.
SURFWNUM Defines the region number for water-wet immiscible saturation function tables and additionally the table describing the wettability as a function of surfactant adsorption (SURFADDW).
TRKPFxxx Specifies the partitioning function for tracer xxx for each grid block ('xxx' = 'SUR' for surfactant).

SOLUTION

Keyword Description
RPTSOL Controls output from the SOLUTION section.
  • SOCR outputs the critical oil saturations following a surfactant flood.
  • SURFBLK outputs the surfactant concentration, the modified water viscosity and the capillary number as well as water-oil surface tension (both for salinity dependent and salinity independent surface tension).
SURF Initial surfactant concentrations.
TVDP Initial surfactant concentrations with depth
TNUM Surfactant concentration regions.

SUMMARY

Refer to Surfactant model in the ECLIPSE Reference Manual.

SCHEDULE

Keyword Description
RPTSCHED Controls output from the SCHEDULE section. Arguments:
  • FIPSURF: surfactant in place.
  • SURFADS: adsorbed surfactant concentration.
  • SURFBLK: surfactant concentrations, modified water viscosity and the capillary number as well as water-oil surface tension.
RPTRST Controls output to the restart file.

Mnemonic VISC can be requested to output

  • EWV_SUR: effective water viscosity due to surfactant.
If a graphics only restart is required (in other words, when mnemonic NORST is requested) then adding mnemonic SURFBLK will output:
  • SURFACT: surfactant concentration.
  • SURFADS: adsorbed surfactant concentration.
  • SURFMAX: maximum adsorbed surfactant concentration.
  • SURFCNM: (log) capillary number (for miscibility transition).
  • SURFST or (SURFSTES): water-oil surface tension
On the other hand, for full restarts (not graphics only) above mentioned arrays will be output by default.
TUNING Sets simulator control parameters. Item 11 of Record 2 (TRGSFT) sets the target surfactant change.
WSURFACT Specifies the surfactant concentration of a water injector.
