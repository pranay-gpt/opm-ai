Obtaining gradients in ECLIPSE

At each simulator timestep, ECLIPSE forces the fully implicit residual in each simulator grid block to be zero (see "Formulation of the equations").

This can be written as

R (Xt+ dt,Xt, λ)= Mt+dt (Xt+ dt,λ)- Mt( Xt,λ )d t+ Ft+d t(Xt+d t,λ )+Q t+dt (X t+dt ,λ)=0 [Eq. 824.1]

where

the subscripts t and t+ dt denote quantities at the current and advanced time, with a simulator timestep of d t,
M is the fluid-in-place in each simulator grid block,
F is the net flow rate into neighboring grid blocks,
Q is the net flow rate into wells during the timestep,
λ is any gradient parameter,
X is the set of solution variables in each grid block.

For ECLIPSE 100, X represents pressure and saturations, and for ECLIPSE 300, X represents pressure and molar densities.

Differentiating equation 824.1 throughout with respect to λ yields

0 ⁢= dRdλ ⁢=  ∂R ∂λ ⁢+  ∂R∂ Xt⁢+ dt ⋅ ∂X t⁢+  dt∂λ ⁢+  ∂R ∂Xt⋅ ∂X t∂λ [Eq. 824.2]

which can be written as

J ⋅∂Xt+dt ∂λ= -∂R ∂X t ⋅∂Xt ∂λ -∂ R∂λ [Eq. 824.3]

where the Jacobian J=∂R /∂X t+dt is the same as that used to solve the reservoir equations, so no additional matrix setup is required. Therefore, for each gradient parameter λ selected, a set of linear equations, equation 824.3 must be solved at each simulator timestep to determine the gradient ∂Xt+dt ∂ λ. When there are several gradient parameters, each requires the solution of the same set of linear equations, equation 824.3 but with different right hand sides. The right hand sides contain two terms. The first is the product of ∂ R/∂ Xt, which is independent of λ , and the previously calculated gradient at the old timestep, ∂Xt/∂λ .

For a fully implicit discretization the second term in the right hand side of equation 824.3 is given by:

∂R∂ λ= 1dt (∂ Mt+dt ∂λ  -  dM td λ) +∂Ft+dt ∂λ+ ∂Q t+d t∂ λ [Eq. 824.4]

Evaluation of equation 824.4 depends on the parameter λ , and additional code is required for each new parameter. If, for example λ is a pore volume multiplier, then it would appear linearly in the accumulation terms, and not appear in the flow or well terms. Therefore equation 824.4 could be evaluated as:

∂R∂ λ= 1dt (∂ Mt+dt ∂λ  -  dM td λ) =1 λ( Mt+dt  -  Mt )dt [Eq. 824.5]

where the right hand side has already been calculated in evaluating the residual equation 824.1.
