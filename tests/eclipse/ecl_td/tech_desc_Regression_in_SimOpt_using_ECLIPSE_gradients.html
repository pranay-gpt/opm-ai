Regression in SimOpt using ECLIPSE gradients

The solution ∂X/∂ λ of equation 824.4 consists of derivatives of solution variables in each grid block. These are converted to derivatives of meaningful observable well quantities ∂ Wcal c/∂λ such as well block pressure and well flow rates. SimOpt uses these quantities to calculate derivatives and the Hessian of the objective function with respect to the gradient parameters for use in the regression algorithm.

It is important to note that ECLIPSE returns gradients ∂ X/∂λ around λ= 1 for multiplier-based parameters (such as HMPORVM, HMPERMX and HMKRW, in HMxxxxxx). During a gradient-based minimization loop, a sequence of multiplicative modifiers λ i,i=i,…,υ may be applied to the base data set whose effect is cumulative, so that after υ iterations, the cumulative modifier is

Λn =Πi⁢= 1 nλi

If the regression requires gradients with respect to the total modifier Λ n, then

∂X∂Λn = ∂X∂( Λn -1 λn )= 1Λ n-1 ⋅ ∂X∂ λn

In SimOpt, the regression operates on the parameter Λ n and the sensitivities provided by ECLIPSE are divided by Λ n at each regression iteration. For regression loops such as SimOpt relying on the cumulative parameters Λ n in this way, it is suggested that the log transform λ=ln ⁡(λ) is applied.
