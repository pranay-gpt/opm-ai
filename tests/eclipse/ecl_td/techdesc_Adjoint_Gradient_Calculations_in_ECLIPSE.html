Adjoint gradient calculations

After a simulation run, the optimization workflow starts with the calculation of the gradients of the objective function with respect to the chosen parameters. These gradients must take into account the equality constraints imposed by the fluid flow calculations solved in ECLIPSE.

At each simulator timestep, ECLIPSE forces the fully implicit residual in each simulator grid block to be zero (see "Formulation of the Equations").

CAUTION: The adjoint gradient calculations require a fully implicit formulation of the equations. If you try to use the reservoir optimization feature without this type of formulation, the run will be aborted.

This cell residual constraint equation may be written as

R (X n+1 ,X n )=M (Xn+1)- M ( Xn )d t+F (Xn+1)+ Q (X n+1 )=0 [Eq. 810.1]

where

the superscripts n+1 and n denote the current and previous timestep respectively, and
X n are the solution variables (pressure and molar densities for example) at time n
M(Xn ) is the fluid-in-place in each simulator grid block at time n,
F(Xn ) is the net flow rate into neighboring grid blocks at time n, and
Q(Xn ) is the net flow rate into wells at time n.

Note that the objective function is a function of both the control parameters λ ̲ and the simulation primary variables X; that is J=J( X, λ̲ ).

A Lagrangian formulation of the objective function is used in order to comply with the constraints imposed by the cell residuals,

L(X, λ̲ )=J(X , λ̲ )- Φ̲ ⋅R( X,λ ̲) [Eq. 810.2]

Note that when all the residuals are satisfied (R= 0) the Lagrangian is simply the objective function. The vector of Lagrange multipliers on the residuals, Φ̲ , is known as the “adjoint vector”.

We are interested in forming the total parameter derivatives of this Lagrangian:

dLd λ̲ ⁢= ∂L ∂λ ̲⁢+  ∂L∂X ⋅∂ X ∂λ̲ [Eq. 810.3]

for which we require the partial Lagrangian derivatives:

∂L∂X   =∂J ∂ X⁢− (Φ⋅ ∂R∂X ) [Eq. 810.4]

and

∂L∂λ̲  = ∂J ∂λ̲ ⁢− (Φ̲ ⋅∂ R ∂λ̲ ) [Eq. 810.5]

as well as the solution derivatives ∂X ∂λ̲ .

Since R=0, the vector of Lagrange multipliers can be chosen in any way.

As there is an implicit dependence of the solution variables on the control parameters, X =X(λ̲ ), the natural choice of Φ̲ is that which sets equation 810.4 to zero. This removes the need to calculate the solution derivatives. Hence we solve the adjoint set of linear equations:

Φ ̲⋅ ∂R ∂X ⁢= ∂J∂X [Eq. 810.6]

for the adjoint vector Φ̲ . The dimension of the adjoint vector for each time period is that of the normal fluid flow Jacobian (number of grid cells times number of simulation variables).

As an example, scoping equation 810.6 into four distinct time periods, it may be written as:

[Φ̲ 1 Φ̲ 2 Φ ̲3 Φ̲ 4 ][ A 110 00 A21 A22 00 0A 32 A33 0 00 A43 A 44 ]=[ ∂J∂X1 ∂J ∂X 2 ∂J ∂ X3 ∂ J∂ X 4 ] [Eq. 810.7]

where the A matrices are derivatives of the fluid flow residuals with respect to solution variables, given by

Amn ⁢=  ∂R m∂ X n [Eq. 810.8]

where m and n are time indices. By multiplying out Amn =∂ R m ∂ Xn , equation 810.7 term by term the general equation, which must be solved at any given time, index n is

Φ ̲ nA nn=∂J ∂X n -Φ̲ n+1A n+1,   n [Eq. 810.9]

This involves the value of the adjoint vector at time period, n+1. Since the only independent equation is the last one (for which we can solve for) then the adjoint Φ ̲4 equation, equation 810.9 must be solved backwards in time .

With the adjoint vector, Φ̲ , chosen as the solution of this system, the Lagrangian gradients we require are:

dLd λ̲ ⁢= ∂J ∂λ⁢̲ ⁢− ⁢ (Φ̲⋅ ∂ R ∂λ⁢̲ ) [Eq. 810.10]
Note: The effort of calculating these gradients is dominated by the solution for the adjoint vector, Φ̲ , which is independent of the type or number of parameters. This makes the adjoint method very efficient for large number of parameters compared to other gradient calculation techniques.

Introducing Additional Constraints

In the reservoir simulator the fluid flow residual equations (R=0) are constraints, which must always be observed as the objective function is optimized. Optionally, you may impose additional constraints on the system, for example limiting the production of a certain phase from a group of wells.

The Lagrangian approach allows us to readily incorporate these additional equality constraint equations, V=0 , by the introduction of further Lagrange multipliers, Ψ̲ :

L (X ,λ̲) =  J(X, λ̲)⁢− Φ⋅R( X,λ̲ )⁢−Ψ⋅V( X,λ̲ ) [Eq. 810.11]

The Lagrangian derivatives given in equations 810.3 to 810.5 above may be extended to include derivatives of the additional constraint functions. This allows us to form an extended adjoint system of equations, from which we obtain both Φ ̲ and Ψ̲ . The Lagrangian gradient equations, 810.4 and 810.5, then become:

dLdX ⁢=  ∂J∂ X ⁢− ⁢(Φ̲ ⋅  ∂R ∂X ) − ( Ψ ̲⋅ ∂V∂ X ) [Eq. 810.12]
dLd λ̲ ⁢=  ∂J∂λ⁢ ̲⁢ − ⁢( Φ ̲⋅  ∂R ∂λ⁢̲ ) −  (Ψ̲ ⋅∂ V∂λ⁢̲ ) [Eq. 810.13]

Notice that we have retained the special identity of the cell residual equations, as distinct from all other constraints. This allows us to solve for the Lagrange multipliers using modifications to the existing simulation fluid flow matrix A, rather than having to construct an augmented system.

In order to solve for Ψ̲ , we arbitrarily set ∂L∂ λi ⁢=  0 in equation 810.13 for as many parameters, index i, as there are active constraints. Consequently, equation 810.13 only applies to those parameters not used in determining Ψ̲ . This effectively divides the parameter set into 'free' and 'dependent' subsets: λ̲ =( λ ̲f ,λ̲ d ), where the free parameters are those for which we have Lagrangian gradients, and the dependent parameters are those which 'depend' on the free parameters using the constraint equations. This has important implications for the optimization workflow, as discussed in "Optimizer search direction".
