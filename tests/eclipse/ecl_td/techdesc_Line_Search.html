Line search

Given a search direction, s, the standard line search algorithm is to determine some step size multiplier, α, which maximizes the objective function value. The control parameters are updated using the algorithm λ̲= λ̲ +αs̲. The following figure illustrates the problem.




Figure 812.1 Line search

With no preferred scale, a line search may take many iterations to find the optimum position. However, along the way, we may encounter, or jump over, a new constraint. An indication of the position of the nearest constraint to the starting position of a line search can be obtained by expanding the constraint inequalities to give:

Vi (X +α iΔ X ,   λ ̲f +α iΔ λ ̲ f)=Vi(X, λ ̲)+α i( ∂V i∂X ⋅ΔX)+α i( ∂Vi∂ λ ̲ f⋅Δ λ̲ f)≤0 [Eq. 812.1]

Clearly, the closest constraint (that which would be first violated if an unrestricted amount of the search direction were used) is that for which the value of α is smallest when the inequality becomes an equality constraint. This may be obtained by rearranging equation 812.1, from which:

αi =-V i/( ∂Vi ∂ λ̲ f ⋅Δ λ ̲ f+∂Vi∂ X ⋅ΔX) [Eq. 812.2]

This sets a useful guide for the line search algorithm in the presence of constraints, and in practice can save many iterations of the line search.

As a further aid to convergence of the overall optimization loop, the tolerance used in determining the proximity of a constraint, ε , can be specified to potentially ‘catch’ several new constraints at once.
