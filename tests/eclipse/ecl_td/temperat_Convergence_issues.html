Convergence issues

ECLIPSE 100

The effects of unconverged timesteps forced to be accepted by ECLIPSE 100 might be significant although they tend to dissipate rapidly. These anomalies can be corrected if desired by choosing smaller timesteps that ensure the convergence of the solution.

Note: The MESSOPTS keyword can be used to control the severity type for messages in the PRT file that report timesteps that are forced to be accepted. Note also that the total number of timesteps forced to be accepted is output in the Error Summary.
