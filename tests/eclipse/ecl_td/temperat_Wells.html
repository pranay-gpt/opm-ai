Wells

ECLIPSE 100

In ECLIPSE 100 the temperature of the injected fluid can be specified for each well in the SCHEDULE section, using the WTEMP keyword. If a well does not have an injection temperature specified, the fluid is taken to be at zero degrees.

ECLIPSE 300

In ECLIPSE 300 the enthalpy of the injected water must be specified. This can be done by specifying the temperature and pressure of the injected water for each well in the SCHEDULE section, using the WINJTEMP keyword.
