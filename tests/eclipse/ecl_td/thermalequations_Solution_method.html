Solution method

For each cell there are N + 3 variables (pressure, N hydrocarbon components, one water component, and energy) and N + 3 equations (N + 1 component conservation equations, including water, equation 310.1, energy conservation, equation 310.2 and volume balance, equation 310.3). The equations can be solved using a fully implicit method (FULLIMP / default), an implicit pressure, explicit properties method (IMPES) or a combination of both, (AIM).

The component conservation equations are written as

Rfl =V p(Pt +Δt )⋅m fl(t+Δt)-V(P t)⋅mfl(t) Δt+ Ffl+Q fl=0

where, in an implicit cell the flow terms and well terms are evaluated at the new time:

Ffl =F fl(Pt +Δt ,T t+Δt,St+Δt)

Qfl =Q fl(Pt +Δt ,T t+Δt,St+Δt)

and in the IMPES method the flow terms and well terms are evaluated using the new pressure but with properties at the previous timestep:

F fl= Ffl (Pt+Δt ,Tt,St )

Q fl= Qfl (Pt+Δt ,Tt,St )

The energy conservation equation is dealt with in a similar manner, but the volume balance equation is always evaluated at the new timestep.

The non-linear residual equations

R⁡(X) =0

are solved iteratively,

X n=X n-1 +ΔX n-1 [Eq. 319.1]

The solution increment Δ X n-1 is found by solving the linear matrix equation

0 =R(Xn-1)+ J⋅Δ Xn- 1

where J is the Jacobian matrix:

J= (∂R∂X) |X=X n-1

The diagonal Jacobian element corresponding to an IMPES cell has a simple form which can be solved relatively easily:

Linear solvers

To compute the solution increment Δ X the linear system involving the Jacobian matrix must be inverted. Whilst the default WARP linear solver may be adequate for relatively simple simulations better performance is usually achieved with the JALS solver, which is used by default for thermal simulations. The JALS linear solver employs the constrained pressure residual (CPR) technique in which an approximate pressure system is solved for each outer iteration. The solution of the pressure system is referred to as the inner iteration. The GMRES algorithm is used for both the outer and inner iteration. The GMRES algorithm is similar to the ORTHOMIN algorithm and requires storing a set of search directions. The JALS solver options can be controlled with the JALS keyword, which can be inserted in the RUNSPEC section.
