Summary of keywords

RUNSPEC

The keywords are:
  • FRICTION Enables the Wellbore Friction option and sets array dimensions.

SUMMARY

Refer to Wellbore friction model in the ECLIPSE Reference Manual.

SCHEDULE

Keyword Description
OPTIONS Item 55 may be used to damp the Newton iterations if well convergence problems arise.
WFRICTN Designates a well as a friction well, and defines its tubing properties and the position in the tubing of the well connections with the grid cells.
WFRICTNL Performs the same task as WFRICTN, but should be used if the well is situated in a local grid.
