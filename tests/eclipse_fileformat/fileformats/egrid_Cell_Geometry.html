Cell Geometry

The coordinates for node IPOS, JPOS, KPOS (either 0 or 1) for cell I,J,K are constructed from:

  1. x1,y1,z1,x2,y2,z2 = COORD(0:6,I+IPOS,J+JPOS,RES)

    where COORDSYS(1,RES) <= K <= COORDSYS(2,RES)

    or RES = 1 if not defined.

  2. z=ZCORN(2*I+IPOS-1,2*J+JPOS-1,2*K+KPOS-1)
  3. if x1=x2 and y1=y2 then x=x1, y=y1

    else

    x=b*x1+a*x2, y=b*y1+a*y2

    where a=(z-z1)/(z2-z1), b=1-a.
