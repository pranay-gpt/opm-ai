File header records

INTEHEAD 10 INTE  

Each file contains this header record first.

  1. Version number for the SLN file. The version number starts from 1.
  2. Unit to use for geometry and properties. 1 for METRIC and 2 for FIELD.
  3. Phase indicator: 1=oil, 2=water, 3=oil/water, 4=gas, 5=oil/gas, 6=gas/water, 7=oil/water/gas
  4. Report step number, integer between 0001 and 9999.
  5. Day (1-31)
  6. Month (1-12)
  7. Year (as four digits, for example 1952)
  8. Hour (0-23)
  9. Minute (0-59)
  10. Second (0-59)
