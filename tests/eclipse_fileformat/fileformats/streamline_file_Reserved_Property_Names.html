Reserved Property Names

Although the properties in general are application defined, a few property names are reserved. These are:

  1. ID_BEG/END: Scalar property defining the source/sink number, that is index into the NAMES keyword record in the SLNSPEC file.
  2. ID_CELL: Segment property holding the cell numbers along the streamline.
  3. TIME_BEG/END: Node property that holds the time of flight from the first node to any node along the streamline.
